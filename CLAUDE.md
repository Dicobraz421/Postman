# Postman — правила для Claude Code
<!-- ≤3 КБ. Только стабильные правила. Текущая работа — в карточках docs/tasks/. -->

Клиент почты, календаря и контактов под Stalwart (JMAP; плагины IMAP, DAV, EWS); Rust, gpui, Windows.
Базис — скилл `pets-architecture`, процесс — скилл `pets-dev`.

## Где правда
1. `docs/decisions/` и `docs/specs/S0-decisions.md` — решения владельца (приоритетнее всего).
2. `docs/00-ARCHITECTURE.md` — слои, договор плагинов, реестры; отступления от базиса — `docs/adr/`
   (менять только PR класса B).
3. Карточка задачи `docs/tasks/<ID>.md` и разделы из её `read:`. Остальное не читать без нужды.
4. Запуск, снимки, стенд, диск — `docs/DEV.md` (читать нужный раздел).

## Правила
- Полосы — `lanes.toml`; одна волна = одна полоса = один PR; `gh pr merge --auto --rebase`. Коммиты по-русски.
- Проверки в конце волны: clippy и nextest затронутых (`rdeps`), снимки затронутых сцен dev-сборкой.
  Ручная проверка — `docs/manual-tests/<ID>.md`.
- «Не падать»: вне тестов нет `unwrap`/`expect`/`panic!`; ошибка — `Result`.
- Чужие данные (письма, вложения, приглашения) — только в воркере; песочницу не ослаблять без диагностики и ADR.
- Тексты UI — только Fluent (`tr!`), оба языка; журнал — по-английски. Клавиши и действия — только таблицей команд.
- Без модальных окон: подтверждение — строкой в окне, уведомление — тостом.
- Не трогать: чужие полосы, Cargo.toml/lock (→ полоса deps), генерируемые доки, .github/.

## Безопасность (репозиторий публичный)
- Секреты (пароли, токены) — не на диск и не в репо; учётные данные — только из локального окружения.
- Адреса стенда и внутренние системы компании — не в репо и не в выводе.
