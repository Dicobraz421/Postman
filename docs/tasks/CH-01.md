## Задача
ADR 0012 «Каналы бесед»: трейт `ChannelPlugin` рядом с `MailPlugin` (вход, синхронизация, поток событий, отправка),
модель `Conversation` / `Message` / `Participant` / `Attachment`, возможности `ChannelFeatures` (правка, удаление у
всех, реакции, «прочитано», «печатает», ответ на сообщение, сквозное шифрование, лимит вложения).

- Почта — канал `mail`: адаптер поверх существующих `MailPlugin` и `sync::Command`/`Event`, почтовая модель не
  меняется. Беседа почты = беседа Outlook (`thread`).
- Реальное время: канал присылает события сам (Telegram updates, Matrix sync), почта — как сейчас (опрос/IDLE/push).
- Хранение — единое хранилище ADR 0006: сообщения каналов по своему ключу, вложения — по содержимому с дедупом.
- Секреты сессии канала — хранилище секретов ОС, как пароли учёток.
- Включение каналов: настройка и ключ политики организации на канал (`docs/decisions/2026-11-12-policy-keys.md`).

## Готово
ADR 0012 в main с согласием владельца (класс B); `00-ARCHITECTURE.md` — раздел о каналах.
