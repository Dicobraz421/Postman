## Сделать
- Новые `Command`:
  - `CreateFolder { account, parent: Option<String>, name }`;
  - `RenameFolder { mailbox, name }`;
  - `MoveFolder { mailbox, parent: Option<String> }`.
  
  `None` — верхний уровень ящика. Маршрут — по учётке папки, как у `Move`.
- Итог: дерево перечитано → `Event::MailboxesChanged` (уже есть); отказ → новое `Event::FolderFailed { mailbox, error }`.
  Если путь команду не поддерживает, он отвечает `FolderFailed` с «not supported», и команда не теряется.
- Перенос папки в саму себя или в свою подпапку отсекать в ядре, до плагина.

## Приёмка
- Тесты маршрутизации (`target`) трёх команд: своя учётка и доп. учётка.
- Тест: перенос в потомка — `FolderFailed` без вызова плагина.
