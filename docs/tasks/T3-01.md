> Отзыв бета-тестера v0.1.0-beta.4 (issue #552, п. 3): «при создании встречи приложение крашится».

## Причина
Вкладка встречи спрашивает у сервера занятость. Ответ (`Event::Availability`) приходит через `Mailer::on_sync`, то есть
пока `Mailer` обновляется; вкладка читала `Mailer` (неотвеченные приглашения, T2-08в) — паника gpui
`cannot read Mailer while it is already being updated`. Демо-ящик занятость не запрашивает, поэтому сцены не падали.

## Сделано
- Неотвеченные приглашения вкладке передаёт `Mailer::on_sync` (`Meetings::on_sync(ev, pending, cx)`); вкладка `Mailer`
  в обработчике событий не читает.
- Сцена `cal-552-server-busy`: ответ сервера о занятости при открытой встрече тем же путём, что на живом ящике. Без
  правки — паника, с правкой — занятость принята.
