## Сделано
- `postman_ir::autolink` / `find_links`: `http(s)://`, `www.`, `mailto:` в простом тексте, как Outlook; Exchange отдаёт
  ссылку текстом «текст<https://…>» — скобки её ограничивают; схемы — через `check_link`.
- Письма text/plain: ссылки нажимаются (`from_plain`, в воркере).
- Подробности встречи: место и описание — с нажимаемыми ссылками; строка видеовстречи по макету — значок камеры,
  ссылка, тонированная «Подключиться» (открывает браузер). Ссылка — видеосервис (Teams, Zoom, Телемост, Meet, Webex,
  Jitsi, Толк, TrueConf, Jazz, VK, МТС Линк, любой `meet.*`) в месте или описании, иначе ссылка из места; место,
  равное этой ссылке, не повторяется.
- Сцена `event-online`: демо «Созвон с заказчиком» с описанием в форме Exchange.
