> Отзыв бета-тестеров (Postman#552, п. 7): «добавить шрифты/размеры, вставки таблиц нет (вставляется только текст)».
> Решение владельца 2026-11-11: письмо — Markdown, шрифтов и размеров нет (сознательно); таблицы и вставка из Word — да.
> Класс B: полосы app-gpui и formats, своё чтение `CF_HTML` в `sys`.

## Сделано
- Кнопка «Таблица» (значок с подсказкой, как списки и цитата) после «Цитата», команда `compose.table` без клавиши:
  таблица GFM 3 столбца × (заголовок + 2 строки) с новой строки у курсора, выделена первая ячейка заголовка.
- Tab / Shift+Tab в таблице — к следующей / предыдущей ячейке (набранное в ней выделено), Tab в последней — новая
  строка; таблица при этом выравнивается: ширина столбца — по самой длинной ячейке. Вне таблицы Tab — как был.
- Таблица в поле: ячейки на подложке, строка заголовка жирная, `|` и строка `---` приглушены (`display`: `Look::table`).
- Отправка: `<table>` в HTML-части, тест `markdown_table_becomes_html_table`.
- Вставка: в буфере есть HTML (`CF_HTML`, Word, браузер) — он уходит в воркер (`Request::Html` → IR), IR → Markdown
  (`paste_markdown`): таблицы GFM (выровнены, `**` заголовка Word снимаются), списки, жирный, курсив, ссылки,
  заголовки; шрифты, размеры, картинки чужого документа — нет. Не вышло (нет воркера, ошибка) — вставляется текст
  буфера. Без HTML — обычная вставка текста. Больше 8 МБ HTML — текст.
- Чтение `CF_HTML`: у gpui и pets его нет — четыре вызова user32/kernel32 в `app-gpui/src/sys/clipboard.rs`
  (`unsafe` только там), разбор заголовка `StartFragment`/`EndFragment` — `sys::cf_html_fragment` (тест).
  Под `--screens` буфер Windows не читается: `screens::clipboard_html` отдаёт образец сцены (`hold_clipboard_html`).
- Сцены (`on_request`): `compose-t306-table` («Таблица», «Город», Tab, «План»), `compose-t306-paste` (HTML Word:
  таблица, список, жирный).

## Не сделано
- Выравнивание по пробелам — в моноширинном шрифте ровно, в шрифте интерфейса (поле письма) — приблизительно: шрифт
  для отрезка украшения поля gpui-kit не меняет. Ровную сетку в поле даёт только моноширинный шрифт всего поля.
- Выбор размера таблицы (строк × столбцов) — нет: 3×2 и Tab добавляет строки; столбец добавить — руками (`| … |`).
- Чтение `CF_HTML` — своё FFI в `sys` вместо нейтрального API pets (решение 2026-10-28: «своих windows у интерфейса
  нет»). Перенести в `pets_shell::clipboard` — PR в pets и смена rev в полосе deps.
- Картинки из вставки (скриншот в Word) — не вставляются: им нужен выбор «вложить в текст»; отдельная карточка.
