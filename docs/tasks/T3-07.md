> Отзыв бета-тестеров (Postman#552, п. 6): «в подпись нельзя добавить картинку». Решение владельца 2026-11-11:
> Markdown + картинка. Класс B: модель настроек (core), сборка письма (formats), интерфейс.

## Сделано
- `prefs::Signature::images` — `SignImage { cid, name, mime, data }`: PNG, JPEG, GIF (по первым байтам) до 1 МБ
  (`MAX_SIGN_IMAGE`). В файле настроек — только описание; байты — файлом `<cid>.png|jpg|gif` в каталоге
  `<кэш>.settings.images` рядом с ним (`AccountPrefs::images_dir`): пишется при сохранении, удалённые — стираются;
  файла нет или он не той картинки — картинки нет и в подписи. Имя файла — только из своего `cid` (`sig<мс>@postman`).
- Редактор подписи: «Картинка» после «Вставить поле» — выбор файла Windows (rfd), чтение в фоне; ссылка
  `![имя](cid:…)` своей строкой у курсора. Велика, не картинка, не прочиталась — строка под текстом. Стёрли ссылку из
  текста — картинка уходит при «Сохранить». Подсказка «PNG, JPEG или GIF до 1 МБ…».
- Предпросмотр: логотип кадром (раскодирует воркер, как картинки писем), не раскодирован — его имя.
- Письмо: подпись встала (по умолчанию или из меню «Подпись») — картинки, на которые ссылается текст, вложениями с
  `Attachment::inline_cid`; в списке вложений их нет, нетронутое письмо остаётся нетронутым. Сменили подпись — картинка
  без ссылки не уходит (`Model::draft`). Под текстом письма — полоса «Картинки в тексте» с кадром.
- Сборка (`postman_compose::build`): `multipart/alternative [text/plain, multipart/related [text/html, картинки]]`,
  файлы — в `multipart/mixed`; `<img src="cid:…">` HTML и Content-ID части совпадают (тест
  `inline_image_goes_into_related_part`). Раньше mail-builder клал inline-части в `mixed`.
- Сцены (`on_request`): `settings-t307-sign-image`, `compose-t307-sign-image`.

## Не сделано
- Картинка в самом поле письма (на месте `![…](cid:…)`) — поле gpui-kit картинок внутри текста не рисует: кадр — в
  полосе под текстом.
- Черновик с логотипом, открытый с сервера заново (T2-11), — вернётся ли картинка inline, не проверено [проверить];
  новое письмо и смена подписи — проверены тестами.
- Размер картинки в письме (`width`/`height`) — нет: какой выбран файл, такой и уйдёт.
