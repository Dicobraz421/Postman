## Сделано
- `app-gpui/src/update.rs` над `pets-update` (pets `c767dfd`): `helper()` — первая строка `main`, до одиночного
  экземпляра; после окна — итог прошлой установки тостом («Postman обновлён до X» / «Не удалось обновить…») и
  проверка через минуту после старта, дальше раз в час (крейт сам решает, прошли ли сутки). Блокирующие вызовы — в
  своём потоке, UI-поток не ждёт.
- Тост «Вышла версия X · Установить» (и из истории уведомлений) → полоса «Скачивается Postman X · N из M МБ · Отменить»
  → подпись → помощник установки → обычный выход. Ошибки фоновой проверки — только в журнал.
- Оба вида установки: MSI (ставит `msiexec`, сам спросит UAC) и portable (архив, `install.ps1`): метка
  `postman.portable` рядом с exe — её кладут архив (`package.ps1`) и `install.ps1`, MSI — нет; копия из архива до
  метки узнаётся по `install.ps1` рядом с exe. Профиль — `%LOCALAPPDATA%\Postman`, не рядом с exe; в `keep` — метка.
- «Настройки → Общие → Обновления»: «Проверять обновления автоматически» (по умолчанию включено,
  `general.auto_update`, `#[serde(default)]`), «Проверить обновления» — настоящая проверка (`CheckReason::Manual`),
  строка итога, «Установить», «Все выпуски» — прежняя ссылка. Политика — выключатель заперт, кнопки нет.
- Канал по умолчанию — по сборке: у беты «Предварительный» (`Channel::for_build`); сохранённый выбор сильнее.
- Команды `update.check`, `update.install` (палитра).
- Политика: стандартная Pets `HKLM\Software\Policies\Aahz\Postman\AllowUpdate` (DWORD, читает крейт) и своя Postman
  `Software\Policies\Pets\Postman\AllowUpdate` (строкой, как прочие политики Postman); `0` в любой — запрет.
- CI `publish`: minisign каждого `.msi` и `.zip` → `.minisig` до `SHA256SUMS.txt`; без секрета `UPDATE_SIGNING_KEY`
  или переменной `UPDATE_PUBLIC_KEY` выпуск красный.
- Тесты `update_*` на `Updater::with_parts` с подменной сетью: обновление есть (MSI → `.msi`, portable → `.zip`), нет,
  суточное расписание, политика (ни одного запроса), выключенная настройка, канал, вид установки и `keep`.
- Сцены `update-available`, `update-downloading`, `settings-updates`.
