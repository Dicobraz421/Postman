## Сделано
- История обычной задачи — своё свойство `X-POSTMAN-HISTORY` (JSON, как шаги поручения `X-POSTMAN-STEP`; модуль
  `postman_calendar::history`): «Создана», «Создана из письма «…»», «Срок перенесён с … на …», «Выполнена», «Снова в
  работе», «Подзадачи: N из M» (подряд — одной записью), не больше 50 записей. Внизу карточки — последняя запись и
  «История · N» (все записи, новые сверху). У старых задач без записей — «Создана из письма «…»», если есть письмо,
  иначе строки нет. У поручения история — его шаги, как раньше.
- «Перенести на сегодня» у группы «Просрочено» («Сегодня», проект, категория, «Из почты»): срок всех просроченных —
  сегодня без времени, у задачи-письма — срок письма; тост «Перенесено на сегодня: N задач» с «Отменить».
- Вложение к результату: письмо «Готово — на проверку» с файлами, открытое в почте, кладёт к шагу результата ключ
  письма и имена с размерами файлов (`Step::mail`, `Step::files`, `assign::attach_mail`). В карточке поручившего под
  «Результат» — файлы (значок, имя, размер); щелчок — письмо с ними (файл открывается там, через песочницу). Демо: файл
  у «Итогового отчёта», письма нет.

## Не сделано
- Приложить файл к «Готово — на проверку» у исполнителя — макеты не рисуют (файл приходит письмом из любого клиента).
- Метка «Вложение проверено в песочнице» у файла — проверка идёт при открытии вложения в письме, задача её не знает.
