## Сделано
- Карточка приглашения в письме и боковая панель: у «Принять / Под вопросом / Отклонить» — ▾ с «… с комментарием…»
  (поле под кнопками, «Отправить» / «Отмена»; «Ваш день» на это время свёрнут) и «… без ответа организатору».
- Подробности события в календаре: «Другие ответы ▾» над кнопками — те же шесть вариантов (панель узкая).
- Контракт: `Command::RespondInvite { answer }`, `Areas::respond(.., answer) -> Responded` (`NoCopy / Sent / Kept`),
  общий итог `invite::delivery`; новый `Delivery::Silent { saved }` — тост «Ответ записан в ваш календарь, организатору
  не отправлен».
- Как уходит:
  - Exchange: комментарий — текст ответа (`AcceptItem` с `Body`); «без ответа» — `SaveOnly`, сохранённый ответ удаляется.
  - JMAP: статус в событии без рассылки (`sendSchedulingMessages: false`); комментарий — письмом iMIP с `COMMENT`
    (у JSCalendar нет комментария к ответу).
  - CalDAV: копия с `ORGANIZER;SCHEDULE-AGENT=CLIENT` (сервер не рассылает, RFC 6638); комментарий — письмом с
    `COMMENT`. Обычный ответ снимает параметр — снова отвечает сервер.
  - Только почта: комментарий — текст письма и `COMMENT`; «без ответа» — ничего не уходит.
- Найдено попутно: лента беседы (с T2-14 включена по умолчанию) прятала карточку приглашения/поручения и вложения
  открытого письма — теперь они над лентой.
