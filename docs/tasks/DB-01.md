## Сделано
- Решение `docs/decisions/2026-11-14-all-in-db.md` (правило и таблица исключений), ADR 0006 «Что не в базе».
- `postman_cache`: таблица `local` (ключ → значение и части по хэшу), `import_local` — перенос одной транзакцией с
  отметкой `meta.local_import`; вхождения частей из `local` — в `check_refs`.
- `postman_core::local`: метки, настройки учётки с картинками, подписки, история уведомлений, промежуточные S/MIME;
  `adopt` — перенос прежних файлов при открытии базы (файлы → `*.bak`, при следующем открытии — удаляются).
- Интерфейс: метки, подписи, подписки и история уведомлений — из базы профиля; история продолжается после входа и
  переноса формата (раньше после входа писалась только до перезапуска экрана).

## Не сделано
- Общие `settings.json`, `account.json`, `accounts.json` — файлами (исключения с причиной в решении).
- Файлы общей папки (история, подписки, промежуточные) попадают в базу, открытую первой; другой основной вход
  начинает их заново.
