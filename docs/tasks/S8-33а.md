> Решение №6 S8: полный писатель (S8-33б) — только если Outlook открывает пробный файл без восстановления.

## Сделать
- Писатель **нового** Unicode PST (MS-PST), без правки существующего и без транзакций: NDB — заголовок, корень,
  AMap/PMap, деревья узлов (NBT) и блоков (BBT), блоки данных и XBLOCK, `NDB_CRYPT_NONE`, CRC; LTP — HN, BTH,
  контекст свойств (PC) и таблиц (TC); Messaging — хранилище (`PR_IPM_SUBTREE_ENTRYID`, `PR_VALID_FOLDER_MASK`,
  `PR_RECORD_KEY`), корневая папка, IPM Subtree, папки поиска (`Finder`), таблицы иерархии, содержимого и
  «связанного содержимого», одна папка с одним письмом (`MapiMessage` S8-29) и одним вложением.
- Сначала — прочитать `outlook-pst` (Microsoft, MIT): можно ли взять его структуры и запись страниц; нельзя —
  свои, по спецификации.

## Приёмка
- Тест: наш файл открывается `outlook-pst` (dev-зависимость), папка и письмо со свойствами и вложением читаются.
- `docs/manual-tests/S8-33а.md`: Outlook владельца — «Открыть файл данных Outlook»: папка, письмо, вложение;
  `scanpst.exe` — без ошибок. Итог — решение владельца по S8-33б.
