## Сделано
- Модель правила (`postman_core::rules`): имя, условия группами — «ЕСЛИ a ИЛИ b И c» (группа «или», между группами
  «и»), проверки «содержит / не содержит / из домена / не из домена» (домен — у «От» и «Кому»), несколько действий,
  «Остановить обработку следующих правил», «в приложении». Sieve: `anyof`/`allof`/`not`/`address :domain :is`,
  `stop`; имя — строкой `# name:`, правило «в приложении» — `# app:` (сервер его не выполняет, список — один, на
  сервере). Скрипты прежнего вида читаются как были (подмножество).
- Раздел по макету: порядок стрелками ↑/↓, строка «ЕСЛИ … → …» кусками (слова, значения в рамке), «Где выполняется ·
  срабатывания», выключатель, редактор на месте строки (название, условия со списками выбора, «Добавить условие»,
  «Добавить группу „или“», действия с «Добавить действие», «Параметры»).
- «Проверить на последних 100 письмах» — «Подойдёт N писем из 100 · показать» со списком (по кэшу, в фоне,
  `postman_core::rulerun`). «Применять к существующим письмам — найдено N»: после записи правила его действия —
  подходящим письмам кэша (путь кнопок над письмами, `bulk::plan`), тост «Правило применено: N писем».
- «Выполнять на сервере, где возможно (Sieve)»: выключено — все правила «в приложении»: Postman выполняет их по новым
  письмам «Входящих» после каждого обновления (отметка «что проверено» — в кэше; первый запуск — с этой минуты),
  «удалить» — в «Удалённые». Пересылка — всегда на сервере.
- «Журнал срабатываний» (правила «в приложении» и «Применять к существующим»; 200 последних — в кэше), «Весь журнал».
- Контекстное меню письма (последняя группа, как в `Bulk`): «Всегда перемещать от этого отправителя ▸» — подменю
  папок своего ящика; «Заблокировать отправителя» (красным) — в «Нежелательные», нет — в «Удалённые». Без окон:
  правило сразу уходит на сервер (список ещё не пришёл — запрос и дописать по ответу), письма отправителя — следом,
  тост с «Правила».

  жизненный цикл» (S5-04), а не действие правила. Отдельная карточка.

- Срабатывания правил на сервере («сработало 412 раз»): Sieve о них не сообщает — счёт только у правил «в приложении».
- «Фишинг-признаки → Карантин» — снято решением 2026-11-09 (`docs/decisions/2026-11-09-security-is-server.md`).
