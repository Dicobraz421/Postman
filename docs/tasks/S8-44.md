## Сделать
- «Добавить календарь по ссылке»: `webcal://` или `https://…ics` → отдельный календарь «только чтение» с именем из
  `X-WR-CALNAME` (можно сменить) и своим цветом.
- Загрузка — ядро (https, тайм-аут, предел размера, ETag/If-Modified-Since); разбор `.ics` — только воркер; события —
  в хранилище с источником подписки; обновление — раз в N минут (настройка, по умолчанию 60) и по «Обновить».
- Ошибка загрузки — значок у календаря и подсказка, прежние события остаются; удалить подписку — события уходят.
- Повторы (RRULE, EXDATE), часовые пояса VTIMEZONE, весь день — как у своих событий.

## Приёмка
- Тесты на записанных `.ics` (повторы, пояса, изменение и удаление события между загрузками, 304); снимок календаря
  с подпиской; ручная проверка — публичный календарь праздников по ссылке.
