## Сделано
Часть 1 — пересылка: путь вложения от черновика до сервера во всех бэкендах.
- Окно письма: картинка inline без ссылки из текста при пересылке и в открытом черновике — обычным вложением (окно
  убирало её как «картинку подписи», и она пропадала); пустой файл — без blob.
- Сборка (`postman_compose::build`): у картинки inline — имя файла рядом с Content-ID; текстовое вложение в UTF-8 —
  с `charset=utf-8` (байты те же).
- IMAP и EWS (воркер `mime::part`): текстовое вложение — байтами письма, без перекодирования в UTF-8.
- JMAP, IMAP, EWS: вложение не скачалось или пришло пустым (и пустой blob в кэше) — отправка останавливается,
  код `attachment-missing:<имя>`, строка в окне письма.
- Шапка пересылки: «Копия» экранировалась дважды — как «Кому».
- Демо не отправляет (нет сервера); у всех вложений писем демо есть байты.

Часть 2 — `docs/decisions/2026-11-13-reply-all-attachments.md`.
- `postman_compose::share`: кто новый, сравнение файлов, `Draft::outgoing` (копии и конверты),
  `Draft::attachments_letter` (EWS).
- `Cache::letter_parts`: SHA-256 и размеры вынутых частей письма — без нового хэша.
- `app-gpui/src/share.rs`: участники и файлы беседы из кэша в фоне; строка над текстом и команда
  `compose.share_attachments`.
- JMAP: копия новым — `submit_unsaved` (`onSuccessDestroyEmail`), отмена вместе с основной (`jmap.companions` в кэше),
  в списке отложенных её нет. IMAP: два письма SMTP, в «Отправленные» — основное. EWS: «Вложения из беседы»
  `SendOnly`.

## Не сделано
- Черновик, открытый заново из «Черновиков», и письмо, вернувшееся после «Отменить», — без правила (участники беседы
  собираются только при «Ответить» / «Ответить всем»).
- Письма беседы без тела в кэше дают только участников, их файлов правило не знает.
