## Сделать
- `content: Hash → ContentRow { skeleton, parts, refs }`, `part: Hash → PartRow { bytes | chunks, refs }`,
  `chunk: (Hash, n) → bytes` (куски по 1 МиБ); `Hash` — SHA-256 исходных байтов.
- `put_content(raw, split)`: `split` — диапазоны листовых частей и раскодированные байты от воркера (S8-07); кэш
  кодирует часть обратно (base64 — ширина строки и перевод строки исходника; quoted-printable) и сравнивает с
  диапазоном; не совпало — часть остаётся в скелете. Без `split` (шифрованное, мелкое) — скелет = всё письмо.
- `content(hash) → Vec<u8>` (сборка ровно в исходные байты) и `content_reader` — потоком, для экспорта и выгрузки.
- Счётчики: запись письма — `refs + 1` у содержимого и его частей, удаление — `− 1`, ноль — удаление в той же
  транзакции. `check_refs()` — пересчёт для тестов и диагностики.
- `MAX_CACHED_BLOB` для писем снимается (кэш вложений `blob` — до S8-06).

## Приёмка
- Тесты: письмо с одним вложением в двух учётках — одна `part`; сборка = исходные байты (base64 без переносов, с
  LF, с хвостовыми пробелами); `multipart/signed` после сборки — те же байты; удаление последнего письма убирает
  содержимое и части; `check_refs` сходится после 1 000 случайных записей и удалений.
