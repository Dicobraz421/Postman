## Сделать
- `userSMIMECertificate` (RFC 2798) — PKCS#7 SignedData с сертификатами: чужой DER, разбирает только воркер. В
  `SmimePrepare` принимать и такой кандидат: сертификаты из `certificates` — каждый как обычный кандидат.
- Плагин каталога запрашивает и этот атрибут.

## Приёмка
- Тест воркера: PKCS#7 с двумя сертификатами → два подготовленных получателя; мусор — без паники, пропуск.

## Итог
- Протокол воркера не менялся: `prepare` принимает и PKCS#7 — получатель — первый сертификат набора с адресом,
  прошедший проверку, остальные — промежуточные; не больше 16 сертификатов; один кандидат — один ответ.
- Плагин каталога запрашивает `userSMIMECertificate` (и `;binary`).
