## Сделано
- Карточка отменённой встречи: кнопка «Удалить из календаря» (подсказка: организатору ничего не уйдёт). Итог —
  строкой карточки и тостом: «Встреча удалена из календаря» или «В календаре этой встречи нет». Демо — «нужен сервер».
- Команда `RemoveInvite { invite }` → `InviteRemoved { uid, found }` (+ `CalendarChanged`) или `InviteFailed`. Копия —
  по UID приглашения, отменённые тоже; отмена экземпляра серии — только он:
  - JMAP — `CalendarEvent/set` `destroy` (экземпляр — `recurrenceOverrides/<rid>: excluded`), `sendSchedulingMessages:
    false`;
  - CalDAV (и IMAP) — `DELETE` ресурса копии (экземпляр — `EXDATE`, `SCHEDULE-AGENT=CLIENT`);
  - Exchange — `DeleteItem` в «Удалённые», `SendMeetingCancellations="SendToNone"` (серия — по основной встрече).
- Кнопка видна всегда: отменённых в событиях дня нет («без отменённых»), есть ли копия — знает только сервер.
