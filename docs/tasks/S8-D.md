## Запрос
1. **Вопрос после переноса** — нейтральная строка над списком целевой папки (как «Автоответ включён…»): «12 480
   писем перенесены из «Stalwart · Входящие» · Перенести на сервер «Exchange» · Оставить локальным архивом»; у
   Exchange — «Метки Postman на Exchange не сохранятся» (вопрос №9 S8).
2. **Ход** — в строке состояния, как квота: «Перенос: 3 120 из 12 480 · 1,2 ГБ»; щелчок — строка задания с
   «Пауза», «Остановить»; «На сервере нет места: осталось N · Продолжить · Оставить локально»; отмена — «Остановить
   перенос: готово 3 120 из 12 480 · Оставить остальные локально · Вернуть на место»; конец — тост.
3. **Строка письма** — значок «ждёт переноса» и «только на этом компьютере» (место, тон, подсказка).
4. **Дерево** — группа «На этом компьютере» (значок, место в порядке групп, «Новая папка»).
5. **Экспорт** — где команда (меню папки, учётки, выделения), строка выбора формата и охвата в окне (EML, mbox,
   Maildir, MSG, PST; «с подпапками»), ход и тост «Открыть папку».
6. **Просмотр** — вкладки листов книги, листание слайдов (как страницы PDF), письмо во вложении, подпись
   «Просмотр: модуль … (сторонний)»; «Настройки → Просмотр вложений» — список модулей с выключателем.
7. **Хранилище** — строка «Обновление хранилища: N %» вместо списка при первом запуске формата 6; в «Настройки →
   Безопасность» — «Диск не зашифрован BitLocker» (ADR 0006 п. 7).
