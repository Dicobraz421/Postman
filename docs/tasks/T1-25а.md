## Сделать
- Новый модуль `contacts.rs`, папка `contacts` (`DistinguishedFolderId`) и её подпапки класса `IPF.Contact`:
  - изменения — `SyncFolderItems`, первое чтение — `FindItem` по страницам;
  - карточки — `GetItem`: имя, фамилия, отображаемое имя, адреса (до трёх), телефоны, компания, должность, отдел,
    заметки;
  - запись — `CreateItem`, `UpdateItem`, `DeleteItem` (в «Удалённые»).
  
  Списки рассылки (`DistributionList`) — только чтение.
- Справочник: `find_people_page(offset, max)` — `FindPeople` по папке GAL с `IndexedPageItemView` без строки поиска,
  сортировка по имени. Сервер может требовать строку поиска (Exchange 2013) [проверить]. Тогда — пустая страница
  с признаком «только поиском», и интерфейс остаётся при поиске, как сейчас. Обходить GAL через `ResolveNames` по
  буквам нельзя: это массовый обход. Свойства — те, что боевой Exchange отдаёт у GAL (`directory.rs`).
- Правило боевого Exchange (S7): тесты читают GAL одной страницей не больше 20 записей; приложение берёт страницы
  по 100 только по прокрутке пользователя.

## Приёмка
- Тесты на корпусе (обезличенном): разбор `FindItem` и `GetItem` контактов, сборка `CreateItem`, `UpdateItem` и
  `DeleteItem`; разбор страницы `FindPeople` (`TotalNumberOfPeopleInView`, смещение); отказ «нужна строка» → признак
  «только поиском».
- `stand.rs` (`#[ignore]`, тестовая учётка): контакт создан → прочитан → изменён → удалён (метка
  `[postman-test …]`); первая страница GAL ≤ 20.
