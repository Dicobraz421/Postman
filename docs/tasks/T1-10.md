- `ir_view::picture` сейчас ставит картинке ширину кадра. Нужна ширина `min(своя, ширина колонки текста)`, высота — по

  ресайз окна) картинка перевписывается без перекодирования: кадр тот же, меняется только размер элемента.
- Если IR несёт размеры из `width`/`height` HTML и они меньше кадра — уважать их. Если в IR их нет — не добавлять
  (`crates/ir` — другая полоса).
