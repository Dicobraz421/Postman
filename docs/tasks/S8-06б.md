Решение владельца 2026-10-29: хранилищу формата 6 не хватает API для движка переноса (S8-10, трейт `Store`).

## Сделать
- Строка задания `job: JobId → JobRow { mode: MigrationMode, state: MigrationState, total, bytes }`: `jobs`, `job`,
  `save_job`, `drop_job`; `move_letters` заводит её в той же транзакции (в «На этом компьютере» — локальный архив
  без вопроса, в учётку — вопрос), пачки одного переноса — одно задание.
- Шаги письма — одной транзакцией каждый, повтор после перезапуска безвреден, письмо не из задания — ничего:
  `set_step`, `confirm` (связь цели; связь, которую синхронизация цели завела раньше, — то же письмо), `archive`
  (только с содержимым), `refused`, `finish` (`detached`-связи убраны; `Synced` или `Local`).
- «Слишком большое для цели» — `Place::Refused(Refused)`: письмо остаётся в папке цели только в базе, у источника не
  удаляется (связи остаются `detached`).
- Отмена с возвратом: `Outbound::from` — папки до переноса (перенесённое снова, пока у источника есть, — до первого);
  `restore` — одной транзакцией обратно, связи источника снова действуют.
- Содержимое по `LetterId`: `letter_content`, `letter_content_reader`.

## Приёмка
- Тесты: перезапуск посреди задания (файл, шаги и строка задания на месте, повтор шага); отмена с возвратом (в
  несколько папок, из «На этом компьютере», перенесённое дважды); «слишком большое» (пометка, источник не тронут,
  синхронизация источника не возвращает); индексы и ссылки на содержимое сходятся.
