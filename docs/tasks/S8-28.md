## Сделать
- Без разбора письма и без I/O, кроме `Write` и имён путей: на вход — байты письма, дата, адрес отправителя,
  флаги (прочитано, отвечено, флаг, черновик) и папка.
- EML — байты как есть; имя `ГГГГ-ММ-ДД ЧЧММ — Тема.eml` (тема — из строки письма, `safe_name`; повтор — «(2)»).
- mbox (mboxrd): строка `From <адрес> <asctime UTC>`, экранирование `^>*From ` → `>` спереди, пустая строка между
  письмами, переводы строк — как в письме; заголовки `X-Mozilla-Status` не пишем. Дерево — `Папка` +
  `Папка.sbd/` (раскладка Thunderbird); для Apple Mail — пакет `Папка.mbox/mbox`.
- Maildir: `cur/`, `new/`, `tmp/`; имя `<время>.<pid>_<n>.<узел>:2,<флаги>` (флаги `D F R S` по алфавиту);
  запись — в `tmp`, затем переименование в `cur`; подпапки — каталогами (Maildir++ `.Родитель.Ребёнок` —
  переключателем).
- `Tree`: папки учётки → пути файлов, запрещённые символы и зарезервированные имена Windows (`CON`, `NUL`…).

## Приёмка
- Тесты: письмо со строкой `From ` в теле → `>From `, обратное чтение mboxrd даёт исходные байты; флаги Maildir;
  имена Windows; 3 уровня папок → `.sbd`.
- Ручная проверка — у S8-32 (импорт в Thunderbird и Apple Mail).
