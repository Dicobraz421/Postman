> Отзыв бета-тестера (issue #552, п. 5): «добавлять внешние домены в доверенные, чтобы письмо нормально прогружалось».
> Решение владельца — `docs/decisions/2026-11-11-remote-images.md`. Класс B: полосы ir, sandbox (`wasm.rs`), core
> (настройки) и app-gpui.

## Сделано
- IR (`postman-ir`): внешняя картинка — `Inline::Remote { url, alt, width, height }` вместо выброшенной; адрес —
  `http`/`https` с именем сервера, без имени и пароля, не длиннее 2048 (`remote_image_url`); пиксели слежения 1×1 и
  `0` — только подписью, как раньше. `Document::remote_urls` — адреса по порядку без повторов. Новый вариант —
  последним, старые IR читаются как были. В цитате ответа и в выводе модулей просмотра (`wasm.rs`) — подпись `[alt]`.
- Настройки (`postman-core`): `security.trusted_image_domains` — домены нижним регистром, по алфавиту, без повторов;
  `image_domain` (ввод `corp.example`, `@corp.example`, адрес), `sender_domain`, `trusts_images_from` — точное
  совпадение домена.
- Письмо (`remote_images.rs`, часть `images`): строка «Внешние картинки не загружаются (N)» при «Спрашивать» — с
  «Загрузить картинки» и «Всегда для домена …» (домен — в доверенные, тост); доверенный домен — загружаются сами;
  «Не загружаются никогда» (выбор или политика) и опасное письмо — только строка. Загрузка — порциями по 4 в фоне,
  каждая порция — сразу в письмо; не пришли — «Не загрузились внешние картинки: N».
- Сеть и песочница: качает `postman_backend_dav::fetch_public` (тот же клиент, что ссылки занятости: только `https`,
  имя сервера, без входа и кук, перенаправления — на такие же адреса, 5 с); `http` повышается до `https`; байты
  раскодирует воркер (`decode_image`, как `cid:`). Пределы — 5 МиБ на картинку, 20 МиБ и 40 картинок на письмо. Байты
  16 последних писем — в памяти: повторное открытие — без сети. Демо и снимки — заглушка без сети (`Stub`).
- Чтение (`ir_view.rs`): картинка внешняя — по адресу, как `cid:`; ссылка из одной картинки (баннер рассылки,
  логотип) — картинкой со ссылкой (щелчок — как по ссылке, адрес под курсором); незагруженная картинка без подписи
  места не занимает.
- Настройки → Безопасность: «Доверенные домены» под «Картинками из интернета» — поле с «Добавить» (Enter), список с
  «Убрать», «не домен» — подсказкой; при «никогда» — пометка «действует, только когда — Спрашивать». Подсказка
  «Спрашивать» и ключевые слова поиска раздела — про домены.
- Сцены по запросу: `images-banner`, `images-loaded`, `settings-images-domains`.

## Не сделано
- Строка и кнопки — в обычном виде письма; в ленте и стопке беседы внешние картинки, как и `cid:`, остаются подписями.
- Доверие — к домену из «От» (его проверяют SPF/DKIM на сервере, решение 2026-11-09); поддомены — отдельными строками.
