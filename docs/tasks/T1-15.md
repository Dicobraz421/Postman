  включаться только при `Conversation::Outlook` для открытой папки (`Reading::conversation_in`).

  строка на беседу (самое новое письмо папки, число писем), без раскрытия в списке, беседа — в панели чтения.
- Смена вида (настройки, свой у папки, T1-14) перестраивает список сразу, без перезапуска.
