> Владелец 2026-11-13: главное окно на macOS — по макетам `MainMac`, `MainMacDark`, `MainMacFull`
> (`docs/decisions/2026-11-13-macos-main-window.md`). Windows и Linux — без изменений (`MainNav_title`).

## Цель
На Mac окно выглядит как в утверждённом макете в обеих темах и в полноэкранном режиме.

## Что входит
- Заголовок (`chrome.rs`, `cfg(target_os = "macos")`): «светофоры» → вкладки; шестерёнки и своих кнопок окна нет.
  Вкладки 32 px по середине заголовка, без плашки; активная — полужирная, черта 2 px `accent_text` снизу; значок
  16 px по типу (письмо и вкладка почты — конверт `icon.blue`, встреча — календарь `icon.pink`, настройки —
  шестерёнка цветом текста). Главная вкладка в полосе не рисуется.
- Разделы над деревом папок (`mailer.rs` `section_bar`, `chrome.rs` `bar_sections`): четыре кнопки поровну на ширину
  дерева минус поля 8, высота 32; командная строка (`bar.rs`) учитывает смещение `lead` в расчёте места под кнопки
  и положении меню «…».
- Ответы в строке команд («Ответить», «Всем», «Переслать») — значком без подписи, как в макете; название и клавиша —
  в подсказке. Состав и порядок кнопок те же.
- Полный экран (`window.is_fullscreen()`): разделы 36 × 32 в заголовке на месте «светофоров», строка над деревом
  уходит; перестройка — при следующей отрисовке после входа/выхода.
- Документы: решение владельца, DESIGN «macOS», ручная проверка.

## Приёмка
- `macos.yml` зелёный; снимки `bundle --screens` (`list`, `calendar` и др.) совпадают с `MainMac` по раскладке.
- Windows и Linux CI зелёные, их снимки не изменились.
- Ручная проверка `docs/manual-tests/MAC-DES.md` на MacBook (не блокирует слияние).

## Решения для владельца
- Вкладка без строки команд («Настройки», письмо, встреча): разделов над деревом нет — они встают в заголовок за
  «светофорами» (как в полном экране), чтобы переход в раздел мышью оставался. В макете этот случай не показан.
- Полосы app-gpui и docs (DESIGN.md) в одном PR — по поручению владельца: ветка `x/mac-des`, класс B.

## Что не вошло
- Сцена `--screens` полноэкранного режима: снимок CI — в окне.
