> Решение владельца 2026-11-07: один установщик (MSI) и один пакетный менеджер (winget).

## Сделано
- `tools/pack` (`postman-pack`): MSI из комплекта `package.ps1` и манифест winget для готового MSI. Коды GUID выводятся
  из версии, без случайности. Версия MSI для бет — `ids::msi_version`.
- `package.ps1` кладёт `postman-<версия>-windows-x64.msi` в файлы выпуска. Подпись — `sign.ps1`: exe до архива, MSI после.
- CI (job `release`): `msi-check.ps1` на раннере ставит MSI, обновляет до следующей версии, проверяет отказ ставить старую
  поверх новой и удаляет. На тегах — артефакт `winget-<версия>`.
- Тесты: таблицы и CAB пакета, административная распаковка `msiexec /a` (без записи в систему), манифест winget.
- Документы: инструкция пользователя «Установка», `README.txt` комплекта, `docs/DEV.md` «Выпуск», описание выпуска.
