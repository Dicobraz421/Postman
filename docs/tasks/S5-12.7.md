## Цель
В «Настройки → Безопасность» — свои сертификаты S/MIME (`docs/SMIME.md` §7): кому выдан, адреса, издатель, срок,
годен ли для подписи; истекает через ≤ 30 дней — предупреждение строкой.

## Что входит
- Список — `postman_core::smime::personal_certificates()` (Windows — `CurrentUser\My`, macOS — Связка ключей; самый
  поздний срок — первым), вызов в потоке ядра, не интерфейса.
- Тексты — Fluent, оба языка, без названий ОС (`docs/decisions/2026-11-12-no-os-names.md`).
- Снимок сцены с демо-сертификатами.
- Где ключ (TPM, карта, программно) — если ОС отдаёт без доступа к ключу; иначе — не показывать.

## Сделано
- Группа «Свои сертификаты» в «Безопасности» после «Подписывать все письма»: строка на сертификат — кому выдан;
  адреса, издатель, «действует до»; справа — «Подпись» или «Не для подписи», «Истекает …» (≤ 30 дней, цвет сроков),
  «Истёк …», «Ключ не поддерживается». Нет сертификатов — «Своих сертификатов нет» с пояснением.
- Список читается в фоне при открытии «Безопасности» (`personal_certificates()`); демо-ящик — сертификат демо.
- «Где ключ» не показывается: без доступа к ключу ОС этого не отдаёт (Windows — свойство поставщика, macOS — атрибут
  токена) — отдельной задачей, если понадобится.
- Тест `cert_states`; ручная проверка — `docs/manual-tests/S5-12.7.md`. `docs/USER-GUIDE.md` («Подпись писем»: группа
  «Свои сертификаты», «системное хранилище» вместо «Windows») — волной полосы docs.

## Приёмка
Ручная проверка: список совпадает с `certmgr.msc` → «Личные» (Windows) и «Связка ключей» → «Мои сертификаты» (macOS).
