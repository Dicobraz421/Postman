## Сделать
- В шаге «Логин» появляется выбор «Войти как пользователь Windows (без пароля)». Его видно, когда сервер — Exchange
  (EWS) и машина в домене. При этом выборе шаг «Пароль» пропускается, вход — `Auth::Basic { user, password: "" }`
  (как в T1-02а).
- Логин подставлять из Windows: UPN, через `GetUserNameExW(NameUserPrincipal)` в `sys/credentials.rs`. Его можно
  поправить вручную.
- У учётки в `Settings` хранить признак «вход Windows». При запуске пароль не спрашивать, в диспетчер учётных данных
  ничего не писать. В «Настройки → Аккаунты» показывать способ входа строкой «Учётная запись Windows».
- Отказ (T1-02а) показывать строкой в панели входа и предлагать войти с паролем. Без модальных окон.

## Приёмка
- Тесты: при выборе «Windows» уходит пустой пароль, пароль не сохраняется, при запуске его не спрашивают. UPN
  подставляется.
- Снимки `signin` (с выбором) и `settings-accounts` — dev-сборкой.
- Ручная: на машине в домене учётка Exchange добавляется без пароля, перезапуск не спрашивает пароль.
