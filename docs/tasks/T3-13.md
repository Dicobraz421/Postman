> Решение владельца 2026-11-12 (`docs/decisions/2026-11-12-tray-and-notifications.md`): трея в Windows-сборке нет,
> закрытие окна завершает процесс — уведомления о письмах «пропадают».

## Сделано
- pets#52: `gpui_windows::pets::tray` (значок, подсказка, меню, щелчок), `window::hide/show`, `toast::show_clickable`.
- `postman_core::prefs`: `General.on_close` (`Tray` по умолчанию / `Quit`), `General.tray_hint_shown`.
- `app-gpui/src/tray.rs`: значок на всё время работы (ресурс 1; с отметкой — ресурс 2, `res/postman-unread.ico`),
  подсказка — непрочитанные своих «Входящих»; щелчок — показать окно; меню «Открыть Postman», «Выход». События значка и
  уведомлений — каналом в задачу интерфейса. Значок не встал — окно закрывается, как раньше.
- Закрытие окна — спрятать или выйти по настройке; `--minimized` — сразу в трей; повторный запуск показывает
  спрятанное окно; первое сворачивание — уведомление Windows один раз.
- Щелчок по уведомлению о письмах — окно, «Входящие» и письмо (одно) или «Входящие» (несколько); напоминания задач и
  встреч — окно.
- «Настройки → Общие → Закрытие окна» (только Windows), тексты EN+RU.

## Не сделано
- Щелчок по уведомлению из центра уведомлений после перезапуска Postman (нужен COM-активатор).
- Щелчок по напоминанию не открывает саму задачу или встречу — только окно.
- macOS: без изменений (окно прячет система).

## Проверки
- Тесты: `on_close_defaults_to_tray_and_round_trips` (core), `tray_click_target_and_tip` (app-gpui).
- Ручная — `docs/manual-tests/T3-13.md` (MSI и portable): закрыть окно → значок есть, письмо пришло → уведомление,
  щелчок → письмо открыто; «Выход» из меню; автозапуск в трей; настройка «Выйти».
