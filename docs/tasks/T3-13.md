> Решение владельца 2026-11-12 (`docs/decisions/2026-11-12-tray-and-notifications.md`): трея в Windows-сборке нет,
> закрытие окна завершает процесс — уведомления о письмах «пропадают».

## Порядок
1. **pets** (свой PR в pets, запись в его `docs/decisions.md`): `gpui_windows::pets::tray` — значок (ресурс exe или
   файл), подсказка, отметка, события «щелчок» и пункт меню; `pets::window` — спрятать и показать окно (с кнопкой на
   панели задач); `pets::toast` — метка уведомления и событие щелчка по нему, пока процесс жив.
2. **deps:** новый `rev` pets в `Cargo.toml`.
3. **Postman:**
   - `crates/core/src/prefs.rs`: `General.on_close` (`Tray` по умолчанию / `Quit`), `General.tray_hint_shown`.
   - `app-gpui/src/tray.rs`: значок на всё время работы; подсказка и отметка — по числу непрочитанных «Входящих»;
     щелчок — показать окно; меню «Открыть Postman», «Выход».
   - `main.rs`: закрытие окна — спрятать или выйти по настройке; `--minimized` — сразу в трей; повторный запуск
     показывает спрятанное окно; первое сворачивание — уведомление Windows один раз.
   - `newmail.rs`, `screens.rs`: спрятанное окно — «не активно»; щелчок по уведомлению — окно и письмо (одно) или
     «Входящие» (несколько); напоминание задачи — задача.
   - «Настройки → Общие»: строка «Закрытие окна», тексты — Fluent, EN+RU.

## Проверки
- Тесты: настройка по умолчанию и чтение старого файла настроек; текст подсказки значка; куда ведёт щелчок по
  уведомлению (одно письмо / несколько).
- Ручная — `docs/manual-tests/T3-13.md` (MSI и portable): закрыть окно → значок есть, письмо пришло → уведомление,
  щелчок → письмо открыто; «Выход» из меню; автозапуск в трей; настройка «Выйти».
