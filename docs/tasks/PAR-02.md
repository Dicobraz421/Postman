## Цель
Закрыть строки №18, 25–35 аудита `PAR-AUDIT` по договору ADR 0011: одно правило отказа, один уровень и язык журнала,
одни пределы и одни причины для пользователя на всех ОС. Класс B — согласие владельца в чате (решение 2026-10-26).

## Сделано (ветка `x/par-02`)
- №28: коды ключей Windows — одна таблица `keys::windows_fault` для CNG и CryptoAPI; неверный PIN/пароль
  (`NTE_INCORRECT_PASSWORD`, `SCARD_W_WRONG_CHV`) → `NeedPin`, как `errSecAuthFailed` macOS. Тест-таблица на любой ОС.
- №29: предел проверки отзыва — `crl::BUDGET` (8 с) везде: Windows `dwUrlRetrievalTimeout`, macOS — оценка с сетью
  в потоке с тем же пределом (первая оценка — без сети), Linux — как было.
- №30: macOS `errSecInvalidSignature`/`errSecVerifyFailed` → `BadSignature`; «ещё не действует» → `Expired` на обеих
  (у Windows один флаг на оба случая). Тест-таблица кодов.
- №31: цепочка своего сертификата при подписи на Windows — `CERT_CHAIN_CACHE_ONLY_URL_RETRIEVAL | CERT_CHAIN_DISABLE_AIA`,
  без сети, как macOS.
- №32: свои сертификаты — только с закрытым ключом (Windows `CERT_KEY_PROV_INFO_PROP_ID`); «другие люди» — общий отбор
  `smime::others`: с адресом, без своих, ≤ `OTHERS_MAX` (1000). Тест.
- №33: macOS и прочие — без загрузчика CRL (`CRL_DOWNLOAD`): ГОСТ без СКЗИ — `NotCheckedGost` без сети и без WARN.
- №34: тексты ошибок S/MIME Windows и `Unsupported` — по-английски; «ключ не подошёл» — DEBUG на всех ОС.
- №25: все вызовы Связки ключей — под одним замком процесса (вложенные вызовы потока — без повторного замка).
- №26: промежуточные для воркера на macOS — сертификаты Связки ключей без адреса (не корни, не запреты, не свои).
- №27: доверие корней macOS — настройки доверия для S/MIME (без политики или «SMIME»), не TLS.
- №18: LDAP macOS — в тексте ошибки только коды GSS; полный текст — DEBUG (как EWS); сообщения о билете — DEBUG.
- №35: поиск контроллера домена — `sys::bounded`, один предел `DC_TIMEOUT` (5 с) на трёх ОС; события — DEBUG.

## Решения для владельца
1. №26, Linux: системного хранилища промежуточных нет. Предложение (класс B, полоса core): общий для всех ОС кэш
   промежуточных из уже проверенных писем — тогда письмо без промежуточных одинаково на трёх ОС.
2. №30: «ещё не действует» показывается как «истёк» на Windows и macOS (у CryptoAPI один флаг). Отдельная причина —
   новый ключ Fluent в `app-gpui` (другая полоса) и разбор срока в общем коде.
3. №25: замок сериализует и окна PIN — второй запрос ждёт, пока пользователь введёт PIN в первом. Согласиться или
   держать замок только на «молча».
