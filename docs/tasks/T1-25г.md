> Решение владельца 2026-10-28 (`docs/decisions/2026-10-28-exchange-directory-search.md`): справочник Exchange — поиск
> с подсказкой. Без строки — пустой справочник и поле «Найти в справочнике»; найденное — списком с подгрузкой по
> прокрутке; весь справочник не читается. Плагин EWS отвечает на `DirectoryPage` пустой страницей `search_only`
> (T1-25в). Страницы у поиска — `Command::FindPeople { text, offset }` → `Event::PeopleFound { offset, people, more }`
> (договор ядра, `x/people-search-paging`, одобрено владельцем 2026-10-28): найденное — первая страница (`offset: 0`),
> прокрутка к концу при `more` — следующая (`offset` = сколько уже показано), один раз на страницу; у EWS и JMAP —
> по 20.

## Сделать
- «Справочник компании»: при открытии — первая страница (`DirectoryPage` 0); прокрутка к концу — следующая. Счётчик —
  из `total`, если он есть. При `search_only` — строка «Справочник доступен поиском» и поле поиска (`FindPeople`), как
  сейчас.
- «Мои контакты» у Exchange (`Feature::Contacts`) — список, правка и удаление, как у JMAP.
- Подгрузка — не блокирует UI; повторный запрос той же страницы не уходит.

## Приёмка
- Тесты: прокрутка к концу запрашивает следующую страницу один раз; `search_only` показывает строку поиска.
- Снимки `contacts` и `features-exchange` (демо-учётка Exchange с личными контактами и справочником).
- Ручная (Exchange, тестовая учётка): справочник листается, свой контакт создаётся и виден в Outlook.
