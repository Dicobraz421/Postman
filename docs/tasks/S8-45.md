Чтобы внешние могли смотреть мою занятость (S8-42) или подписаться на календарь (S8-44), нужна ссылка без входа. Stalwart
такого не умеет, Stalwart не правим — делать в The Post.

## Сделать
- Сервер (карточка в `Dicobraz421/ThePost`): адрес с секретным токеном, `.ics` и VFREEBUSY, уровень «занятость / подробности»,
  смена и отзыв токена. Утечка ссылки равна утечке данных её уровня.
- Postman: в «Доступ к календарю» — включить, уровень, скопировать, сменить, выключить; сервер без этой возможности —
  строки нет.

## Приёмка
- Ссылка открывается без входа в Outlook и в Postman (S8-42, S8-44); после смены старая не работает.
