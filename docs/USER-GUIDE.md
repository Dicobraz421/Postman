# Postman — инструкция пользователя

Postman — почта, календарь и контакты для Windows 10/11: сервер Stalwart (JMAP), любой сервер IMAP + SMTP с CalDAV и
CardDAV, Exchange on-prem (EWS) — раздел «Учётные записи». Раскладка и клавиши — как в classic Outlook: папки слева,
список писем, письмо справа.

## Установка

1. Распакуйте архив `Postman-<версия>-windows-x64.zip` в любую папку.
2. В этой папке откройте PowerShell и выполните:
   `powershell -ExecutionPolicy Bypass -File .\install.ps1`
3. Postman появится в меню «Пуск». Права администратора не нужны.

Обновление — так же (закройте Postman перед ним). Удаление — `install.ps1 -Uninstall` из папки установки
(`%LOCALAPPDATA%\Programs\Postman`); подробности — `README.txt` в архиве.

## Первый вход

При первом запуске Postman предлагает добавить аккаунт прямо в окне, в три шага: адрес сервера (его даёт
администратор), логин (обычно — адрес почты) и пароль, затем «Проверить и подключить». Пароль — либо в «Диспетчере
учётных данных» Windows, либо нигде («Не хранить — спрашивать при запуске»); на диск Postman его не пишет. Там же
можно сразу выбрать тему и плотность. Если пароль сменился, Postman снова попросит его — адрес и логин уже заполнены.

Postman открывается в одном экземпляре: повторный запуск выводит уже открытое окно вперёд.

## Учётные записи

Вид сервера Postman определяет по адресу, который вы вводите при входе («Адрес сервера»); логин — обычно адрес почты,
пароль хранится в «Диспетчере учётных данных» Windows или нигде. Соединение — TLS 1.2 или 1.3, сертификат сервера и
его отзыв проверяет Windows. Чего у сервера нет, того нет и на экране: раздел, кнопка и команда палитры скрыты,
клавиша такой команды показывает «Нет у сервера этой учётной записи».

| | Stalwart (JMAP) | IMAP + SMTP + CalDAV/CardDAV | Exchange (EWS) |
|---|---|---|---|
| Адрес сервера | узел почты: `mail.example.com` (Postman найдёт JMAP сам, `/.well-known/jmap`) | `imaps://imap.example.com` — TLS (IMAP 993, SMTP 465); `imap://…` — STARTTLS (143, SMTP 587). SMTP на другом узле — `?smtp=smtp.example.com[:порт]`; календарь и контакты — CalDAV и CardDAV того же узла, если они там есть, иначе `&dav=https://dav.example.com` | домен почты (`example.com`) или адрес EWS `https://mail.example.com/EWS/Exchange.asmx` |
| Логин | адрес почты | как у сервера IMAP (обычно адрес почты) | адрес почты (тогда точный адрес EWS Postman найдёт через Autodiscover); `ДОМЕН\логин` — только с полным адресом EWS |
| Вход | пароль | пароль | пароль учётной записи домена (Negotiate: Kerberos или NTLM через Windows); Basic и OAuth — нет |
| Почта, беседы, поиск, вложения | да | да (беседы собирает Postman) | да; поиск — по папкам на сервере |
| Метки, категории, сроки, «Ждём», «Напомнит» | да | если сервер хранит свои ключевые слова писем | нет (только «прочитано» и флаг) |
| «Отменить» отправку / «Отправить позже» | да / да (держит сервер) | 10 с держит Postman / нет | 10 с держит Postman / нет |
| Календарь, встречи, ответы на приглашения | да | да (CalDAV, приглашения рассылает сервер) | да: неделя, новая встреча, правка и отмена своей, ответы |
| Занятость, «Помощник планирования» | да | да (free/busy, RFC 6638) | да |
| Задачи и поручения | да | да (задачи CalDAV) | нет |
| Контакты / справочник компании | да / да | личные (CardDAV) / нет | нет / да (поиск от 3 букв, подсказки адресов) |
| Правила, автоответ, место в ящике, общие ящики | да | нет | нет |
| Новые письма | сразу (push) | «Входящие» — сразу (IDLE), остальные папки — опросом | опрос раз в 2 минуты; «снова на связи» — сразу |

Ограничения:

- **IMAP + SMTP.** Правил и автоответа нет (ManageSieve не поддерживается), входа через OAuth2 и общих папок IMAP —
  тоже. Календари коллег по CalDAV не показываются; занятость коллеги видна, только если он её открыл.
- **Exchange** — только свой сервер компании (Exchange 2013 и новее, on-prem); Exchange Online (Microsoft 365) не
  поддерживается. Задач, личных контактов, правил Outlook, автоответа, категорий Outlook, общих ящиков и делегатов
  нет. Почта Exchange идёт по EWS — IMAP и SMTP на сервере не нужны.
- **Несколько учётных записей** — «Настройки → Аккаунты → Добавить аккаунт»: каждая — группой в дереве папок, поле
  «От» письма и встречи выбирает учётную запись, календари всех учётных записей — в одном календаре, поиск «Все папки»
  — по всем. Контакты, задачи, правила и автоответ — у первой (основной) учётной записи.

## Окно

Всё — в одном окне, отдельных окон и модальных диалогов нет.

- **Вкладки** — в заголовке окна: «Почта» (не закрывается), новые письма, встречи и «Настройки». Ctrl+Tab /
  Ctrl+Shift+Tab — между ними, Ctrl+W или «×» — закрыть; точка на вкладке — есть несохранённое. Ctrl+T — ещё вкладка
  почты на той же папке и фильтрах (например, «Все папки» с фильтром рядом с «Входящими»): дальше у неё свои папка,
  фильтры и выбранное письмо, название — открытая папка.
- **Командная строка** — под заголовком: «Новое письмо», «Ответить», «Ответить всем», «Переслать», «Удалить»,
  «Флаг», «…» (автоответы, правила, все настройки, Вид → Быстрые фильтры) и поле поиска (Ctrl+E) с переключателем «Везде | Текущая папка». В
  календаре и контактах — свои команды.
- **Рейл** — значки слева: Почта (Ctrl+1), Календарь (Ctrl+2), Контакты (Ctrl+3); внизу — шестерёнка настроек.
- **Строка состояния** — внизу: число писем, связь и синхронизация, место в ящике на сервере, песочница, 🔔 —
  история уведомлений.
- **Тема** — светлая или тёмная, как в Windows (или своя в настройках), плотность строк — там же.
- **Палитра команд** — Ctrl+K в любой вкладке (раздел «Почта» ниже).

## Почта

- **Список.** Новые письма отмечены синей полосой слева и жирным отправителем. Листание — колесом, полосой
  прокрутки или клавишами; более старые письма подгружаются сами. Внизу — «Элементов: N из M».
- **Чтение.** Письмо открывается справа, при первом открытии помечается прочитанным. Письма разбираются в
  изолированном процессе (песочнице): внизу видно «Песочница: полная». Внешние картинки не загружаются —
  это защищает от слежки; картинки, вложенные в само письмо, видны сразу.
- **Вложения** — лентой под шапкой письма: «Вложения · N · размер», «Сохранить все…», у каждого файла — «Просмотр»,
  «Открыть», «Сохранить как…». Просмотр — на месте текста письма, без внешних программ: картинки (и BMP, ICO, TIFF), PDF (страницы
  листаются), текст, документы (Word, OpenDocument, RTF, Markdown), книги Excel и таблицы (листы — вкладками,
  первая строка закреплена), презентации (слайды — ‹ › и ← / →), письма во вложении (.eml, .msg — шапка, текст и свои
  вложения; вложенное письмо — глубже, Esc — назад), оглавление архива (с предупреждением об опасных файлах и zip-бомбах); ← / → — по вложениям,
  Esc — закрыть. Всё разбирается в песочнице. Документ Office с макросами помечен «Содержит макросы · открытие
  заблокировано», исполняемые файлы и скрипты можно только сохранить. Сохранённый файл помечается как полученный из
  Интернета (Windows спросит при открытии).
- **Приглашения на встречу** — карточкой в письме: когда, где, организатор, сколько приняли. «Принять», «Под
  вопросом», «Отклонить» (в схеме «Одиночные клавиши» — A, T, N) — ответ уходит организатору, встреча ложится в календарь. Справа —
  «Ваш день»: ваши встречи вокруг этой и пересечения с ней. Если организатор перенёс встречу или сменил место,
  карточка покажет, что изменилось (прежнее — зачёркнуто), и попросит ответить заново; отменённая, прошедшая или
  устаревшая (есть более новая версия) — короткой строкой без кнопок.
- **Беседы** — письма одной цепочки (и ваши ответы из «Отправленных») вместе. Вид — Настройки → Чтение или правой
  кнопкой по папке → «Вид беседы» (свой у папки): **лента** — «Беседа (N)» над письмом, только новый текст каждого
  письма; **стопка** — письма карточками, прочитанные свёрнуты строкой, последнее раскрыто (щелчок или Enter —
  раскрыть, «показать цитату» — история письма, «Развернуть все»); **как Outlook** — в списке строка на беседу со
  стрелкой и числом писем: щелчок по стрелке, → и ← — развернуть и свернуть, Enter — то же; флажок у строки беседы
  выбирает все её письма. Ctrl+→ / Ctrl+← — по письмам беседы в любом виде.
- **Флаг и прочитанность** — флаг кнопкой «Флаг» (панель выделения, контекстное меню), прочитанность — Ctrl+Q,
  Ctrl+U. **Удаление** — Delete: письмо уходит в «Удалённые»;
  в «Удалённых» Delete удаляет насовсем после подтверждения строкой.
- **Поиск** — Ctrl+E и слова: результаты появляются по мере набора. Справа в поле — «Везде» (все папки, результаты
  группами по папкам) или «Текущая папка». Совпадения подсвечены в списке и в открытом письме; над текстом письма —
  «Совпадение k из N»: F3 / Shift+F3 (или ↑ / ↓ рядом) — к следующему и предыдущему, текущее выделено плотнее и
  прокручивается в вид. Чипы «Уточнить» под строкой результатов сужают поиск: отправитель, «мне», вложения, непрочитанные,
  за 7 или 30 дней, категория. Условия можно писать и руками: `from:петров`, `to:me`, `subject:счёт`,
  `has:attachment`, `is:unread`, `is:flagged`, `after:30d`, `before:2026-10-01`, `category:Клиенты` (и по-русски:
  `от:`, `кому:`, `тема:`, `есть:вложения`, `после:`, `до:`, `категория:`); значение с пробелами — в кавычках.
  Без сети поиск идёт по своему индексу; с сервером «Везде» находит и письма, которых ещё нет на компьютере.
  Esc — вернуться к папке.
- **Палитра команд** — Ctrl+K в любой вкладке: команды (с клавишами), папки всех ящиков, быстрые фильтры и письма по
  набранным словам. Набирать можно с опечатками, начала слов и в другой раскладке (`fh[` — «арх»); ↑/↓ — выбрать,
  Enter — выполнить, Esc — закрыть. Недавние команды и папки — первыми.
- **Фильтры** — воронка у открытой папки (или палитра команд): слева вместо папок — фильтры. «Где искать» — эта
  папка или все папки (результаты — группами по папкам). Непрочитанные, упоминания (`@Имя` в тексте), вложения,
  флаг, внешние отправители (не из вашего домена), категории; число у фильтра — сколько писем останется, если
  его включить. Над списком — чип включённых фильтров (× — сбросить), «N из M» и сортировка (по дате,
  отправителю, размеру). Письма папки сгруппированы по датам; группу можно свернуть щелчком по заголовку.
- **Быстрые фильтры** — закладки внизу списка: Угрозы, Срок, Ждём, Мне (вы в «Кому»), Истекают. Несколько
  закладок — письма любой из них; вместе с фильтрами слева — только подходящие под те и другие. Наведите на
  закладки — панель с числами. «×» справа скрывает закладки, вернуть — «…» → Вид → Быстрые фильтры. Какие закладки и в
  каком порядке — Настройки → Быстрые фильтры.
- **Сроки и напоминания** — кнопки в шапке письма (или команды): «Срок» (Insert) — сегодня, завтра, в пятницу,
  на следующей неделе или своя дата; в списке — «До пт» янтарным, прошедший срок — «Просрочено 1 д» на янтарной
  подложке, такие письма — наверху, в группе «Срочное». «Напомнить» — письмо уходит в «Архив» и в назначенное время
  возвращается во «Входящие» непрочитанным, наверх, с карточкой «Напоминание · Открыть». «Ждать ответа» (и в новом
  письме) — пришёл ответ в той же беседе — метка снимается; нет ответа в срок — письмо снова во «Входящих». «Исчезнет» —
  в срок письмо уходит в «Удалённые» (или в «Архив», Настройки → Быстрые фильтры и сроки); письма с кодами
  подтверждения исчезают сами через 24 часа, рассылки можно отправлять в архив через N дней. Всё это работает, пока
  Postman запущен; закрытый Postman доделает пропущенное при следующем запуске.
- **Несколько писем сразу** — наведите на строку: на месте аватара появится флажок. Ctrl+щелчок добавляет письмо,
  Shift+щелчок и Shift+↑/↓ — диапазон, Ctrl+A — все, Esc — снять. Над списком — панель: «Прочитано», «Флаг»,
  «Категория», «Срок», «В папку», «Архив», «Удалить»; справа — сводка выбранного. Клавиши (Ctrl+Q, Insert, 1–9,
  Delete…) тоже действуют на всё выбранное. После действия — тост «Отменить».
- **Контекстное меню** — правой кнопкой по письму (или Shift+F10, клавиша «Меню»): ответ, прочитано, флаг,
  категория, сроки, «Переместить» (Ctrl+Shift+V), «Архив» (Backspace), «Удалить». Стрелки и Enter — по пунктам.
- **Сообщить о фишинге** — пункт с красной маской: письмо уходит в «Нежелательные» с меткой угрозы (закладка
  «Угрозы»). Если в Настройки → Общие → «Сообщения о фишинге» указан адрес (например, службы безопасности), туда
  уходит и само письмо вложением.
- **Нет связи** — внизу «Нет связи · повтор через N с», у вашего ящика метка «нет связи», над списком полоса с
  «Повторить сейчас». Письма видны из локальной копии; отметки, перемещения и удаления, сделанные без связи, уйдут
  на сервер, когда она вернётся (письма отправить нельзя — Postman скажет об этом в письме).

## Перенос и «На этом компьютере»

- **«На этом компьютере»** — последняя группа в панели папок: письма, которые хранятся только в базе Postman на этом
  компьютере, без сервера. Правой кнопкой по группе — «Новая папка»; по своей папке — «Переименовать» (F2),
  «Удалить» (только пустую), «Экспорт…».
- **Перенос между учётками** — перетащите выделенные письма на папку другой учётки или «На этом компьютере», или
  «В папку ▾» (там папки всех учёток). Письма появляются в папке сразу, со значком «ждёт переноса», и уходят на
  сервер в фоне; в строке состояния — «Перенос: N из M · размер», щелчок — «Пауза», «Остановить».
- **Вопрос после переноса** — над списком папки: «Перенести на сервер «…»» или «Оставить локальным архивом». Перенос в
  «На этом компьютере» вопроса не задаёт. У исходной учётки письмо удаляется только после ответа сервера-цели.
- **Нет места на сервере** — перенос встаёт на паузу: «Продолжить» или «Оставить локально». «Остановить» — оставить
  остальные локально или вернуть на место. Письмо больше предела сервера остаётся на этом компьютере (тост с
  «Показать»).
- **Обновление хранилища** — один раз после обновления Postman вместо списка видно «Обновление хранилища: N %»;
  письма на сервере при этом не меняются, прежние файлы сохраняются рядом (`*.v5.bak`).

## Экспорт

«Экспорт…» — в меню писем, папки и «На этом компьютере»; «Экспорт учётки…» — у заголовка учётки; в Ctrl+K —
«Экспорт…» и «Экспорт всего…». Над списком — формат (EML — по письму в файле; mbox — для Thunderbird и Apple Mail;
Maildir; MSG — для Outlook), «С подпапками», «Выбрать папку и начать…». Ход — в строке состояния, «Остановить» —
готовые файлы остаются. В конце — тост «Экспортировано N писем · Открыть папку». Письма, которых ещё нет на
компьютере, Postman сначала загрузит с сервера.

## Общие ящики

Ящики, к которым вам дали доступ (общий ящик отдела, делегированный ящик руководителя), — отдельными ветками в
дереве папок, их можно свернуть. Ветка с подписью «только чтение» — письма можно читать, но не удалять и не
помечать. В новом письме поле «От» позволяет отправить от имени общего ящика (если сервер это разрешает); ответ на
письмо из общего ящика по умолчанию уходит от его имени, копия — в «Отправленные» этого ящика. Если сменить «От» на
свой адрес, под текстом ответа появится предупреждение: коллеги такой ответ не увидят.

Чтобы коллеги не ответили на письмо параллельно, возьмите его в работу: Ctrl+J или «Взять в работу» в командной
строке и в шапке письма. Коллеги увидят «Взято в работу: ваше имя · время», в списке — метку «Назначено: …»; у себя —
«Назначено: вы». Письмо, взятое коллегой, можно «Забрать себе», своё — «Вернуть в очередь». Сразу после действия в
сообщении справа сверху есть «Отменить». В ящике, открытом только для чтения, взять письмо нельзя.

## Конфиденциальные письма

Метка «Конфиденциально» шифрует письмо S/MIME сертификатами получателей и вашим (копия в «Отправленных» тоже
читается). Сертификаты адресатов Postman берёт из их подписанных писем и из хранилища Windows «Другие пользователи»;
у адресата с сертификатом в поле — замок. Если у кого-то сертификата нет, «Перед отправкой» скажет об этом красным:
уберите этих адресатов или снимите «Конфиденциально» (письмо уйдёт без шифрования — это нужно подтвердить). Если у
одних адресатов сертификаты ГОСТ, а у других — RSA, уйдут два письма; оба будут в «Отправленных». Письма по ГОСТ
шифрует только сертифицированное СКЗИ. Черновик с этой меткой хранится на сервере зашифрованным для вас.

## Подпись писем

Если в хранилище сертификатов Windows есть ваш сертификат для подписи почты, новое письмо подписывается S/MIME:
кнопка «Подписать» в строке над текстом включена (выключить — в письме; совсем — «Подписывать все письма» в
настройках «Безопасность»). Если ключ на смарт-карте и нужен PIN или карта не вставлена, письмо не уходит — во вкладке
появится строка с причиной. Сертификат ГОСТ подписывает только сертифицированное СКЗИ (КриптоПро CSP или ViPNet CSP).

## Зашифрованные письма

Письмо, зашифрованное S/MIME, в списке отмечено замком и подписью «Зашифрованное письмо» — сервер его текста не
видит. При открытии Postman расшифровывает его ключом из хранилища сертификатов Windows: в шапке — «Зашифровано»
(и «Подписано», если внутри подпись). Если ключ на смарт-карте, появится строка «Нужен PIN смарт-карты · Ввести»: окно
PIN — системное. Письмо, зашифрованное не для вас, и повреждённое письмо не открываются — строка говорит почему.
Расшифрованный текст и вложения не сохраняются на диск сами: вложение можно просмотреть или сохранить («Сохранить
как»), поиск по тексту таких писем не работает (как в Outlook). Письма, зашифрованные по ГОСТ, открываются только при установленном сертифицированном
СКЗИ (КриптоПро CSP или ViPNet CSP); без него Postman так и пишет — «нужно СКЗИ».

## Письмо

- **Новое** — Ctrl+N или «Новое письмо»: письмо открывается вкладкой в заголовке окна (название — тема, точка —
  есть несохранённое). Несколько черновиков — несколько вкладок; Ctrl+Tab — между ними и почтой.
- **Ответ** — Ctrl+R, **всем** — Ctrl+Shift+R, **переслать** — Ctrl+F (вложения оригинала идут с письмом): ответ
  открывается в области чтения над письмом. «Развернуть» переносит его во вкладку с тем же текстом; открыли другое
  письмо — ответ с текстом уходит во вкладку сам.
- **Адреса** — начните вводить имя или адрес: подсказки из контактов, справочника сотрудников и переписки. Готовый
  адрес становится чипом («;», «,» или Enter); Backspace в пустом поле возвращает последний чип для правки. Адрес
  вне своего домена помечен «Внешний», нераспознанный — красной рамкой. «Копия» и «Скрытая» — ссылками справа.
- **Текст** — с разметкой Markdown, оформленной прямо при вводе: заголовки и **жирный** — жирным, *курсив* —
  курсивом, ссылки — акцентом с подчёркиванием, цитата — серым, маркеры списков — акцентом; знаки разметки (`**`,
  `#`, `>`, `[…](…)`) видны приглушённо. Кнопки «Ж», «К», «Ч» (Ctrl+B, Ctrl+I, Ctrl+U), списки, ссылка и цитата
  вставляют разметку у курсора. Получатель увидит оформленное письмо (и простой текст для почтовиков без HTML).
  «Подпись» — сменить подпись, «Шаблон» — пока пусто.
- **Метка «Конфиденциально»** — ставится на письмо (шифрования пока нет). **«Ждать ответа · N дней»** — письмо
  запомнит срок ответа; **категория** — цветом, как в списке.
- **Вложения** — «Вложить» или перетащите файлы в письмо.
- **Перед отправкой** (справа во вкладке, под текстом в ответе) — номер карты или пароль в тексте (отправка
  остановлена, пока не «Замаскировать» или «Это не карта»), упомянутое, но не вложенное вложение, внешние адресаты
  при «Конфиденциально», адресат, который последний раз писал с другого адреса («Заменить адрес»).
- **Отправка** — Ctrl+Enter; «▾» у «Отправить» — отправить позже. Черновик сохраняется сам; закрытие
  (Ctrl+W, Esc) с изменениями спросит строкой «Сохранить черновик? Да / Нет / Отмена»; корзина внизу — удалить
  черновик.

## Календарь

- **Неделя** — Ctrl+2. PgUp / PgDn — предыдущая и следующая неделя, Home — сегодня; слева — месяц (щелчок по
  дню — его неделя). Цвет встречи — её категория (как у писем); пунктир — приглашение ждёт ответа, штрих слева —
  «под вопросом», отклонённые не показываются. Линия — текущее время.
- **Подробности** — щелчок по встрече: время, место, пересечения с другими встречами, участники и их ответы;
  «Принять», «Под вопросом», «Отклонить» и «Изменить ответ»; «Написать участникам».
- **Новая встреча** — Ctrl+Shift+Q или «Создать встречу»: вкладка в заголовке окна. Обязательные и
  необязательные участники (Enter или «;» после адреса), переговорная (если они есть в справочнике), место, время,
  описание. Ниже — подбор времени: занятость каждого на выбранный день, «Только общее свободное время» — зелёные
  окна, где свободны все (щелчок ставит встречу туда), длительность, «Учитывать необязательных». Ctrl+Enter —
  отправить приглашения, Esc — закрыть вкладку.
- **Занятость коллег** видна, только если коллега открыл вам свою: «Открыть мою занятость» слева в календаре —
  введите адрес коллеги. Без этого у участника — «нет данных» (это не значит «свободен»).

## Контакты

Ctrl+3 — «Часто пишу», «Справочник компании» и «Мои контакты» слева, список по алфавиту с указателем букв, поиск
(Ctrl+E) в строке команд — сразу по всем трём, группами, и в другой раскладке или латиницей («ivanova»). «Часто
пишу» — с кем вы переписывались за 30 дней, чаще и недавно — выше; сотрудник и личный контакт открываются своей
карточкой. Карточка: «Написать», «Встреча» (вкладка новой встречи с этим участником), «Копировать адрес»,
адреса, телефоны, организация, у сотрудников и переговорных — занятость на сегодня. Личный контакт — «Новый
контакт» (Ctrl+Shift+C), «Изменить» (F2, форма на месте карточки), «Удалить» (Delete, после «Да»); справочник
только читается, «Добавить в мои контакты» делает личную копию.

## Настройки

Настройки открываются вкладкой: шестерёнка внизу слева, Ctrl+, или «…» → «Все настройки». Слева — разделы и поиск
по ним («тема», «пароль», «клавиши»). Изменения действуют сразу; Esc или Ctrl+W закрывают вкладку.

- **Общие** — язык, запуск вместе с Windows (окно свёрнутым), что открыть при запуске, Postman — почтовый клиент по
  умолчанию (ссылки `mailto:` откроют новое письмо; Windows попросит подтвердить), уведомления и тихие часы, версия и
  «Проверить» (страница сборок в браузере — сам Postman в сеть не ходит), уровень журнала, папка журнала и отчёт для
  поддержки (архив на рабочем столе: журнал за неделю, версия, настройки без паролей и адресов).
- **Безопасность** — внешние картинки («Никогда» или «Спрашивать»), предупреждение о подменённых ссылках, файлы с
  макросами (не открываются никогда; сохранять ли), состояние песочницы разбора писем и как включить полную, адрес
  службы ИБ для «Сообщить о фишинге», пароль (в Диспетчере учётных данных Windows или не хранить), TLS 1.2 или 1.3,
  проверка отзыва (всегда; проверяет Windows: отозванный сертификат сервера — отказ в соединении, сервер отзыва
  недоступен — соединение не прерывается), «Сбросить сохранённые входы». Первая строка — шифрование диска с базой: не зашифрован BitLocker — предупреждение и
  «Параметры BitLocker» (письма «На этом компьютере» хранятся только здесь), зашифрован — галочка. Выбрать можно только строже; если значение задаёт
  организация, выбор недоступен и это сказано рядом.
- **Внешний вид** — тема («Как в Windows», светлая, тёмная, высокая контрастность; если её задаёт организация, выбор
  недоступен), акцент (синий, бирюзовый, зелёный, фиолетовый, графит), плотность (компактная или обычная), размер
  шрифта (12–18), аватары и превью в списке, анимации, KeyTips — удержите Ctrl, и
  над кнопками появятся их клавиши (выключатель и задержка). Клавиша кнопки видна и в подсказке при наведении:
  «Ответить (Ctrl+R)».
- **Аккаунты** — учётные записи, общие ящики, где хранится пароль, безопасность подключения; добавить и удалить
  аккаунт. Учётных записей может быть несколько (раздел «Учётные записи»).
- **Категории** — имя, цвет и клавиша 1–9. Цвета, похожие на занятые, перечёркнуты; красный и янтарный заняты
  угрозами и сроками. Удалённая категория остаётся у писем — снять её с писем можно отдельно («Снять с писем»).
  Таблица хранится на сервере и общая для всех ваших устройств.
- **Быстрые фильтры и сроки** — какие закладки показывать и в каком порядке; через сколько дней вернуть письмо без
  ответа, убрать рассылки в архив, удалить коды подтверждения. Сроки работают, пока Postman запущен.
- **Чтение** — вид бесед (лента, стопка, как в Outlook; можно своё для папки), где панель чтения (справа, снизу,
  скрыта), предупреждение о ссылках с подменённым адресом. Картинки из интернета Postman не загружает никогда.
- **Просмотр вложений** — встроенные форматы (справка) и модули просмотра: файл `.wasm` с описанием `.json` в папке
  модулей (`%LOCALAPPDATA%\Postman\viewers`, «Открыть папку модулей»). У модуля — имя, версия, форматы и выключатель;
  сторонний модуль помечен «сторонний» и работает в песочнице, видит только открытый файл. В шапке просмотра — «Просмотр:
  модуль «…»».
- **Подписи и шаблоны** — несколько подписей, какая ставится в новые письма и в ответы, шаблоны писем. Хранятся на
  этом компьютере.
- **Клавиатура** — схема («Outlook» или «Одиночные клавиши»), все команды и их клавиши обеих схем, поиск по названию
  или сочетанию. «Изменить» — нажмите новое сочетание (Esc — отмена) — оно ляжет в столбец выбранной схемы; занятое
  другой командой — «Заменить» или «Оставить оба» (конфликт будет виден). «Сбросить» — у команды и всех.
- **Правила** — что делать с новыми письмами: если отправитель, тема или получатель содержат слово — переложить в
  папку, пометить, удалить или переслать. Правила хранятся на сервере и работают, даже когда Postman закрыт.
- **Автоответы** — «Нет на месте»: включить, период, тема и текст. Пока автоответ включён, вверху окна полоса
  «Автоответ включён… Выключить». Автоответ и правила работают вместе.

Пока только запоминают выбор (его подхватят следующие версии): предупреждение о ссылках с подменённым адресом и
шаблоны (меню «Шаблон» в письме пока пустое). Остальное действует сразу: тема, плотность, язык, категории, клавиши,
быстрые фильтры и сроки, место панели чтения, вид бесед (общий и свой у папки), подписи (письмо берёт подпись по
умолчанию, меню «Подпись» — все), аккаунты, правила и автоответы.

## Уведомления

Сообщения появляются справа сверху и исчезают сами (справа внизу у сообщения — сколько секунд осталось); ошибки
держатся дольше, сообщения с «Отменить» — 15 секунд. Видно не больше трёх, остальные — кнопкой «+N ещё». История —
значок 🔔 в строке состояния: панель справа, фильтр «Все / Ошибки / Действия»; «Отменить» работает и оттуда.
Модальных окон в Postman нет: вопросы задаются строкой в самом окне.

## Язык

Язык интерфейса — как у Windows (русский или английский) или свой: «Настройки → Общие».

## Если что-то не так

- Нет связи с сервером — строка состояния и полоса над списком (раздел «Почта», «Нет связи»); Postman работает с
  уже загруженными письмами и сам повторяет подключение.
- Ошибки запуска и сбои пишутся в журнал Windows «Приложение» (источник «Postman»).
- Выйти из учётной записи (удалить сохранённый вход): «Настройки → Аккаунты → Удалить» или `postman.exe --sign-out`.

## Клавиши

Схема «Outlook»: не больше одного модификатора. Ctrl + буква или цифра — команды; без модификатора — переходы и
действие над выбранным (стрелки, Enter, Esc, Delete, Insert, F2, F3, Home, End, PgUp/PgDn, Backspace, 1–9 —
категории); Alt не используется. Два модификатора — только привычные по Outlook: Ctrl+Shift+R, Ctrl+Shift+Q,
Ctrl+Shift+C, Ctrl+Shift+V, Ctrl+Shift+Tab. Свои
сочетания (Настройки → Клавиатура) — поверх схемы; прежние свои клавиши после обновления переносятся сами: снятые
сочетания (Alt+…, Ctrl+Shift+G, Ctrl+Shift+F, прежние J/K и A/T/N) уходят, своё на новой клавише остаётся своим.

Схема «Одиночные клавиши» (Настройки → Клавиатура → Схема, выключена по умолчанию) — ещё буквы без модификатора,
как в Gmail: J/K — следующее и предыдущее письмо, C — новое, R / A / F — ответить, всем, переслать, E — архив,
V — в папку, Q / U — прочитано и нет, `/` — поиск; над приглашением без ответа A / T / N — принять, под вопросом,
отклонить (там A — не «Ответить всем»). Буквы действуют, когда фокус в списке, а не в поле ввода; клавиши Outlook
работают и в этой схеме. У каждой схемы — свои сочетания: «Изменить» правит столбец выбранной схемы.
