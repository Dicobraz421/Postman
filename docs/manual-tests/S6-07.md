# S6-07. Повтор и напоминания

Статус: 🤖 частично (2026-11-06): шаги 1–3, 5 и тост шага 4 — сцены; шаги 1, 2 повторены на стенде; владельцу — 4 (уведомление Windows при свёрнутом окне); не покрыто — повтор шагов 3, 5 на стенде

Демо-ящик и живой ящик стенда.

1. Карточка → «Повтор»: варианты (каждый день, по будням, каждую неделю в день срока, каждый месяц, каждый год, через
   1 / 7 дней после выполнения, не повторяется); выбранное — в строке задачи («Каждый месяц»).
2. Выполнить повторяющуюся («Продлить лицензии», каждый месяц): тост «Выполнено · следующая — …», в «Сегодня» её нет,
   в «Предстоящих» — копия со сроком через месяц; выполненная — в «Выполненных» без повтора. «Отменить» — как было.
3. Задача со сроком 31-го и повтором «каждый месяц» — следующая 30-го (в месяце из 30 дней).
4. Напоминание «За 15 мин» у задачи со сроком через 16 минут: через минуту — тост «Напоминание: …» с «Отложить на 10
   мин»; «Отложить» — через 10 минут снова. Свернуть окно до срабатывания — уведомление Windows «Postman».
5. В вариантах напоминания первым — значение по умолчанию из «Настройки → Календарь».
