# S6-06. Карточка задачи

Статус: 🤖 (2026-11-06): шаги 1–3 — сцены и стенд, шаг 4 — стенд (поля VTODO запросом CalDAV вместо Thunderbird)

Демо-ящик и живой ящик стенда, обе темы.

1. Щелчок по «Напоминание», «Проект», «Категория» — варианты под полем; выбор — сразу в задаче и в строке списка.
   «Проект» — новый строкой (Enter). Insert — варианты срока.
2. «Добавить подзадачу»: Enter — подзадача внизу, поле готово для следующей; отметка подзадачи — сразу, прогресс
   «N/M» в строке задачи.
3. Заметки: `**жирный**`, `*курсив*`, списки `- …`, ссылки — оформляются при наборе, как в письме; знаки разметки
   приглушены. Переключить задачу и вернуться — текст сохранён.
4. Живой ящик: правка видна во втором Postman (push календаря) и в Thunderbird (поля VTODO).
