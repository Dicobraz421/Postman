# Ручная проверка: баги беты 0.1.0-beta.5 (исправлены в 0.1.0-beta.7)

Windows и macOS, демо-ящик или своя почта.

1. «Настройки → Чтение → Беседы»: по очереди выбрать «Лента без цитат», «Стопка в панели чтения», «В списке, как
   Outlook». Схема в карточке «Предпросмотр» меняется: письма подряд / свёрнутые строки над письмом / беседа деревом в
   списке. Подпись под схемой — выбранный вид.
2. Поставить категорию письму (появится тост). Пока тост на экране: правая кнопка по письму → «Вид беседы» → «Как
   Outlook» мышью — у бесед в списке появляются стрелки раскрытия; «По умолчанию» — пропадают. Окно уменьшить по
   высоте: пункты подменю «Вид беседы» не уходят за нижний край.
3. Открыть письмо, в шапке «+ категория»: у кнопки — только список категорий (без «Ответить», «Переслать»). Щелчок
   по категории — она у письма; ← или щелчок мимо — список закрыт.
4. Навести курсор на ссылку в письме: внизу панели — адрес. Увести курсор со ссылки на пустое место письма — адрес
   пропал. Навести и не двигать — адрес пропадает сам через 4 с. Щёлкнуть ссылку (открылся браузер) — по
   возвращении адреса нет.
