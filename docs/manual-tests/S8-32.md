# S8-32: «Экспорт…»

1. ПКМ по папке с подпапками → «Экспорт…»: над списком полоса «Экспорт «Учётка · Папка» · N писем», формат
   (впервые — EML), «С подпапками (N)»; «Отмена» и Esc закрывают полосу. То же у группы «На этом компьютере»,
   у локальной папки, у писем (контекстное меню и выделение), в палитре — «Экспорт…», «Экспорт учётки…»,
   «Экспорт всего…».
2. «Выбрать папку и начать…» → диалог Windows; отмена диалога — полоса остаётся.
3. mbox: в строке состояния «Экспорт: N из M»; щелчок — полоса «Экспорт в mbox · … · загрузка с сервера: K» с
   «Остановить». Конец — тост «Экспортировано N писем · mbox · каталог» с «Открыть папку».
   Импорт в Thunderbird (ImportExportTools NG) и Apple Mail — письма и подпапки на месте.
4. Maildir → mutt (`mutt -f <каталог>`) или Dovecot: письма читаются.
5. EML → открыть файл в Outlook. MSG и PST в списке нет, пока нет их писателя (S8-30, S8-33б).
6. «Остановить» посреди mbox: тост «Экспорт остановлен: записано N из M · Готовые файлы целы, недописанный удалён».
7. Учётка без связи: тост «Экспортировано N из M» и «K писем не загрузились с сервера «…»».
8. В следующий раз формат по умолчанию — прошлый выбор (на время работы Postman).
