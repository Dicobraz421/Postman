# T2-58. «Предпросмотр» и «По умолчанию»

Статус: ⏳ (вид — 🤖 снимки `settings-reading`, `settings-sign`, `settings-general`, `settings-security`,
`settings-look`)

1. В каждом из разделов Чтение, Подписи и шаблоны, Общие, Безопасность, Внешний вид — «По умолчанию» в заголовке и
   карточка «Предпросмотр» справа; предпросмотр меняется сразу вслед за настройкой.
2. Внешний вид: перетащить границу списка и чтения — «Сейчас справа, N %» меняется; панель «снизу» — «Сейчас снизу»;
   «Открыть „Чтение“» открывает раздел.
3. «По умолчанию» во Внешнем виде — тема «Как в Windows», плотность «Обычная», шрифт 14.
