# T2-41. Списки рассылки

Статус: ⏳ (вид — 🤖 снимок `contacts-lists`; живой сервер — владелец)

1. Сервер с группами (Stalwart — группа с адресом, Exchange — список рассылки): слева «Списки рассылки» с адресами.
2. Щелчок по списку — в средней колонке списки, справа карточка: «Написать», «Копировать адрес», тип «Список
   рассылки», строка «Состав списка сервер не сообщает…».
3. В окне письма адрес списка подсказывается при наборе его имени.
