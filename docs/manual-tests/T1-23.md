# T1-23. Контакты: контекстное меню строки списка

Статус: 🤖 частично (2026-11-06): шаги 1–4 — сцены, шаги 1–3 — стенд; не покрыто — повтор шага 4 на стенде; сцена `task-t123-menu` пишет демо-адрес в настоящий буфер Windows (находка F9)

Демо (`--demo`) и живой ящик.

1. Контакты (Ctrl+3) → «Справочник компании», выбрать одного сотрудника. Правой кнопкой по строке другого сотрудника:
   меню «Написать», «Встреча», «Копировать адрес» и после разделителя «Добавить в мои контакты»; карточка справа
   остаётся на выбранном сотруднике.
2. «Копировать адрес» в меню — тост с адресом строки под курсором, в буфере — её адрес; панель не переключилась.
   «Написать» — новое письмо этому адресату, «Встреча» — вкладка встречи с ним.
3. «Мои контакты», правой кнопкой по контакту: ещё «Изменить» (F2) и «Удалить» (Delete). «Изменить» — форма этого
   контакта справа; «Удалить» — строка «Удалить контакт? Да / Нет» в его карточке.
4. Выбрать строку стрелками, Shift+F10 (и клавиша «Меню»): меню у выбранной строки; ↑/↓, Home/End — по пунктам,
   Enter — выполнить, Esc и щелчок мимо — закрыть. В открытом меню Delete и F2 ничего не делают с контактом.
