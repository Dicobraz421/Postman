# T2-21. Подробности события: «Пришло письмом», «Открыть», пояс у Exchange

Статус: ⏳ (вид — 🤖 снимки `calendar`, `event-imip`; домен и пояс Exchange — 🤖 тесты; живой сервер — владелец)

1. Приглашение от внешнего организатора (Google, другой домен) в календаре: строка «Пришло письмом — ответ уйдёт
   организатору письмом». Приглашение коллеги — без неё.
2. Выбрать приглашение, Enter (или «Открыть» в шапке): письмо с приглашением открывается новой вкладкой почты. Письмо
   удалено — тост «Письма с этим приглашением нет в почте».
3. Своя встреча, Enter: вкладка встречи на правку; у повторяющейся — сначала «Только эту / Всю серию».
4. Exchange: встреча, созданная в Екатеринбурге (Outlook, пояс UTC+5), у вас — «У организатора: … · Yekaterinburg».
