# T2-38. Свои быстрые фильтры

Статус: ⏳ (вид — 🤖 снимок `search-saved`)

1. Найти «от:Петров вложения» → «Сохранить как быстрый фильтр»: тост, внизу закладка с этим запросом.
2. Закрыть поиск, щёлкнуть закладку — тот же поиск; ещё раз — поиск снят.
3. «×» у включённой закладки — закладки нет. Перезапуск — свои закладки на месте.
