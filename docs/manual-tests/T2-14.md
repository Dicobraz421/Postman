# T2-14. Быстрый ответ, «Весь день», «Частная»

Статус: ⏳ (тесты форматов — 🤖; живые серверы — владелец)

1. Открыть письмо: внизу — «Ответить — отправитель»; щелчок — ответ над письмом, курсор в тексте.
2. Новая встреча «Весь день»: в Outlook / на телефоне — событие на весь день.
3. «Частная»: у коллеги, которому открыт ваш календарь, — только «Занят»; у вас — замок у встречи.
4. Частное событие коллеги в «Календарях коллег»: замок и «владелец скрыл подробности».
