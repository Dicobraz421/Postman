# T2-30r. Контекстное меню

Статус: ⏳ (вид — 🤖 снимок `menu-due`)

1. Правая кнопка по письму → «Срок ▸»: «Сегодня», «Завтра», «В пятницу», «На следующей неделе» с датами справа;
   выбрать — метка срока в строке. «Выбрать дату…» — панель с полем.
2. «Напомнить ▸» — «Позже сегодня», «Завтра», «В понедельник».
3. В списке: Пробел — письмо выделено (флажок), ещё раз — снято.
