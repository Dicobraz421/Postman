# S8-34: сквозная проверка S8

Release-сборка из архива `main` (или `cargo build --release --workspace --features postman-worker/viewer`).

1. Первый запуск на прежней базе — «Обновление хранилища: N %», затем список; рядом с базой — `*.v5.bak`.
2. Exchange (тестовая учётка): выделить архивную папку → перетащить в «На этом компьютере». Письма в цели сразу,
   вопроса нет; в строке состояния — ход; в конце — тост; у Exchange письма удалены после ответа.
3. Часть писем из «На этом компьютере» → папка Stalwart. Вопрос над списком → «Перенести на сервер». Пауза,
   «Продолжить», «Остановить» → «Оставить остальные локально». Выйти посреди выгрузки, запустить — перенос
   продолжается.
4. «Экспорт…» у папки «На этом компьютере» → mbox, «С подпапками» → открыть в Thunderbird: письма, вложения, даты.
5. Настройки → Безопасность: строка BitLocker совпадает с «Управление BitLocker» в Windows.
6. Окно и список после переноса 10 000 писем — без рывков; `--bench` — `docs/MEMORY.md`, «Замер после S8».
