# T2-50. Правила и правила из письма

Статус: ⏳ (вид — 🤖 снимки `rules`, `rules-test`, `menu-rule`; модель и Sieve — 🤖 тесты `rules::`, `rulerun::`)

1. «Настройки → Правила» → «Новое правило»: название, «Тема содержит счёт», «Добавить группу „или“» — «pdf»,
   «Добавить условие» — «От · не из домена · свой домен»; действия «Пометить флагом» и «Пометить прочитанным»;
   «Остановить обработку». Сохранить — правило в списке строкой «ЕСЛИ … ИЛИ … И … → …», сервер принял.
2. Письмо себе с темой «Счёт» с внешнего адреса — пришло с флагом и прочитанным; с адреса своего домена — нет.
3. «Проверить на последних 100 письмах» — «Подойдёт N из 100 · показать», список писем совпадает с ожиданием.
4. «Применять к существующим письмам — найдено N», сохранить — у N писем действия применились, тост «Правило
   применено».
5. Стрелки ↑/↓ — порядок меняется, сохраняется на сервере.
6. Выключить «Выполнять на сервере» — у правил «в приложении»; новое письмо по правилу — действия выполняет Postman,
   строка в «Журнале срабатываний». Закрыть Postman, прислать письмо — правило не сработало (ожидаемо).
7. ПКМ по письму → «Всегда перемещать от этого отправителя ▸ <папка>» — тост, правило в списке, письма отправителя в
   папке; следующее письмо от него — сразу в папке.
8. ПКМ → «Заблокировать отправителя» — его письма в «Нежелательных» (нет такой папки — в «Удалённых»).
