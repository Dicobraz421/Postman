# T3-06. Таблицы в письме и вставка из Word

Статус: ⏳ (демо — 🤖 сцены `compose-t306-table`, `compose-t306-paste`; буфер обмена Windows сцены не читают)

1. Новое письмо → «Таблица»: таблица 3 столбца с заголовком у курсора; набрать, Tab — следующая ячейка, Shift+Tab —
   назад, Tab в последней ячейке — новая строка; столбцы выравниваются.
2. В Word выделить таблицу с жирным заголовком, список и абзац с крупным шрифтом, Ctrl+C → Ctrl+V в письмо:
   таблица `| … |`, список `- …`, жирный `**…**`; шрифта и размера нет. То же из браузера (таблица с сайта).
3. Ctrl+V простого текста (Блокнот) — как раньше.
4. Отправить себе: в Outlook и в Postman — таблица таблицей.
