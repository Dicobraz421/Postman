# T2-24. Вкладки, строка состояния

Статус: ⏳ (вид — 🤖 снимок `list`; живой сервер — владелец)

1. Справа от вкладок «+» — новая вкладка почты. У неактивной вкладки «×» появляется при наведении. Наведение на
   вкладку — полное название; на точку черновика — «Есть несохранённые изменения».
2. Строка состояния: «● Синхронизировано ЧЧ:ММ» (и в Почте, и в Календаре), «N аккаунтов · N общих ящиков», в папке с
   непрочитанными — «· непрочитанных: N». Выключить сеть — «(кэш)».
3. Наведение на число писем беседы — «Писем в беседе».
4. «Настройки → Жизненный цикл → Исчезнувшие — в Архив»: метка «В архив через N д».
