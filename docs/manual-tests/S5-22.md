# S5-22. Календари коллег и цвет владельца

Статус: 🤖 частично (2026-11-06): шаг 3 — сцены, шаг 4 — стенд, в шаге 2 — флажок; не покрыто — шаг 1 (только условием по модели), в шаге 2 пять цветов и сохранение после перезапуска

Демо — шаги 1–3; живой ящик (`POSTMAN_URL`…), user2 открыл user1 календарь (`mayReadItems`) — шаг 4.

1. Ctrl+2: слева «Мои календари» и «Календари коллег» (Иванова Мария, Петров Алексей) — у каждого свой цвет. События
   коллег в неделе — подложкой цвета их календаря, сверху имя владельца; свои — синие, категория — полосой слева.
2. Снять флажок у коллеги — его события пропадают; вернуть — снова видны. «…» у календаря — пять цветов, выбор меняет
   цвет сразу; перезапуск — выбранное на месте.
3. Настройки → Календарь: «Цвета по владельцу» выключить — события коллег цветом категории; «Показывать имя
   владельца» выключить — имени нет. Цвета календарей — те же образцы.
4. Живой ящик: календарь коллеги слева, его события в неделе; общая встреча — один раз.
