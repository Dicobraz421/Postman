# T3-07. Картинка в подписи

Статус: ⏳ (демо — 🤖 сцены `settings-t307-sign-image`, `compose-t307-sign-image`; диалог выбора файла — вручную)

1. «Настройки → Подписи и шаблоны» → подпись → «Картинка»: выбрать PNG логотипа — в тексте строка `![…](cid:…)`,
   в предпросмотре — логотип. «Сохранить», перезапустить Postman — логотип на месте.
2. «Картинка» с файлом больше 1 МБ и с `.txt`, переименованным в `.png`, — строка под текстом, подпись без картинки.
3. Подпись с логотипом по умолчанию → новое письмо: логотип своего размера в тексте подписи, в «Вложениях» его нет;
   стрелками в строку логотипа — видна ссылка `![…](cid:…)`, картинка под ней; ушли из строки — снова картинка.
   Отправить себе: в Outlook и в Postman логотип — в тексте подписи, не вложением.
4. Сменить подпись в письме на другую — логотип пропал из текста; отправленное письмо — без него.
