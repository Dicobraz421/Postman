# T2-43. Клавиши «Контактов»

Статус: ⏳ (реестр без конфликтов — 🤖 тест; нажатия — владелец)

1. «Контакты», выбран коллега: Ctrl+N — письмо ему; Ctrl+Shift+Q — встреча с ним; Ctrl+C — тост «Адрес скопирован», в
   буфере его адрес.
2. В поле поиска Ctrl+C копирует набранный текст, а не адрес.
3. Ничего не выбрано: Ctrl+N — пустое письмо.
4. В «Почте» Ctrl+N — новое письмо, в «Календаре» Ctrl+Shift+Q — новая встреча (как раньше).
5. Подержать Ctrl: у «Написать», «Встреча», «Копировать адрес» — подсказки клавиш; в русской раскладке — так же.
