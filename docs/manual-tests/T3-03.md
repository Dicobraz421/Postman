# T3-03. «Кому…»

Статус: ⏳ (демо — 🤖 сцены `mail-t303-picker`, `mail-t303-added`)

1. Exchange: «Кому» → набрать часть фамилии сотрудника, которого нет в переписке, — он появляется в списке из
   справочника, «ОК» — чип.
2. Ответ в области чтения: «Копия» → панель под строками адресатов, Esc — панель закрыта, ответ на месте.
