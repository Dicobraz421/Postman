# S5-12.7. Свои сертификаты в «Безопасности»

Статус: ⏳

Windows (компьютер с сертификатом S/MIME) и MacBook Air M1 (сертификат в Связке ключей «вход», см.
`docs/manual-tests/MAC-05.md`, шаг 1). Сборка — артефакт CI PR.

1. «Настройки» → «Безопасность» → группа «Свои сертификаты». Ожидается: по строке на сертификат с закрытым ключом —
   кому выдан, адреса, издатель, «действует до»; справа «Подпись» (сертификат для подписи почты).
2. Сверка. Windows — `certmgr.msc` → «Личные» → «Сертификаты»; macOS — «Связка ключей» → «Мои сертификаты». Список
   тот же (на Windows могут быть и сертификаты без адреса — строка «без адреса»).
3. Срок. Есть сертификат, который истекает в ближайшие 30 дней (или истёк), — справа «Истекает …» другим цветом
   (или серое «Истёк …»).
4. Нет сертификатов (другая учётная запись ОС или пустая Связка): «Своих сертификатов нет» с пояснением.
5. Открытие «Безопасности» не подвисает и со смарт-картой в считывателе (список — в фоне).

Что записать в отчёт: номер шага и что видно (снимок экрана).
