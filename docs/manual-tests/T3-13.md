# T3-13. Значок в трее, закрытие окна в трей, щелчок по уведомлению

Статус: ⏳ (тесты моделей — 🤖; Windows, MSI и portable — владелец)

1. Запуск: в области уведомлений — значок Postman, подсказка «Postman». Есть непрочитанные во «Входящих» — значок с
   красной отметкой, подсказка «Postman — непрочитанных: N»; прочитали все — отметка ушла.
2. Крестик (и Alt+F4): окно исчезло с экрана и с панели задач, значок остался. Первый раз — уведомление Windows
   «Postman работает в фоне»; второй раз — уже нет.
3. Щелчок по значку — окно вернулось и впереди. Правая кнопка — «Открыть Postman», «Выход»; щелчок мимо меню его
   закрывает. «Выход» — процесса нет, значок пропал; письмо из «Отменить» отправлено.
4. Окно спрятано, пришло письмо: уведомление Windows. Щелчок по нему — окно, «Входящие», это письмо открыто. Пришло
   несколько — щелчок открывает «Входящие».
5. Окно спрятано, сработало напоминание задачи или встречи: уведомление Windows, щелчок возвращает окно.
6. Окно спрятано, запустили Postman ещё раз (ярлык, `mailto:`): показано прежнее окно (со ссылкой — новое письмо).
7. «Настройки → Общие → Закрытие окна: Выйти»: крестик завершает Postman. Вернуть «Свернуть в трей».
8. Автозапуск включён, вход в Windows: окна и кнопки на панели задач нет, значок есть, письма приходят.
9. Перезапуск Проводника (диспетчер задач → «Проводник» → «Перезапустить»): значок вернулся.
10. Portable (архив) и MSI ведут себя одинаково.
