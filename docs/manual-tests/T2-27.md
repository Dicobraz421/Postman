# T2-27. Поиск

Статус: ⏳ (вид — 🤖 снимок `search`, отрывок — 🤖 тест; живой сервер — владелец)

1. Найти слово из середины письма: в превью строки — «…» и текст вокруг слова.
2. «Везде» → чип «только <папка>» → результаты только текущей папки; ещё раз — снова везде.
3. Включить уточнения так, что ничего не найдено: «Сбросить уточнения» — чипы сняты, результаты вернулись.
