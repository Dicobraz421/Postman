# T1-17. Переслать несколько писем вложениями

Статус: 🤖 частично (2026-11-06): шаги 1, 2 — сцены, шаги 1–3 — стенд; владельцу — открытие в Outlook (шаг 4); меню строки беседы — последнее письмо, сцена `mail-29-thread-forward` (решение владельца 2026-11-06, п. 10)

Живой ящик (`POSTMAN_URL`…); шаги 1–2 — и в демо.

1. Входящие: Ctrl+щелчком выделить три письма. В панели массовых действий — «Переслать» (значок пересылки); нажать:
   новое письмо вкладкой, тема пустая, три вложения `<тема>.eml` по дате (старое первым).
2. Правой кнопкой по одному письму (не в выделении) → «Переслать вложениями»: одно вложение `.eml`, тема «FW: <тема>».
   По строке беседы — только её последнее письмо (как и «Напомнить» и другие сроки); всем письмам беседы — выделить их и нажать «Переслать» (шаг 1). Удаление, архив, перенос, отметки и категории по строке — вся беседа.
3. Письма, тела которых ещё не загружались (давние, без открытия): тост «Загружаю письма…», затем вкладка письма.
4. Переслать три письма себе. В Outlook (и в Postman) вложения открываются как письма: отправитель, тема, текст,
   вложения исходных писем — как в оригинале.
