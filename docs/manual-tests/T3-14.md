# T3-14. Пересылка целиком; «Ответить всем» — вложения беседы новым участникам

Статус: ⏳ (ручная проверка — владелец, позже; нужны три ящика: свой, A и B, и новый участник C)

Пересылка
1. Письмо с PDF, Excel, текстовым файлом в windows-1251 и картинкой в тексте → «Переслать» себе на другой ящик:
   все файлы на месте, открываются, текстовый файл читается; картинка — в тексте, у неё есть имя при сохранении.
2. Письмо Apple Mail с картинкой «inline», на которую текст не ссылается → «Переслать»: картинка пришла вложением.
3. Выключить сеть после открытия письма, не открывая вложений → «Переслать» и «Отправить»: строка «Не отправлено:
   вложение „…“ не скачалось…», письмо осталось в окне; включить сеть → «Отправить» — ушло целиком.

«Ответить всем» (JMAP, IMAP, Exchange — по очереди)
4. Беседа A ↔ B с вложением (A прислал отчёт). «Ответить всем», в «Копию» — C: над текстом строка «Новым участникам
   (C) уйдут вложения беседы: 1 файл». Отправить.
5. У A и B — ответ без вложения; у C — тот же ответ (тема, «Кому», «Копия» те же) с отчётом. Exchange: у C — ответ
   и отдельное письмо «Вложения из беседы» с отчётом в той же беседе.
6. «Отправленные» — одна запись ответа, без вложения.
7. Снова «Ответить всем» с C, «Не отправлять» в строке → C получил ответ без вложений; строка снова «Отправить» —
   вернуть.
8. «Ответить» A с добавленным вручную D — строка с D; убрать D из полей — строка пропала.
9. JMAP: ответ с C → «Отменить» в окне «Отменить»: не пришло ни A, ни B, ни C. «Отправить позже» с C → в списке
   отложенных одна строка; отменить её — C ничего не получил.
10. «Настройки → Почта → При ответе на сообщение: без исходного письма» — пункт 4 так же.
11. Ответ всем с C, «Не отправлять», закрыть с «Сохранить» → открыть черновик из «Черновиков»: строка «… вложения
    беседы не уйдут» на месте. «Отправить» → «Отменить» в окне «Отменить»: письмо вернулось с той же строкой.
12. Черновик ответа с C (строка «уйдут»), сохранить, закрыть, открыть снова: строка «Новым участникам (C) уйдут…».
