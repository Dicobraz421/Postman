# T2-52. Подписи и шаблоны

Статус: ⏳ (вид — 🤖 снимки `settings-sign`, `settings-sign-template`, `compose-template`; поля и команда — 🤖 тесты
`fill::`)

1. «Профиль для полей подписи»: имя, должность. Подпись «С уважением,\n**{имя}**\n{должность}» — «Предпросмотр»
   показывает значения, имя жирным; «Ответ» — подпись над цитатой.
2. Новое письмо — подпись по умолчанию с подставленными полями; меню «Подпись» — то же.
3. Шаблон «КП»: команда «кп», текст с `{Компания}`, «Прикрепить файл», «Спрашивать значения» включено. В новом
   письме набрать «/кп» и пробел — над текстом строка «Поля шаблона», ввести «Вектор» — «Вставить»: текст с
   «Вектор», тема заполнена, файл во вложениях. «Без значений» — поля остаются метками.
4. Меню «Шаблон» нового письма — шаблоны с командами; выбор — вставка у курсора.
5. «Ж»/«К» в правке подписи — разметка вокруг выделения.
