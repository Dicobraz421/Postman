# S8-15: «На этом компьютере» и перенос между учётками

Статус: 🤖 частично (2026-11-07): шаги 1, 2 — сцены; шаг 3 — стенд, 10 000 и 2000 писем, Ctrl+A выбирает всё на сервере, сверка числа писем у цели и источника запросом, дублей нет, список цели показал письма за 1,4–4,2 с; шаг 3 перетаскивается в другую учётку JMAP, Exchange не проверялся; шаги 4, 5 — стенд, шаг 5 в сценах — только «письмо открывается»; шаг 6 — сцены (закрытие письма, снятие выделения) и стенд, группа `find`: «Везде» находит перенесённое письмо (S8-09, решение 5, 2026-11-07)

Стенд: две учётки в профиле (например, Stalwart и Exchange) или демо `--demo 50000`.

1. Дерево папок: внизу — группа «На этом компьютере» (значок монитора); подсказка — «Хранится только в базе
   Postman на этом компьютере · N писем». Щелчок по подписи сворачивает группу.
2. ПКМ по подписи группы → «Новая папка» → имя, Enter: папка в корне группы. ПКМ по ней → «Новая папка» —
   вложенная; «Переименовать» — поле в строке; «Удалить» у непустой — тост «Удалить можно пустую папку»; у пустой —
   папка исчезает. Перетащить локальную папку на другую локальную — вложилась; на подпись группы — в корень.
3. Выделить 10 000 писем «Входящих» одной учётки (Ctrl+A), перетащить на папку другой учётки.
   Ожидание: список цели за 1–5 с показывает письма со значком «ждёт переноса» (подсказка «Ждёт переноса на
   сервер «…»»), окно не замирает; во «Входящих» источника писем больше нет.
4. То же через «В папку ▾»: в списке — папки своей учётки, затем другие учётки и «На этом компьютере» подписями групп.
5. Перенести письма в «На этом компьютере»: без вопроса; письма открываются (тело — из базы, без сети).
6. Выделение, открытое письмо и поиск после переноса: открытое письмо закрывается, выделение снято, поиск «Везде»
   находит перенесённое письмо.
