# T3-02. «Отправить и получить — все папки»

Статус: ⏳ (демо — 🤖 сцена `mail-t302-sync`)

1. Живой ящик с двумя учётными записями: F9 и кнопка у поиска — тост «Отправка и получение…», новые письма обеих
   учётных записей приходят сразу, не дожидаясь опроса.
2. Без сети написать письмо (уходит в очередь), вернуть сеть и нажать F9 — письмо уходит сразу, без паузы повтора.
