# T3-02. «Отправить и получить — все папки»

Статус: ⏳ (демо — 🤖 сцены `mail-t302-sync`, `mail-t302-progress`, `mail-t302-done`)

1. Живой ящик с двумя учётными записями: F9 или кнопка у поиска — в строке состояния «Отправка и получение…», кнопка
   серая; затем тост «Отправка и получение: готово», новые письма обеих учётных записей — сразу, не дожидаясь опроса.
2. Без сети написать письмо (уходит в очередь), F9 — тост «Отправка и получение не завершены: …»; вернуть сеть, F9 —
   письмо уходит сразу, тост «готово».
