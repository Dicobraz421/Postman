# MAC-01. Postman для macOS собирается и запускается

Статус: ⏳

MacBook Air M1, macOS 13 или новее. Сборка — артефакт CI, демо-ящик без сервера. Вход, Cmd-клавиши, уведомления и
mailto в этой волне не проверяются (MAC-02).

1. Скачать сборку: GitHub → Postman → Actions → прогон «macOS» нужного PR или main → внизу «Artifacts» →
   `postman-<версия>-macos-arm64`. Скачается `postman-<версия>-macos-arm64.zip` (архив GitHub); двойной щелчок —
   внутри ещё один `postman-<версия>-macos-arm64.zip`, его тоже открыть двойным щелчком. Появятся `Postman.app` и
   `README.txt`. Перетащить `Postman.app` в «Программы».
2. Снять карантин — одно из двух:
   - Finder: двойной щелчок по `Postman.app` → отказ («Не удаётся проверить разработчика» или «повреждён») →
     «Готово». «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Postman заблокирован…» →
     «Всё равно открыть», пароль или Touch ID; или
   - Терминал: `xattr -dr com.apple.quarantine /Applications/Postman.app`.
   Ожидается: дальше `Postman.app` открывается без вопросов.
3. Демо: в Терминале `/Applications/Postman.app/Contents/MacOS/postman --demo` (первый запуск создаёт демо-ящик —
   до минуты). Ожидается: окно Postman со списком писем демо-ящика, папки слева, значок «Ленты» в Dock.
4. Письмо: щелчок по письму с оформлением (HTML) — текст, жирный, ссылки видны в панели чтения; под письмом нет
   строки «Песочница недоступна» или «Нет компонента postman-worker».
5. Вложение PDF: письмо с PDF → щелчок по вложению — страница PDF в просмотре (рендер в песочнице воркера).
6. Календарь: раздел «Календарь» — неделя с событиями демо-ящика.
7. Значок и версия: Finder → `Postman.app` → «Свойства» (Cmd+I): значок «Ленты», версия `0.1.0-beta.N`.
   `codesign -dv /Applications/Postman.app` в Терминале — строка `Signature=adhoc`.
8. Данные: в Finder «Переход» → «Переход к папке…» → `~/Library/Application Support/Postman` — папка есть (демо-ящик
   `demo.redb` и настройки).
9. Закрыть окно (красная кнопка или Cmd+Q) — процесс завершается: в «Мониторинге системы» нет `postman` и
   `postman-worker`.

Терминала после шага 3.
