# MAC-06. Выпуск Postman для macOS ставится на Mac

Статус: ⏳

MacBook Air M1, macOS 13 или новее. Файлы — со страницы выпуска (после тега) или из артефакта прогона CI (до тега).
Подписи Apple пока нет — первый запуск через «Всё равно открыть».

1. Скачать:
   - выпуск: GitHub → Postman → Releases → нужная версия → «Скачать — macOS» → **Образ диска** (.dmg); или
   - до тега: GitHub → Postman → Actions → прогон «CI» нужного PR или main → внизу «Artifacts» →
     `postman-<версия>-macos-arm64`. Скачается архив GitHub; двойной щелчок — внутри `.dmg` и `.zip`.
   Ожидается: на странице выпуска у `.dmg` и `.zip` есть файлы `.minisig`, в `SHA256SUMS.txt` — их строки.
2. Проверить сумму (по желанию, после тега): в Терминале `cd ~/Downloads && shasum -a 256 postman-*-macos-arm64.dmg`
   — та же строка, что в `SHA256SUMS.txt` выпуска.
3. Образ диска: двойной щелчок по `postman-<версия>-macos-arm64.dmg`. Ожидается: окно диска «Postman <версия>» с
   `Postman.app`, `README.txt` и ярлыком `Applications` (папка «Программы»). Перетащить `Postman.app` на ярлык.
   Если Postman уже стоит — Finder спросит «Заменить», ответить «Заменить». Извлечь диск (⏏ в боковой панели Finder).
4. Первый запуск: «Программы» → `Postman` двойным щелчком → отказ («Не удаётся проверить разработчика» или
   «повреждён») → «Готово». «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Postman
   заблокирован…» → «Всё равно открыть», пароль или Touch ID → снова открыть Postman → «Открыть».
   Ожидается: окно Postman (первый запуск — мастер входа или прежние ящики, если Postman уже стоял).
   Второй запуск — без вопросов.
5. Версия и подпись: Finder → `Postman.app` → «Свойства» (Cmd+I) — значок «Ленты», версия как на странице выпуска.
   В Терминале `codesign -dv /Applications/Postman.app` — строка `Signature=adhoc`.
6. Архив: удалить Postman из «Программ» (в Корзину), скачать `.zip` того же выпуска, распаковать двойным щелчком,
   перенести `Postman.app` в «Программы», первый запуск — как в шаге 4 (или в Терминале
   `xattr -dr com.apple.quarantine /Applications/Postman.app`). Ожидается: то же приложение, письма и вход на месте.
7. Обновление поверх (когда выйдет следующая версия): Cmd+Q в Postman, новый `Postman.app` из `.dmg` на ярлык
   `Applications` с заменой. Ожидается: новая версия в «Свойствах», письма, вход и настройки сохранились.
8. Страница выпуска: блок «Скачать — macOS 13 и новее» понятен без этого файла: ссылки на `.dmg` и `.zip`
   открываются, инструкция «Первый запуск» совпадает с тем, что показал Mac.

Терминала после шагов 2 и 5.
