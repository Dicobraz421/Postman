# S7-08. Занятость и справочник Exchange: «Помощник планирования», подсказки адресов, «Справочник»

Статус: ⏳

Боевой Exchange компании, учётка `user1` (тестовая). Справочник и занятость — **только чтение**: ничего не
создаётся. Обе темы.

1. «Помощник планирования»: вкладка «Встреча», участники — `user2` и адрес вне организации (`nobody@example.com`).
   Ожидание: у `user2` — его занятость (сравните с OWA `user2`: занят — синим, под вопросом — светлым, «вне офиса» —
   серым); у внешнего адреса — «нет данных» (заливка с прозрачностью), а не свободное время; «Только общее свободное
   время» не считает внешний адрес свободным.
2. Занятость коллеги на сегодня: «Контакты → Справочник» → найдите `user2` → карточка. Ожидание: полоса «Сегодня» —
   его занятость на сегодня (если в его календаре есть встречи), как в OWA.
3. Подсказки адресов: поле «Кому» нового письма — первые 3 буквы фамилии коллеги. Ожидание: подсказки из справочника
   организации (имя и адрес), как в OWA; списки рассылки — тоже.
4. «Контакты → Справочник»: поиск по фамилии коллеги. Ожидание: коллеги находятся; в строке — должность и отдел; в
   карточке — «Должность», «Организация» (отдел), «Телефоны» — как в адресной книге Outlook. Телефона по `FindPeople`
   в строке нет (`docs/EXCHANGE.md`) — он добирается через `ResolveNames` при открытии карточки (S7-08б, S7-07б шаг 6); [проверить]: должность и отдел видны у коллег, у кого они заполнены в
   AD (у тестовых учёток их нет).
5. Без связи: выключите сеть, наберите в «Кому» 3 буквы. Ожидание: подсказки — из уже найденного и переписки, без
   ошибки; сеть вернулась — снова из справочника.
