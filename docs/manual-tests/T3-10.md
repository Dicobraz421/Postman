# T3-10. Где совпало во вложении

Статус: ⏳ (вид — 🤖 снимок `search`)

1. Первый запуск после обновления: индекс поиска пересобирается в фоне; пока он не готов, поиск работает по кэшу (без
   подписи «во вложении»).
2. Письмо с вложением `.docx` или `.txt`, открытым хотя бы раз (или письмо из локальной папки): набрать в поиске слово,
   которое есть только в тексте вложения, — письмо найдено, под темой скрепка и «во вложении: имя — …отрывок…», слово
   подсвечено.
3. Слово есть и в письме (тема, отправитель, тело), и во вложении — обычное превью, без подписи; два слова, одно из
   которых есть только во вложении, — подпись «во вложении».
4. Набрать имя файла вложения — «во вложении: имя» без отрывка.
5. То же слово с опечаткой и в другой раскладке — подпись та же. Английский интерфейс — «in attachment: …».
