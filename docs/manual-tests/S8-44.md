# S8-44. Подписка на календарь ICS

Статус: ⏳

Нужна публичная ссылка на календарь: например, государственные праздники Google (`…/public/basic.ics`) или
опубликованный календарь Outlook.

1. «Календарь» → «Подписки» → «Добавить по ссылке», ввести `http://…`, Enter: «Нужна ссылка https:// или webcal://…».
2. Ввести настоящую ссылку (`https://` и `webcal://`): в группе появился календарь с именем из файла, события — в неделе.
3. Сверить с источником: события на весь день в верхней полосе в правильный день, повторы, часовые пояса.
4. Открыть событие: подпись «Подписка», кнопок ответа нет, изменить и удалить нельзя.
5. Флажок слева скрывает события; образец цвета — смена цвета, там же «Обновить» и «Удалить».
6. Перезапуск: подписка и цвет на месте; без сети — прежние события и «Не обновился, показаны прежние события».
7. «Удалить»: календарь и события ушли, в `%LOCALAPPDATA%\Postman\subscriptions` файла нет.
8. «Настройки → Календарь → Обновлять подписки»: по истечении срока файл обновился; в журнале сервера повторный запрос
   с `If-None-Match` получает 304, если сервер отдаёт ETag.
9. Встреча поверх события подписки: помощник планирования на мою занятость подписка не влияет.
