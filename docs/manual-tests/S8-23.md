# S8-23: листы, слайды, письмо во вложении

1. Письмо с книгой Excel (несколько листов, лист шире панели): «Просмотр» — листы вкладками в строке инструментов
   (подсказка — «Лист «…»»); первая строка закреплена при прокрутке вниз; шире панели — прокрутка вбок; числа —
   вправо. Большая книга — внизу «Показано начало: N строк · Сохранить…».
2. Презентация PowerPoint: «3 / 12», ‹ › и ← / → листают слайды (у последнего → не уходит к следующему вложению);
   справа — «Слайд N · заголовок»; картинка — пометкой «[рисунок]»; заметки — «Заметки докладчика».
3. Таблица CSV и TSV — сеткой без вкладок.
4. Письмо `.msg` из Outlook и `.eml`: шапка (От, Кому, Копия, Дата), тема, свои вложения карточками, текст письма.
5. Документ RTF, ODT, Markdown — текстом, как письмо.
6. Английский интерфейс: «Sheet “…”», «Slide N», «[picture]», «Speaker notes».
