# S8-43. Управление доступом к календарю

Статус: ⏳

Сервер с JMAP или CalDAV (The Post или другой), две тестовые учётные записи: A и B.

1. A: «Календарь» → «Доступ к календарю» → «Открыть календарь коллеге», адрес B, без флажка: тост, B появился в списке
   с «Только занятость». У B в помощнике планирования видна занятость A, календарь с событиями — нет.
2. Щелчок по «Только занятость»: уровень стал «Занятость и подробности», у B появились события A.
3. Открыть ещё раз тому же адресу с другим флажком: запись заменилась, повтора в списке нет.
4. «Закрыть доступ»: B ушёл из списка, у B занятость снова «нет данных».
5. Перезапуск A: список тот же (читается с сервера).
6. Exchange: список пуст; «Открыть» — сообщение, что доступом управляет сервер.
