# MAC-02. Postman на Mac — для ежедневной почты

Статус: ⏳

MacBook Air M1, macOS 13 или новее. Сборка — артефакт CI «macOS» PR MAC-02 (как скачать и снять карантин —
`docs/manual-tests/MAC-01.md`, шаги 1–2). Запуск — из Finder или Dock, не из Терминала (иначе журнал пишется в
Терминал). Нужен живой ящик (JMAP, IMAP или Exchange) — любой, тестовые адреса не годятся.

1. Вход и Связка ключей. Запустить Postman, войти в живой ящик с паролем. Ожидается: письма загрузились. Cmd+Q, снова
   открыть Postman. Ожидается: вход не спрашивается (пароль — в Связке ключей). Если macOS спросит «Postman хочет
   использовать конфиденциальную информацию…» — «Всегда разрешать» (подпись ad-hoc, вопрос бывает после обновления).
   «Связка ключей» → поиск `Postman` — запись «пароль программы».
2. Клавиши. В списке писем: Cmd+N — новое письмо, Cmd+R — ответ, Cmd+F — переслать (как Ctrl+N/R/F на Windows).
   Cmd+, — настройки; Ctrl+Tab — следующая вкладка. В подсказках кнопок и палитре (Cmd+K) клавиши — значками ⌘ ⇧.
3. Option печатает. В тексте письма Option+E, затем E — «é»; Option+- — «–». Команды Postman не срабатывают.
4. Системные клавиши: Cmd+M — окно сворачивается в Dock; Cmd+H — Postman скрыт; щелчок по значку в Dock — окно
   вернулось; Cmd+Q — выход (в «Мониторинге системы» нет `postman`).
5. Окно. Слева в заголовке — системные «светофоры» (красная, жёлтая, зелёная), своих «─ □ ✕» справа нет. Перетаскивание
   за пустое место заголовка двигает окно, двойной щелчок — увеличивает. Красная кнопка скрывает Postman (почта
   продолжает приходить), Dock возвращает окно. Значки кнопок и меню — рисунками, без пустых квадратов; исходный текст
   письма и отпечатки сертификатов — моноширинным шрифтом (Menlo).
6. Уведомление. Первое новое письмо — macOS спросит разрешение уведомлений: «Разрешить». Свернуть окно (Cmd+M),
   отправить себе письмо с другого ящика. Ожидается: баннер в правом верхнем углу «Postman» с отправителем и темой.
7. `mailto:`. «Настройки» → «Общие» → «Сделать Postman клиентом по умолчанию» → macOS спросит «Использовать
   «Postman»?» → подтвердить. Safari: страница со ссылкой `mailto:` (или адрес `mailto:test@example.test` в строке
   адреса) → щелчок. Ожидается: Postman впереди, новое письмо с адресатом `test@example.test`. То же при закрытом
   Postman (Cmd+Q, затем ссылка) — Postman запускается и открывает новое письмо.
8. Журнал. «Настройки» → «Общие» → «Открыть папку журнала» — Finder открывает `~/Library/Logs/Postman`, там файл
   `postman-<дата>.log` с записями этого запуска. «Отчёт для поддержки» → собрать → «Показать файл» — Finder с выделенным архивом.
9. Вложения. Письмо с вложением PDF: «Открыть» — PDF в «Просмотре». «Сохранить как» → в Терминале
   `xattr -p com.apple.quarantine <файл>` — строка `0001;…;Postman;`. Вложение `.app`, `.command`, `.pkg`, `.scpt`
   или `.terminal` — «Открыть» нет, только «Сохранить».
10. Перетаскивание. Перетащить вложение PDF из письма на рабочий стол — там появляется копия файла.

Что записать в отчёт: номер шага и что видно (снимок экрана: Cmd+Shift+4, пробел, щелчок по окну); для шагов 1, 6, 7 —
последние строки журнала из шага 8.
