# T2-51. Аккаунты: «Настроить», «Синхронизировать»

Статус: ⏳ (вид — 🤖 снимок `settings-account-setup`)

1. «Настройки → Аккаунты»: в строке учётки — узел, протокол (JMAP / IMAP/SMTP / Exchange (EWS)) и состояние.
2. «Настроить» — параметры сервера совпадают с адресом входа; «Офлайн-кэш» — размер, похожий на файл кэша в
   `%LOCALAPPDATA%\Pets\Postman`. «Свернуть» — карточка уходит.
3. Отправить себе письмо с другого клиента, сразу «Синхронизировать» — письмо в списке без ожидания опроса (JMAP,
   IMAP, Exchange). Без сети — «Синхронизировать» = «Повторить сейчас».
