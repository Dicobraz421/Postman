# S7-03б. Несколько учётных записей

Статус: 🤖 частично (2026-11-06): шаги 1–6, 8 — стенд; не покрыто — 7 (перезапуск с обеими учётками; по карте стенда пароль берётся из Диспетчера учётных данных — владельцу)

Стенд Stalwart: основная учётная запись `user1`, дополнительная — `user2` (тот же сервер — проверка пути; со стандартами
и Exchange — в S7-04…S7-08). Обе темы.

1. «Настройки → Аккаунты» → «Добавить аккаунт» при живом `user1`: адрес, логин `user2`, пароль. Ожидание: карточка
   закрывается, когда сервер ответил; в списке — карточка `user2` с «Удалить»; `user1` остаётся основной (экран
   не перезапускается). Неверный пароль — причина в карточке, учётная запись не добавляется. Тот же `user1` ещё раз —
   «Эта учётная запись уже подключена».
2. Дерево папок: под общими ящиками `user1` — группа `user2` со значком почты, её папки, ниже — её общие ящики.
   Письмо в папке `user2` открывается, отмечается прочитанным, переносится и удаляется (на сервере — у `user2`).
3. Новое письмо: «От» — адреса обеих учётных записей. От `user2` письмо уходит с его адреса, копия — в «Отправленные»
   `user2`. Ответ на письмо из папки `user2` — по умолчанию от `user2`.
4. Календарь: в «Моих календарях» — «Мой календарь» и календарь `user2` (подпись — адрес, свой цвет, флажок
   скрывает); события `user2` — его цветом, с подписью владельца. Встреча, на которую приглашены оба, — один раз.
5. «Создать встречу»: строка «От» с адресами обеих учётных записей; от `user2` — организатор `user2`, занятость в
   «Помощнике» — путём `user2`. Выбрано событие `user2` в календаре — «От» новой встречи сразу `user2`.
6. Поиск «Все папки»: находит письма обеих учётных записей одним списком; «Входящие» — только текущей.
7. Перезапуск Postman: обе учётные записи на месте, синхронизация `user2` идёт сама (пароль — из Диспетчера).
8. «Удалить» у `user2` → подтверждение строкой → группа исчезает из дерева, календарь — из «Моих календарей»,
   адрес — из «От»; у `user1` всё на месте.
