# S7-06. Учётная запись Exchange по EWS: почта, календарь, занятость, справочник

Статус: ⏳

Боевой Exchange компании, **только тестовые учётки** `user1` и `user2` (S7 «Проверка на боевом Exchange»); письма и
встречи — только между ними. Всё созданное — с меткой `[postman-test]` в теме, после проверки — удалить. Обе темы.

1. «Настройки → Аккаунты → Добавить аккаунт» (или первый запуск): адрес сервера — домен почты user1, логин — адрес
   почты user1, пароль. Ожидание: вход прошёл; адрес учётной записи — `https://…/EWS/Exchange.asmx`; в заголовке —
   «Почта», «Календарь», «Контакты»; «Задач», «Правил» и «Автоответа» нет; в «Контактах» — «Мои контакты» и «Справочник» (T1-25г).
2. Почта: «Входящие», «Черновики», «Отправленные», «Удалённые» и свои папки Exchange — с теми же именами и
   вложенностью, что в OWA. Письмо user2 уходит (копия — в «Отправленных») и приходит у user2 (опрос — до 2 мин).
   Прочитано, флаг, перенос в папку, удаление — так же в OWA. Черновик сохраняется в «Черновики» OWA.
3. Календарь: неделя с встречами user1 — те же, что в OWA; повторяющаяся — каждый экземпляр на своём дне; поиск в
   календаре находит встречу по теме.
4. Новая встреча с user2 `[postman-test] …`: уходит, в неделе user1 — сразу; у user2 — приглашение. user2 отвечает
   «Принять» из карточки письма в Postman (вторая учётная запись рядом) — у user1 через опрос (до 2 мин) у участника
   «принял».
5. «Помощник планирования» встречи: занятость user2 видна; адрес вне организации — «нет данных», а не «свободен».
6. Поле «Кому» и участники встречи: первые 3 буквы фамилии коллеги — подсказки из справочника (GAL); в
   «Контакты → Справочник» поиск по фамилии находит коллег.
