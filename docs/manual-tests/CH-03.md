# CH-03. Канал Telegram — вход, диалоги, реальное время

Статус: ⏳ (ручная проверка — владелец, тестовый аккаунт Telegram, сборка с ключом приложения)

Подготовка: сборка с ключом приложения — переменные `POSTMAN_TG_API_ID`/`POSTMAN_TG_API_HASH` при сборке (в CI — из
секретов `TKNAPPID`/`TKNZORIO`; без них в «Настройки → Аккаунты → Каналы
бесед» — строка «В этой сборке нет ключа приложения Telegram»). Вид бесед — CH-04: до него беседы и сообщения видны
только по журналу (`Debug`) и в базе профиля; здесь проверяется вход и то, что канал получает и отправляет.

1. «Настройки → Аккаунты»: группа «Каналы бесед», «Telegram» выключен. Включить — появилась кнопка «Добавить учётку
   Telegram». Политика `AllowChannelTelegram = 0` (реестр, `Software\Policies\Pets\Postman`) — группы нет; `= 1` —
   включён, выключатель недоступен, строка «Задано политикой организации».
2. «Добавить учётку Telegram» → номер с ошибкой (`+7 1`) — «Telegram не принял номер…». Верный номер → «Получить
   код» → поле кода с подсказкой, откуда код (приложение или SMS). Неверный код — «Неверный код…», шаг тот же;
   «Отправить код снова» — новый код.
3. Учётка с паролем двухэтапной проверки: после кода — поле пароля с подсказкой; неверный — «Неверный пароль…»;
   верный — карточка входа закрылась, строка учётки: имя, «Подключение…» → «В сети».
4. Вход по QR: «Добавить учётку Telegram» → «Войти по QR-коду» → QR (тёмный на светлом и в тёмной теме). Телефон:
   Telegram → «Настройки» → «Устройства» → «Подключить устройство» → навести камеру: вход прошёл (с паролем — поле
   пароля). Подождать 30 с не сканируя — QR обновился. «Войти по номеру телефона» — снова поле телефона.
5. В Telegram на телефоне — «Устройства»: сеанс «Postman». Перезапуск Postman — учётка «В сети» без нового входа
   (сессия — в диспетчере учётных данных: запись `postman channel telegram <id>`; файлов сессии рядом с базой нет).
6. Диалоги: журнал `Debug` — `channel: conversations changed` после подключения; личные, группы, супергруппы, каналы,
   папки Telegram и архив (база профиля: `chan_account`, `conv`).
7. Реальное время: с телефона написать себе в «Избранное» и собеседнику; в журнале — `conversations changed` в
   течение секунд. Правка и удаление сообщения на телефоне — так же.
8. Отправка (через запрос канала — интерфейс отправки CH-04): тест `crates/backend-telegram/tests/conformance.rs`
   проверяет отправку, правку, удаление, реакцию, файл на подставном сервере; на живом аккаунте — после CH-04.
9. Связь: выключить сеть — строка учётки «Нет связи, повтор через N с»; включить — «В сети», пропущенные за время
   без связи сообщения пришли (догон от курсора).
10. «Выйти» — строка учётки пропала; на телефоне в «Устройствах» сеанса «Postman» нет; записи в диспетчере учётных
    данных нет. Выключить «Telegram» — учётки не подключаются, данные остаются до «Выйти».
