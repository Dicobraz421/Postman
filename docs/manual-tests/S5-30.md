# S5-30. Настройки: Общие, Безопасность, Внешний вид

Статус: 🤖 частично (2026-11-06): шаги 1, 7 — сцены; владельцу — 2, 3 и части шагов 4, 5 (Проводник, внешний браузер); не проверены — 6, 8 (класс не определён), остальное в 4, 5

Release-сборка (журнал в файл — только без консоли), Ctrl+,.

1. Разделы слева по порядку макетов: Общие, Аккаунты, Чтение, Просмотр вложений, Календарь, Категории, Быстрые фильтры и сроки,
   Безопасность, Клавиатура, Внешний вид, затем Подписи, Правила, Автоответы; поиск «пароль», «шрифт», «mailto» находит.
2. Общие: «Запускать вместе с Windows» — в «Диспетчер задач → Автозагрузка» появился Postman; выйти и войти в Windows —
   окно свёрнуто. Выключить — пропал.
3. «Сделать Postman клиентом по умолчанию» — открылись «Приложения по умолчанию»; выбрать Postman для MAILTO. Щелчок по
   `mailto:кто@corp.example?subject=Тест` в браузере — новое письмо во вкладке Postman (и когда Postman уже открыт).
4. «Открыть папку журнала» — `%LOCALAPPDATA%\Postman\logs`, в ней `postman-ДАТА.log`. Уровень «Отладка», перезапуск —
   записей больше. «Собрать отчёт» — zip на рабочем столе, «Показать файл» выделяет его; в архиве нет адреса ИБ.
5. Уведомления, тихие часы, звук, канал — выбор запоминается (пометка «сохраняется»); «Проверить» открывает страницу
   сборок.
6. Безопасность: картинки — «Никогда» или «Спрашивать»; выключить «Разрешить сохранение файлов с макросами» — в просмотре файла
   с макросами вместо «Сохранить…» — строка «Сохранение … выключено». Песочница — «Полная»; при частичной — «Как
   включить полную» показывает команду icacls. «Сбросить сохранённые входы» → «Сбросить» — при следующем запуске
   спросит пароль.
7. Внешний вид: акцент «Бирюзовый» — главные кнопки, ссылки, переключатели и тонированные кнопки бирюзовые сразу (и в
   тёмной теме — приглушённо); размер шрифта 12…18 (по умолчанию 14) — список и письмо меняются сразу; плотность —
   «Компактная» и «Обычная» (была «Удобная» — стала «Обычная»); аватары и превью выключаются (в компактной —
   недоступны); KeyTips выключить — плашек нет; задержка 0,8 с — плашки позже.
8. Безопасность: TLS 1.3 — новое подключение к стенду только по TLS 1.3; пароль «Не хранить» — сохранённый удалён,
   при запуске спросит. Политика: `reg add HKCU\Software\Policies\Pets\Postman /v MinTls /d 1.3` (и `ExternalImages`
   = `ask`, `StorePasswords` = `0`) — после перезапуска выбор недоступен, «Задано организацией».
