# S7-09. Приёмка S7: три учётные записи рядом, бюджеты, инструкция

Статус: ⏳

Release-архив из CI этого PR (или `cargo build --release -p postman-gpui -p postman-worker`). Учётки: Stalwart
(`user1@itt.test`, JMAP), тот же стенд по IMAP + CalDAV (`user2@itt.test`), Exchange компании — тестовая учётка. Письма
и встречи — только между тестовыми учётками; созданное в конце удалите. Обе темы.

1. Вход в три вида сервера по `docs/USER-GUIDE.md` «Учётные записи»: первый запуск — адрес стенда (без схемы),
   `user1`; «Настройки → Аккаунты → Добавить аккаунт» — `imaps://<стенд>` и `user2`; ещё раз — домен почты Exchange и
   адрес тестовой учётки. Ожидание: каждая подключается без правки адреса руками (IMAP — с найденным CalDAV, Exchange —
   через Autodiscover), в дереве папок — три группы; подсказки поля «Адрес сервера» совпадают с инструкцией.
2. «Нет у сервера — нет на экране»: выберите папку каждой учётки по очереди. Ожидание: у Exchange нет «Задач»,
   «Мои контакты», правил, автоответа, категорий; у IMAP нет «Справочника», правил, автоответа, «Отправить позже»; у
   Stalwart — всё. Клавиша скрытой команды (например, «Задачи» у Exchange) — тост «Нет у сервера этой учётной записи».
3. Письмо по кругу: из Exchange — на `user1`, из `user1` — ответ на тестовую учётку Exchange, из `user2` (IMAP) — на
   `user1`. Поле «От» выбирает учётку. Ожидание: доходят все три; у Stalwart — сразу, у IMAP во «Входящих» — сразу,
   у Exchange — не позже 2 минут; «Отменить» в течение 10 с отменяет отправку у IMAP и Exchange.
4. Календарь: новая встреча из учётки Exchange со второй тестовой учёткой Exchange, затем — из `user2` (CalDAV) с
   `user1`. Ожидание: календари всех учёток — в одном календаре, списком слева; встречи видны у получателей,
   ответ «Принять» доходит организатору. Удалите встречи.
5. Холодный старт с кэша: закройте Postman, запустите снова (с тремя учётками). Ожидание: список писем — меньше чем
   за секунду, без «зависания» окна, пока учётки подключаются; диспетчер задач через минуту простоя — «Память»
   `postman.exe` заметно меньше 150 МБ, ЦП — 0 %.
6. Размер: `postman.exe` в архиве — не больше 53 МиБ (55 574 528 байт), `postman-worker.exe` — не больше 11 МиБ
   (11 534 336 байт); замер S7-09 — 52,24 и 10,13 МиБ (`docs/SIZE.md` «После S7»).
7. Инструкция: `docs/USER-GUIDE.md` «Учётные записи» — таблица и ограничения совпадают с увиденным в п. 1–4.
