# CMF-01. Беседа — заглушить / вернуть звук

Статус: ⏳ (ручная проверка — владелец, Windows и macOS)

1. Беседа во «Входящих» с непрочитанным письмом. Палитра команд (Ctrl+K) → «Беседа: заглушить / вернуть звук» (или
   меню письма → «Заглушить беседу»): тост «Беседа заглушена…», в строке — значок «без звука», число непрочитанных у
   «Входящих», в трее (Dock, строке меню) уменьшилось.
2. Второй клиент отвечает в эту беседу: письмо пришло без уведомления и звука, счётчик не вырос, у письма — значок.
3. Во втором клиенте (Thunderbird, веб) у писем беседы видно ключевое слово `$muted`.
4. «Вернуть звук беседы»: значок пропал, счётчик вернулся; следующее письмо беседы — с уведомлением.
5. «Отменить» в тосте возвращает как было.
6. Правило сервера кладёт письма беседы в папку «Проекты»: заглушить беседу, второй клиент отвечает — письмо в
   «Проектах» со значком «без звука», без уведомления; у него в другом клиенте — `$muted`.
