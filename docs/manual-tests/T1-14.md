# T1-14. «Вид беседы» — в меню письма

Статус: 🤖 (2026-11-06): шаги 1, 2 — сцены; шаг 3 исправлен (меню папки теперь есть)

1. ПКМ по письму → «Вид беседы ▸ Лента / Стопка / Как Outlook / По умолчанию»: галочка у своего вида папки, у «По умолчанию» справа — вид из настроек.
2. Выбрать «Как Outlook» — список и чтение папки письма сразу в этом виде; «По умолчанию» — снова общий вид.
3. ПКМ по папке — открывается меню папки, не меню письма (пункты папки — T1-04д, S8-15, S8-32).
