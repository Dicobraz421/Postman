# T1-05б. Ширины панелей — разделители

Статус: ⏳

1. Между папками и списком, списком и чтением — разделитель: курсор «влево-вправо», тянется мышью; уже минимума не сжимается.
2. Двойной щелчок по разделителю — ширина макета.
3. Перезапуск — ширины те же. Узкое окно — сначала ужимается чтение, затем список.
