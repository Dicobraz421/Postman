# S5-12.1д. S/MIME ГОСТ без СКЗИ: отзыв по CRL

Статус: ⏳

Живой ящик, компьютер **без** КриптоПро CSP и ViPNet CSP. Нужны: корень тестового УЦ ГОСТ в `CurrentUser\Root`,
два письма от подписантов этого УЦ — действующий и отозванный сертификат, в сертификатах — адрес CRL `http://…`
(CDP), CRL УЦ лежит по этому адресу.

1. Откройте письмо действующего подписанта: текст виден сразу, значок «Подписано»; щелчок по значку — карточка,
   строка отзыва «не отозван · проверено <дата и время>», движок — «Postman, без СКЗИ (реализация не сертифицирована)».
2. Письмо отозванного подписанта: значок и заголовок карточки — «Сертификат отозван» (красный), строка отзыва —
   «отозван».
3. Отключите сеть (или адрес CRL недоступен) и откройте письмо **нового** подписанта того же УЦ: текст виден сразу,
   «Проверка подписи…» не дольше ~8 с, затем строка отзыва «не проверен (ГОСТ без СКЗИ)».
4. Снова откройте письма шагов 1–2 без сети: итог тот же, без ожидания (из кэша).
5. CRL, подписанный не тем УЦ (подмените файл по адресу CRL), — у нового письма «не проверен (ГОСТ без СКЗИ)».
6. Тёмная тема (шаги 1–3): строки читаются, красная — только у отозванного.
