# T1-04д. Папки — новая, переименовать, перенести

Статус: ⏳

Живой ящик (Exchange, тестовая папка).

1. ПКМ по папке → «Новая папка»: поле под ней; имя, Enter — папка появилась (в Outlook — тоже). Esc — отмена.
2. ПКМ → «Переименовать»: поле на месте строки, Enter — новое имя. У Входящих, Отправленных и т. п. пункт недоступен.
3. Перетащить папку на другую — стала подпапкой; на подпись учётки — на верхний уровень. Ролевую не перетащить.
4. Отказ сервера — тост с причиной.
