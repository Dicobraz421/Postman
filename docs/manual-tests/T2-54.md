# T2-54. Чтение

Статус: ⏳ (вид — 🤖 снимок `settings-reading`)

1. «Группировать в беседы» выключить — в папке каждое письмо строкой, в панели чтения нет «Беседа (N)»; включить —
   как было.
2. «Показывать цитаты по умолчанию» — лента беседы открывается с цитатами; «Скрыть цитаты» — скрыты.
3. «Отмечать прочитанным: через 2 с» — открыть непрочитанное и сразу перейти к другому: первое осталось
   непрочитанным; подождать 2 с — прочитано. «Вручную» — не меняется само. «Сразу» — как раньше.
4. Навести на ссылку в письме — внизу панели чтения полный адрес; увести — пропал. Выключить настройку — нет строки.
5. «По умолчанию» — всё вернулось (лента, справа, через 2 с…).
