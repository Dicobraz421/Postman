# S6-04. Быстрое добавление задачи

Статус: 🤖 (2026-11-06): шаги 1–5 — сцены

Демо-ящик, «Задачи» → «Сегодня», обе темы, русский и английский интерфейс (`--lang en`).

1. В строке «Добавить задачу» набрать «Отправить КП завтра 10:00 #Клиенты !»: под полем — чипы «завтра», «10:00»,
   «#Клиенты» (цвет категории), «!», ниже — итог «Пятница, 23 октября, до 10:00 · Клиенты · важно». Enter — задача
   с этим сроком, категорией и «!», название — «Отправить КП».
2. × на чипе «завтра» — он снова часть названия, срок — по времени (сегодня, если 10:00 ещё впереди, иначе завтра).
3. «#rkbtyns» (набрано в английской раскладке) — категория «Клиенты». «Глава 7.2 договора» — без срока.
4. «в пт», «через 3 дня», «15.11», «15 ноября», «утром» / «вечером» (часы — из «Настройки → Календарь»).
5. Английский интерфейс: «Call tomorrow at 3pm #clients !».
