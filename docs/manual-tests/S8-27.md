# S8-27: «Настройки → Просмотр вложений», подпись модуля

Модуль: `fb2.wasm` и `fb2.json` (сборка `viewers/`, см. `viewers/README.md`); `postman-viewer.exe` — рядом с
`postman.exe`.

1. «Настройки → Просмотр вложений» (после «Чтение»): встроенные форматы справкой; «Модулей нет. Положите файл .wasm
   в папку модулей.»; «Открыть папку модулей» — открывается `%LOCALAPPDATA%\Postman\viewers` (папка создаётся).
2. Положить `fb2.wasm` и `fb2.json` в эту папку, перезапустить Postman: в разделе — «FB2 · 1.0 · сторонний»,
   форматы и папка, выключатель включён.
3. Письмо с книгой `.fb2`: «Просмотр» — книга главами; в шапке — «Просмотр: модуль «FB2» 1.0 (сторонний) · в
   песочнице».
4. Выключить модуль: та же книга — карточка «нет просмотра» со ссылкой «Включить модуль «FB2»»; щелчок — модуль
   включён, книга открыта модулем.
5. Модуль от администратора (`%ProgramFiles%\Postman\viewers`): пометка «от администратора», в шапке просмотра — без
   «(сторонний)».
