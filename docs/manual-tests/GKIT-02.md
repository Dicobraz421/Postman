# GKIT-02. Postman на gpui-kit 0.9.1 — снимки и ручная проверка на Windows

Статус: ⏳ (стенд, владелец)

1. Снимки до и после: на `main` и на ветке PR — `cargo run -p postman-gpui -- --screens <каталог>` (все сцены), выход 0.
   Сравнить попарно; отличий быть не должно, кроме сглаживания текста.
2. Таблица сеткой и картинки в письме (T3-06, T3-07, блоки поля форка gpui-base):
   `POSTMAN_SCREENS_ONLY=compose-t306-grid,compose-t306-paste,compose-t306-table,compose-t307-sign-image cargo run -p postman-gpui -- --screens <каталог>`:
   таблица сеткой, картинка на месте, курсор обходит блок.
3. Колесо мыши в списке писем и в письме прокручивает; живой ресайз окна без мерцания (патч gpui-pre-windows).
4. «Настройки → Клавиши → Изменить»: нажатие Ctrl+Shift+K записывается как `ctrl-shift-k`; в русской раскладке
   сочетания команд (Ctrl+Е → Ctrl+E) срабатывают.
5. `POSTMAN_KEYLOG=1`: в строке состояния — сочетание и действие.
