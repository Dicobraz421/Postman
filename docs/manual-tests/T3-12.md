# T3-12. Самообновление (MSI и portable)

Статус: ⏳ (вид — 🤖 снимки `update-available`, `update-downloading`, `settings-updates`). Нужен выпуск с ключом: в
сборке `UPDATE_PUBLIC_KEYS` не пуст, у выпуска есть `.minisig`. Нужны два выпуска: установленный (старше) и новый.

Без ключа (как сейчас)
1. «Настройки → Общие → Обновления»: «Проверить обновления» — тост «В этой сборке нет ключа подписи…»; в журнале
   `update: no signing key`; сетевых запросов к GitHub нет (Монитор ресурсов → Сеть, `postman.exe`).

MSI (для всех, Program Files)
2. Поставить старый `.msi`, запустить. Через минуту — тост «Вышла версия X · Установить» (если сутки с прошлой проверки
   прошли; для повтора удалить `%LOCALAPPDATA%\Postman\updates\state.json`).
3. «Установить» — полоса «Скачивается Postman X · N из M МБ»; «Отменить» останавливает, полоса пропадает, «Установить»
   можно нажать снова из истории уведомлений (🔔) или в «Настройках».
4. «Установить» до конца — окно закрывается, Windows спрашивает разрешение (UAC) — «Да»; MSI ставится без вопросов,
   Postman запускается сам — тост «Postman обновлён до версии X», в «Настройках» версия новая, вкладки на месте.
5. На шаге 4 «Нет» в UAC — Postman запускается прежней версией с тостом «Не удалось обновить до версии X: …».

Portable (архив, `install.ps1`, без прав администратора)
6. Распаковать старый `.zip`, выполнить `install.ps1` — в `%LOCALAPPDATA%\Programs\Postman` лежит `postman.portable`.
   Запустить.
7. Шаги 2–4: скачивается `.zip`, UAC не спрашивается, файлы в папке заменяются, `postman.portable` на месте, ярлык в
   «Пуске» запускает новую версию, песочница работает (письмо с вложением открывается).
8. Копия из архива до метки (нет `postman.portable`, есть `install.ps1`) — тоже обновляется из `.zip`, не из MSI.
9. Распакованный архив без `install.ps1`-установки (запуск из папки распаковки) — обновляется там же из `.zip`.

Выключатели
10. «Проверять обновления автоматически» выключить, перезапустить — через минуту и дальше запросов нет; «Проверить
    обновления» работает: «Установлена последняя версия» или «Вышла версия X».
11. Политика: `HKLM\Software\Policies\Pets\Postman`, `AllowUpdate` = 0 (DWORD) или "0" (строка); прежний ключ
    `Software\Policies\Aahz\Postman` — запасной, в журнале WARN (POL-01); перезапуск — выключатель заперт с пояснением «выключено политикой», кнопки
    «Проверить обновления» нет, сетевых запросов нет.
12. Канал «Предварительный» — предлагается бета; «Стабильный» — бета не предлагается. Нет сети — фоновая проверка
    молчит (только журнал), кнопка — «Не удалось проверить обновления: …».
13. Выпуск без `.minisig` или с чужой подписью не предлагается и не запускается.
