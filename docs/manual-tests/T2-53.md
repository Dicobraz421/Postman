# T2-53. Категории: авто-назначение

Статус: ⏳ (вид — 🤖 снимок `settings-categories`; правило из полей — 🤖 тест `auto_assign_rule`)

1. «Настройки → Категории» → новая категория «Партнёры», домен отправителя «partner.ru», тема «партнёр»,
   «Применить к уже полученным — подходит N» — сохранить: у N писем категория, в «Правилах» — правило категории.
2. Письмо с адреса @partner.ru — пришло с категорией.
3. Стереть оба поля, сохранить — правило ушло из «Правил».
4. Столбец «Писем» совпадает с числом писем с категорией в списке.
