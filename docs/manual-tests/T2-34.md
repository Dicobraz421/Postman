# T2-34. Командная строка задач: «Запланировать», «В проект», «Вид», порядок, «+» проекта

Статус: ⏳ (вид — 🤖 снимки `tasks`, `tasks-sort`, `tasks-view`, `tasks-project-new`)

1. Выбрать задачу: «Запланировать» — блок в календаре; «В проект» — варианты проекта в карточке.
2. «Вид: список» — меню; «Плотный список» — строки в одну линию, подпись «Вид: плотный»; «Список» — как было.
3. «По сроку ▾» над списком — «По названию», «Сначала важные»: порядок внутри групп меняется. Другой раздел — снова свой
   порядок («Вручную» во «Входящих», «По дате выполнения» в «Выполненных», «По статусу» в «Поручениях»).
4. «+» у «Проекты» — поле; «Бюджет 2027», Enter — открыт пустой проект, он слева; добавить задачу — она в проекте.
   Esc в поле — ничего не создано.
5. Окно уже (около 1200 px): поле поиска сжимается, кнопки и «Вид» целиком.
