# CMF-02. Закрепить / открепить

Статус: ⏳ (ручная проверка — владелец, Windows и macOS)

1. Во «Входящих» меню письма → «Закрепить»: письмо — вверху группой «Закреплённые», над датами, со значком булавки.
2. Сортировка «По отправителю», «По размеру»: «Закреплённые» вверху, ниже — «Остальные».
3. Вид «В списке, как Outlook»: закрепить строку беседы — вверху вся беседа.
4. Закрепить 20 бесед, 21-ю — тост «В папке уже 20 закреплённых…».
5. Второй клиент: у письма ключевое слово `pm.pin`; закреплённое там — закреплено и в Postman после синхронизации.
6. «Открепить» и «Отменить» в тосте.
7. «Все папки»: закреплённые письма разных папок — вверху группой «Закреплённые», ниже — группы папок.
8. Поиск (Ctrl+E) по слову из закреплённого письма: оно первым, группой «Закреплённые».
