# T1-16б. Порядок писем в беседе

Статус: 🤖 частично (2026-11-06): шаги 2, 3 — сцены; не покрыт — 1 («Сначала новые»)

1. Настройки → Чтение → «Порядок в беседе»: «Сначала новые» — лента и стопка от нового письма к старому (дни — тоже).
2. Кнопка «Сначала старые / Сначала новые» в строке беседы меняет ту же настройку.
3. При «Сначала новые» Ctrl+→ ведёт к более старому письму, Ctrl+← — к более новому.
