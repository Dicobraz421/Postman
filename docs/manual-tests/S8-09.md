# S8-09: первый запуск на кэше формата 5

1. Сборка до S8 (формат 5) с живой учётной записью: открыть, дождаться синхронизации, закрыть.
2. Запустить сборку с S8-09.
   Ожидание: окно появляется сразу; в строке состояния «Обновление хранилища: N %», проценты растут; по
   окончании — папки и письма учётной записи, синхронизация идёт как обычно.
3. Рядом с кэшем — `*.v5.bak` (прежний файл без изменений).
