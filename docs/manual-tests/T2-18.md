# T2-18. Время встречи в строке списка

Статус: ⏳ (формат и отбор — 🤖 тесты, вид — 🤖 снимок `list`; живой сервер — владелец)

1. Пришло приглашение (JMAP / IMAP / Exchange): в строке списка вместо превью — значок календаря и «День, число
   месяца · начало–конец». Пояс — как в календаре.
2. Встреча на весь день — «· Весь день». Отмена встречи — «Отменена · …».
3. Старое приглашение, которое ещё не открывали: время появляется, пока список открыт (без открытия письма).
4. Перезапуск: время сразу, без ожидания.
5. Обычные письма — с превью, как раньше; шифрованное — «Зашифрованное письмо».
