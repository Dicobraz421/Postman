# T1-10в. Картинка письма — размер из HTML, не шире колонки

Статус: 🤖 частично (2026-11-06): шаги 1, 4 — стенд (ширина по снимку); сцена по условию ширины картинок снята — не сошлась, причина не выяснена (D6), шаг 3 не закрыт; не покрыт — 2

Обе темы. Письма — тестовые, со своего тестового ящика.

1. Подпись-таблица из Outlook с логотипом, у которого в HTML задан размер меньше кадра (`width`/`height` или `style`
   в дюймах). Ожидание: логотип в заданном размере, как в Outlook, а не в размере кадра.
2. Письмо с картинкой, у которой задана только ширина. Ожидание: высота по пропорции, картинка не искажена.
3. Картинка с заданной шириной больше панели чтения; двигайте разделитель и меняйте размер окна. Ожидание: картинка
   по ширине колонки, пропорции сохранены, горизонтальной прокрутки нет.
4. Картинка без размеров в HTML. Ожидание: как в T1-10 — свой размер, не шире колонки.
