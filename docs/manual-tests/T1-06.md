# T1-06. Панель папок: группа своей учётки сворачивается

Статус: ⏳

Живой ящик (стенд) с общим ящиком или второй учётной записью. Обе темы.

1. Щёлкните подпись своей учётной записи над папками. Ожидание: шеврон «▸», её папки скрыты, справа —
   непрочитанные всех её папок; щелчок ещё раз — папки снова видны, шеврон «▾».
2. Сверните свою группу, когда открыта её папка. Ожидание: подпись группы — выбранная (заливка, полужирный).
3. Сверните ветку общего ящика или второй учётки, затем Ctrl+Y или палитра (Ctrl+K) → папка этой ветки.
   Ожидание: ветка разворачивается, папка выбрана и видна в дереве.
4. Сверните группы, переключитесь в «Календарь» и обратно. Ожидание: свёрнутые остались свёрнутыми (до выхода из
   Postman).
