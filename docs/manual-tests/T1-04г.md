# T1-04г. Панель папок — дерево по вложенности

Статус: 🤖 частично (2026-11-06): шаги 1–3 — сцены; Exchange — порядок папок как в Outlook (шаг 1); шаг 3 — Ctrl+Y, сцена `mail-t104-go` (решение владельца 2026-11-06, п. 7)

1. Exchange (и демо): подпапки — под родителем с отступом 16 px на уровень, порядок — как в Outlook.
2. Шеврон ▾/▸ у папки с подпапками сворачивает и разворачивает её; после перезапуска — снова развёрнуто.
3. «Перейти к папке» (Ctrl+Y, как в Outlook; палитра Ctrl+K тоже) — переход в папку внутри свёрнутой разворачивает родителей. Счётчики непрочитанных — как раньше.
