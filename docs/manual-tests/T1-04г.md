# T1-04г. Панель папок — дерево по вложенности

Статус: 🤖 частично (2026-11-06): шаги 1–3 — сцены; Exchange — порядок папок как в Outlook (шаг 1); в шаге 3 Ctrl+Y нигде не назначен (находка F1, решение владельца), Ctrl+K работает

1. Exchange (и демо): подпапки — под родителем с отступом 16 px на уровень, порядок — как в Outlook.
2. Шеврон ▾/▸ у папки с подпапками сворачивает и разворачивает её; после перезапуска — снова развёрнуто.
3. Палитра (Ctrl+Y) — переход в папку внутри свёрнутой разворачивает родителей. Счётчики непрочитанных — как раньше.
