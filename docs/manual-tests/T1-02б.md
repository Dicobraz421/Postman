# T1-02б: «Войти как пользователь Windows»

Машина в домене, учётка Exchange (EWS).

1. «Добавить аккаунт»: адрес EWS (`https://…/EWS/Exchange.asmx`) → «Продолжить». На шаге «Логин» — выбор «Войти как
   пользователь Windows (без пароля)» и «Войти с паролем»; при выборе Windows логин подставляется (UPN, можно
   поправить), кнопка — «Проверить и подключить», шага «Пароль» нет.
2. Вход проходит без пароля; в «Диспетчере учётных данных» Windows записи `Postman:…` для этой учётки нет.
3. «Настройки → Аккаунты» — строка «Учётная запись Windows — без пароля».
4. Перезапуск Postman — пароль не спрашивается, синхронизация идёт.
5. Вне домена (или адрес не EWS) — выбора нет, вход с паролем как раньше.
6. Отказ входа Windows (учётка не пускает текущего пользователя) — строка «Не удалось войти учётной записью Windows —
   введите пароль», открыт шаг «Пароль».
