# T1-18. Вложение перетаскивается в другое приложение

Статус: ⏳

Демо (`--demo`) и живой ящик.

1. Письмо с PDF и картинкой. Нажать на карточку PDF и повести мышь: курсор перетаскивания Windows. Бросить в
   Проводник (рабочий стол, папка) — появился тот же файл (имя, размер, открывается). Повторить с картинкой.
2. Бросить PDF в документ Word — вставлен файл (объект или содержимое — как у Outlook). Бросить картинку в окно
   браузера на страницу загрузки файла (почта, облако) — загружен тот же файл.
3. Esc во время перетаскивания — отмена, ничего не появилось. Короткий щелчок по карточке — просмотр, как раньше.
4. Живой ящик, письмо с вложением, которое ещё не скачивалось (новое письмо, просмотр не открывался): повести —
   курсор «нельзя», через миг тост «… загружено — перетащите его ещё раз»; повторное перетаскивание работает.
5. Книга с макросами (красный щиток) и `.exe` — не перетаскиваются (как и не открываются).
6. `%TEMP%\Postman\drag` после выхода из Postman пуст или отсутствует.
