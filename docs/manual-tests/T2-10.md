# T2-10. Уведомления о новых письмах

Статус: ⏳ (тесты моделей — 🤖; живой ящик — владелец)

1. Postman свёрнут, «Новые письма: Все»: пришло письмо — уведомление Windows «отправитель — тема»; несколько сразу —
   «Новых писем: N» и первые три. В 🔔 Postman — запись.
2. «Только важные»: письмо с @упоминанием вас, ответ в вашей беседе, письмо со сроком — уведомление; обычное — нет.
3. Тихие часы (поставьте текущий час): уведомления не всплывают, в 🔔 — есть.
4. «Звук» включён — звук «Новое письмо»; выключен — молча.
5. Окно активно — уведомления Windows нет, в 🔔 — запись. Перезапуск — старые письма не всплывают.
