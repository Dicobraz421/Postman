# T2-29. Вложения

Статус: ⏳ (вид — 🤖 снимки `attach-macro`, `preview-pdf`, `preview-zip`; очистка — 🤖 тест на `budget.xlsm`)

1. Письмо с `.xlsm`/`.docm`: просмотр → «Открытие заблокировано» → «Открыть без макросов» — Excel/Word открывает
   `.xlsx`/`.docx` без предупреждения о макросах; данные на месте. У `.xls` с макросами кнопки нет.
2. ZIP: открыть просмотр, закрыть — на карточке «… · Архив: N файлов».
3. PDF: «+» до 200 % — страница крупнее, прокрутка вбок; «−» до 50 %.
4. Письмо из беседы (лента): щелчок по вложению — просмотр открывается.
