# S8-16: вопрос после переноса, ход, пауза, отмена, значки

Стенд: две живые учётки (JMAP или IMAP и Exchange), у цели — квота.

1. Перенос в «На этом компьютере» — без вопроса; в строке состояния «Перенос: N из M · …»; в конце тост «N писем —
   только на этом компьютере».
2. Перенос в папку другой учётки — над списком папки цели полоса «N писем перенесены из «Учётка · Папка»» с кнопками
   «Перенести на сервер «…»» и «Оставить локальным архивом»; у Exchange-цели — «· Метки Postman на Exchange не
   сохранятся». Открыть другую папку — полосы нет; вернуться — есть. Закрыть Postman и открыть — вопрос на месте.
3. «Перенести на сервер»: строка состояния — ход; щелчок по ней — полоса «Перенос в «…»» с «Пауза», «Остановить»;
   Esc или щелчок — скрыть. «Пауза» — «Перенос на паузе», значки строк — «Перенос на паузе»; «Продолжить» — идёт.
4. Выход посреди выгрузки и запуск — перенос продолжается с того же места, без дублей на сервере цели.
5. «Остановить» → «Остановить перенос: готово X из Y»: «Не останавливать» (и Esc) — продолжается;
   «Вернуть на место» — письма вернулись в папку источника, тост «N писем возвращены в «…»»; в другом прогоне
   «Оставить остальные локально» — остаток со значком «только на этом компьютере».
6. Квота цели почти полна: полоса «На сервере «…» нет места: осталось N писем · …» появляется сама, в строке
   состояния — значок и жирное «Перенос стоит: нет места». «Оставить локально» — остаток локальным архивом.
7. Конец: тост «Перенесено на сервер «…»: N писем» и «У «…» письма удалены после ответа «…»».
8. Первый запуск на кэше формата 5: вместо списка «Обновление хранилища: N %» с полосой, затем папки.
