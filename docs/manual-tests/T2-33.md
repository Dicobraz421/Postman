# T2-33. История задачи, «Перенести на сегодня», вложение к результату

Статус: ⏳ (вид — 🤖 снимки `tasks`, `task-history`, `delegation-steps`; запись истории — 🤖 тест
`history_round_trips_and_merges_subtasks`; живой сервер — владелец)

1. Новая задача (Ctrl+N) — внизу карточки «Создана · ЧЧ:ММ». Поменять срок (Insert) — «Срок перенесён с … на …».
   Отметить подзадачу — «Подзадачи: 1 из 3»; ещё одну — та же строка, «2 из 3». «История · N» — все записи, новые сверху.
2. Перезапустить Postman (или открыть задачу на другом компьютере): история та же (хранится в задаче на сервере).
3. «Сегодня» с просроченными: «Перенести на сегодня» у «Просрочено» — все на сегодня, тост с «Отменить»; «Отменить» —
   сроки прежние. Просроченное письмо со сроком — срок письма тоже сегодня.
4. Коллега-исполнитель отвечает «Готово» письмом с файлом (из Postman — ответом на письмо поручения с вложением, или из
   Outlook). Открыть это письмо в почте. В «Я поручил» у поручения под «Результат» — файл с размером; щелчок — письмо.
