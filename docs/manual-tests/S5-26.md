# S5-26. Правила: действие «Категория»

Статус: 🤖 (2026-11-06): шаг 1 — сцены, шаги 2, 3 — стенд

Живой ящик (`POSTMAN_URL`…); шаг 1 — и в демо.

1. Настройки → Правила → «Новое правило»: в «Тогда» есть «Поставить категорию»; под ним — категории таблицы с цветными
   точками; без выбора «Сохранить» пишет «Выберите категорию.». В списке правило читается «… → поставить категорию
   «Тендеры»».
2. Правило «Тема содержит тендер → категория Тендеры», сохранить. Написать себе письмо с темой «тендер проверка»:
   письмо приходит во «Входящие» с меткой «Тендеры» (розовая полоса и метка в строке).
3. Удалить правило — следующее такое письмо приходит без метки.
