# T2-15. Ответ с комментарием и без ответа организатору

Статус: ⏳ (форматы и итог — 🤖 тесты; живые серверы — владелец)

1. Письмо-приглашение → ▾ у «Отклонить» → «Отклонить с комментарием…» → текст → «Отправить»: организатор
   (Outlook, The Post) видит отказ с вашим текстом.
2. ▾ у «Принять» → «Принять без ответа организатору»: встреча в вашем календаре принята, у организатора ответа нет,
   в «Отправленных» и «Черновиках» ничего нового.
3. То же из календаря: подробности приглашения → «Другие ответы ▾».
4. Письмо-приглашение в беседе (лента «Беседа (N)» включена): карточка с кнопками видна над лентой.
