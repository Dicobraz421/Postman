# LIN-03. Системные возможности Linux

Статус: ⏳ (стенда с Linux нет — решение 2026-11-12-linux: GNOME на Wayland и KDE, когда появится)

GNOME 47+ (Ubuntu 24.10+ или Fedora 41+) и KDE Plasma 6. Сборка — артефакт `postman-…-linux-x64` прогона CI «Linux»
PR LIN-03: распаковать в `~/opt/postman`, `postman.desktop` положить в `~/.local/share/applications` и указать в нём
`Exec=/home/<имя>/opt/postman/postman %u`. Запуск — из меню приложений. Нужен живой ящик (шаги 1, 3, 6).

1. Пароль в хранилище. Войти в учётную запись с «Запомнить». GNOME: «Пароли и ключи» (Seahorse) → «Вход»: запись
   Postman. Перезапуск Postman — вход без пароля. `killall gnome-keyring-daemon` (KDE — остановить KWallet), перезапуск:
   строка входа с понятной причиной, файла с паролем в `~/.local/share/Postman` нет (`grep -r` по паролю — пусто).
2. Почта по умолчанию. «Настройки» → «Общие» → «Сделать почтовой программой по умолчанию». В терминале
   `xdg-mime query default x-scheme-handler/mailto` → `postman.desktop`. Ссылка `mailto:a@b.example` в браузере —
   открылось новое письмо в уже запущенном Postman (второго окна нет).
3. Автозапуск. «Запускать при входе в систему» — включить: есть `~/.config/autostart/postman.desktop`. Выйти и войти —
   Postman открылся сам. GNOME Tweaks → «Автозапуск» выключить → в Postman переключатель выключен. Выключить в Postman —
   файла нет.
4. Журнал и «Показать в папке». Запуск из меню: «Настройки» → «Общие» → «Папка журнала» — открылась
   `~/.local/state/Postman`, в ней `postman-<дата>.log` со строками. Сохранить
   вложение, «Показать в папке» — Nautilus/Dolphin с выделенным файлом.
5. Тема и акцент. «Внешний вид» → «Как в системе». GNOME «Настройки» → «Внешний вид» → «Тёмный» — Postman тёмный сразу;
   акцент → фиолетовый — кнопка «Новое письмо» фиолетовая. KDE: «Цвета» Breeze Dark и акцент — то же.
6. Уведомления. Свернуть Postman, отправить себе письмо — уведомление среды «Postman» со звуком; «Звук» в «Общих»
   выключить — без звука.
7. Буфер и перетаскивание. Скопировать таблицу из Firefox и из LibreOffice Writer, вставить в новое письмо — таблица
   сеткой (X11 и Wayland). Перетащить файл из Nautilus в новое письмо — вложение добавлено. Перетащить вложение из
   Postman наружу — пока нет (gpui на Linux не умеет источник перетаскивания), вложение — «Сохранить как».
8. Клавиши. Раскладка «Русская»: Ctrl+N (Ctrl+Т) — новое письмо, Ctrl+Enter — отправить, Ctrl+F — поиск. Удержать
   Ctrl — подсказки клавиш.
9. Окно. Перетаскивание за заголовок, двойной щелчок — развернуть, «─ □ ✕», край окна тянет размер (GNOME Wayland и
   X11, KDE).
10. Политика (по желанию, root): `sudo mkdir -p /etc/postman` и
    `echo '{"StorePasswords":0,"SandboxNamespaces":"required"}' | sudo tee /etc/postman/policies.json`. Перезапуск:
    «Безопасность» → «Хранить пароль» закреплён «не хранить»; журнал — `policy: sandbox namespaces are required`.
    Удалить файл.
11. Замер простоя (один раз): `~/opt/postman/postman --bench` → строка с `idle_cpu_pct=…` и `idle_private_ws_mb=…` —
    прислать целиком.
