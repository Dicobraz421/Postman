# S5-21. Календарь: виды, поиск, статусы

Статус: 🤖 частично (2026-11-06): шаги 1–7 — сцены демо, шаг 8 — стенд; не покрыто — повтор шагов 1–7 на стенде (по шапке файла)

Демо-ящик и живой ящик стенда, обе темы.

1. «Календарь» (Ctrl+2): над сеткой справа переключатель «День / Раб. неделя / Неделя / Месяц», правый край — по краю
   сетки, справа от него — поле «Поиск в календаре» над панелью события. Клавиши 1…4 (вне поля поиска) — те же виды;
   наведение — «Рабочая неделя (2)» и т. п.
2. «День» — одна колонка, заголовок «Среда, 21 октября 2026»; PgUp/PgDn — день назад и вперёд, Home — сегодня.
   «Неделя» — 7 дней, выходные затенены; «Раб. неделя» — рабочие дни из «Настройки → Календарь».
3. «Месяц» — клетки с числами; многодневное событие — полосой через дни (через неделю — продолжается в следующей
   строке), остальные — «время · тема» с точкой цвета; в людный день — «+N ещё». Щелчок по числу или «+N ещё» — этот
   день видом «День». PgUp/PgDn — месяц.
4. «Настройки → Календарь»: «Первый день недели — Воскресенье» — неделя, месяц и мини-месяц слева начинаются с
   воскресенья; «Шаг сетки 15 мин» — в часе четыре линии; «Показывать второй пояс» — слева вторая шкала часов;
   «Вид по умолчанию — Месяц» — календарь сразу переходит на месяц, после перезапуска открывается месяцем.
5. Выбранное событие светится по контуру; приглашение без ответа — без заливки, пунктирный контур и бледная полоса.
6. Событие с участниками: под «Участники · N» — значки с числами (✓ 2, ? 1…), подсказка «Приняли: 2»; «нет ответа» —
   серый кружок с точками. Приглашение без ответа: «Принять» — синяя заливка, «Под вопросом» и «Отклонить» — бледно-
   синие со значками.
7. Ctrl+E — курсор в поиске календаря; набрать «Переговорная 1» — вместо панели события список «Найдено: N» с датами,
   временем и местом; ↑/↓ — строка, Enter или щелчок — неделя события и его подробности. Esc — поиск очищен.
8. Живой ящик: поиск по слову из темы встречи на другой неделе — находит её («Ищу на сервере…», затем список);
   переход — неделя загружается, подробности открыты.
