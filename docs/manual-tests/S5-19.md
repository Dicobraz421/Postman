# S5-19. Тонированные кнопки

Статус: 🤖 частично (2026-11-06): шаги 1–4 — сцены; владельцу — 5 (высокая контрастность Windows)

Демо-ящик; светлая и тёмная тема.

1. Календарь → событие-приглашение: «Принять» залита акцентом, «Под вопросом» и «Отклонить» — светло-синие без рамки
   (тёмная — тёмно-синие), при наведении чуть темнее (светлее в тёмной).
2. Новая встреча, контакт (карточка и правка), Настройки (Общие, Категории, Клавиатура, Подписи, Аккаунты, Календарь),
   Правила, Автоответ, строка входа: рамочных кнопок нет, главная — одна, залита.
3. Выделить три письма: кнопки сводки справа — тонированные; «Удалить навсегда?» в «Удалённых» — «да» залита, «нет»
   тонированная.
4. Во всех местах текст кнопок читается; кнопка не сливается с подложкой (форма категории, строка вопроса письма).
5. Высокая контрастность Windows: кнопки — цветом выделения ОС.
