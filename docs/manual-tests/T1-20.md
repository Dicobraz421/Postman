# T1-20. Exchange: письмо, удалённое в другом клиенте, уходит из Postman

Статус: ⏳

Сборка CI этого PR. Учётка — тестовая учётка Exchange; второй клиент — Outlook (или OWA) с той же учёткой. Письма —
только себе, с меткой в теме; в конце удалите их и из «Удалённых».

1. Отправьте себе два письма («удалить 1», «удалить 2»). Дождитесь их во «Входящих» Postman, не открывайте.
2. В Outlook удалите «удалить 1» (Del — в «Удалённые») и «удалить 2» насовсем (Shift+Del).
3. Сразу выберите «удалить 1» в Postman. Ожидание: письмо пропадает из списка, тоста об ошибке нет.
4. Подождите до 2 минут (опрос) или переключите сеть («снова на связи»). Ожидание: «удалить 2» пропадает из
   «Входящих» без действий; «удалить 1» — в «Удалённых» Postman; счётчики папок верные.
