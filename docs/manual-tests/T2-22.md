# T2-22. Отмена ответа, «Общие», строка состояния календаря

Статус: ⏳ (вид — 🤖 снимки `calendar`, `event-imip`; живой сервер — владелец)

1. Письмо-приглашение → «Принять»: тост «Принято · Ctrl+Z — отменить». В течение 5 с Ctrl+Z (или «Отменить» в
   тосте) — «Ответ отменён — не отправлен», кнопки ответа снова видны; организатору ничего не пришло. Без отмены —
   через 5 с обычный итог («Ответ ушёл …»).
2. Календарь общего ящика, открытый вам, — в группе «Общие», а не «Календари коллег».
3. Строка состояния в «Календаре»: вид, число событий, ждут ответа, отклонённых скрыто, пояс; меняется со сменой
   недели и ответами.
4. Наведение на блок коллеги: «Календарь <имя>: …»; на приглашение без ответа — «… — приглашение без ответа».
5. Приглашение в подробностях: «… приглашает вас · <день время>» — когда пришло письмо (письмо открывали или видели в
   списке). Внешний участник — с доменом под именем.
