# S8-33а: PST — пробный файл в Outlook

Статус: ✅ 2026-11-02 — шаги 2–5 пройдены: Outlook открыл без восстановления, письмо и вложение на месте; scanpst
(после S8-40): только несущественные несоответствия («Store created by build: (not available)» — закрыто в S8-33б).
Первый прогон scanpst — «Элементы, требующие восстановления: 1» (журнал — `docs/tasks/S8-40.md`). Решение №6:
Outlook открывает без восстановления — S8-33б сделан.

Итог — решение владельца по S8-33б (полный писатель — только если Outlook открывает файл без восстановления).
Файл собирает тест, адреса в нём — только `example.test`.

1. На Windows из корня репозитория (ветка этого PR):
   `set POSTMAN_EXPORT_SAMPLES=C:\tmp\pst` и `cargo test -p postman-export --test pst`.
   Ожидание: тесты зелёные, в `C:\tmp\pst` — `S8-33а пробный.pst`.
2. Скопируйте файл (Outlook дописывает в PST при открытии). Classic Outlook: «Файл → Открыть и экспортировать →
   Открыть файл данных Outlook» → копия.
   Ожидание: без предложения «Средства восстановления папок» и без ошибок; в дереве — файл «Postman».
3. Раскройте его. Ожидание: папка «Входящие» (и «Удалённые»), в ней одно непрочитанное письмо «Re: Отчёт за октябрь»
   от «Анна Иванова», со скрепкой, дата 30.10.2026.
4. Откройте письмо. Ожидание: тема, отправитель, «Кому: Пётр», «Копия: team@example.test», текст «Привет! Отчёт во
   вложении.», вложение «отчёт.txt» — открывается, в нём четыре строки «Строка отчёта».
5. Закройте Outlook. На второй копии (не открывавшейся) запустите `scanpst.exe`
   (`C:\Program Files\Microsoft Office\root\Office16\SCANPST.EXE`) → «Начать».
   Ожидание: «Ошибок не обнаружено» (или только «незначительные несоответствия» — записать какие).
6. Запишите результат шагов 2–5 (снимки сообщений, если были) в PR — это вход для решения по S8-33б.
