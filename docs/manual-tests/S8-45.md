# S8-45, S8-46. Расширения The Post: публикация календаря и занятость внешних

Статус: ⏳ ждёт волну `jmap-09` The Post (JMAP-19, JMAP-20) и календари JMAP.

1. Сервер с `urn:thepost:calendarpublish`: в календаре под «Доступом» есть «Публикация по ссылке». Другой сервер — группы нет.
2. «Создать ссылку: только занятость»: адрес показан один раз, «Скопировать ссылку» работает; после перезапуска адреса нет,
   запись в списке есть.
3. Открыть ссылку без входа: календарь или занятость соответствуют уровню. «Отозвать»: ссылка перестала работать.
4. Уровень выше политики организации: ошибка строкой, ссылка не создана.
5. Сервер с `urn:thepost:availability`: внешний участник с FBURL в справочнике или партнёрским шаблоном — занятость в помощнике
   без ссылки на вкладке. Адрес без данных — «Внешний адрес…», не «свободен».
