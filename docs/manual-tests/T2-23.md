# T2-23. Новая встреча: пояс, ссылка, черновик

Статус: ⏳ (вид — 🤖 снимки `meeting`, `meeting-zone`; комната и черновик — 🤖 тесты; живой сервер — владелец)

1. «Создать встречу» → «MSK (UTC+3) ▾» → «Екатеринбург»: время в полях то же, у получателя встреча — по поясу
   Екатеринбурга.
2. «Новая ссылка»: адреса сервиса нет — строка «Видеовстречи»; ввести `https://meet.компания.ru`, Enter — в «Место»
   ссылка комнаты по теме. Второй раз — сразу ссылка.
3. Заполнить тему и участников, подождать секунду: «Черновик сохранён ЧЧ:ММ». Закрыть вкладку (×), снова «Создать
   встречу» — поля на месте. «Удалить черновик» — следующая встреча пустая. Отправить — черновика нет.
4. Помощник: в строке «Вы» — названия ваших встреч; у сотрудника справочника — отдел после роли.
