# S8-30: MSG в Outlook

Статус: ❌ 2026-11-02 — открываются; `logo.png` не показывается, `отчёт.pdf` нет; вложенное письмо не видно;
подписанное — ошибка вложения и «Система безопасности не может найти ваше цифровое удостоверение» → S8-41.
⏳ 2026-11-03 — после S8-41 повторить шаги 2–5 (новые файлы — `C:\tmp\msg`).

До «Экспорта…» в интерфейсе (S8-32) файлы собирают тесты; адреса в них — только `example.test`.

1. На Windows из корня репозитория (ветка этого PR):
   `set POSTMAN_EXPORT_SAMPLES=C:\tmp\msg` и `cargo test -p postman-export --test msg`.
   Ожидание: тесты зелёные, в `C:\tmp\msg` — три файла `S8-30 *.msg`.
2. Откройте двойным щелчком «S8-30 письмо.msg». Ожидание: тема «Re: Отчёт за октябрь», отправитель «Анна Иванова»,
   «Кому: Пётр; ivan@example.test», «Копия: team@example.test», текст «Привет!…», вложения «отчёт.pdf» и «logo.png».
3. «S8-30 вложенное письмо.msg»: третье вложение «Исходное письмо» открывается письмом (тема, «Пётр», текст).
4. «S8-30 подписанное.msg»: открывается без ошибки формата, текст «Подписанное письмо для проверки S8-41.»; значок
   подписи. Outlook предупредит, что сертификату нет доверия, — это ожидаемо (самоподписанный тестовый).
5. Перетащите все три файла в любую папку Outlook. Ожидание: три письма в списке с темами и отправителями.
