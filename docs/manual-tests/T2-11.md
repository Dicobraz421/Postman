# T2-11. Черновик на правку и «Последняя вкладка»

Статус: ⏳ (вкладки и формат — 🤖 тесты, полоса и вкладка черновика — 🤖 снимки `reading-draft`, `draft-edit`;
живой сервер и перезапуск — владелец)

1. «Черновики» → письмо: над текстом «Черновик — не отправлен · Продолжить», быстрого ответа внизу нет.
2. «Продолжить», Enter в списке или двойной щелчок по строке: черновик открывается во вкладке письма (адресаты, тема,
   текст, вложения). Поправить → «Сохранить»: в «Черновиках» одна версия, не две. Повторное «Продолжить» —
   та же вкладка.
3. Отправить черновик: он уходит из «Черновиков», письмо — в «Отправленных».
4. Настройки → Общие → «Открывать при запуске: Последняя вкладка». Открыть: вкладку почты (Ctrl+T) на
   «Отправленных», «Настройки», сохранённый черновик; главную — в «Календаре». Закрыть Postman, открыть снова: те же
   вкладки, та же активная; главная — в «Календаре».
5. «Открывать при запуске: Входящие» → перезапуск: только главная вкладка на «Входящих».
6. Несохранённое письмо и новая встреча после перезапуска не возвращаются (их нет на сервере) — это ожидаемо.
