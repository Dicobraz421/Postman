# T2-26. Лента беседы

Статус: ⏳ (вид — 🤖 снимки `thread`, `thread-stack`; живой сервер — владелец)

1. Беседа лентой: сверху «N писем · участники · с даты»; у чужих писем — аватар; у писем с файлами — их имена и размер.
2. У последнего письма — «Ответить» и «Переслать»: ответ на него.
3. Цитаты скрыты: под письмом «··· цитата из письма от <кто>, <дата>».
4. Стопка: раскрыть несколько писем — у каждого его вложения.
