# T2-36. «Поручить»: должность и загрузка, Ctrl+N, «Отклонённые», строка состояния

Статус: ⏳ (вид — 🤖 снимки `delegate-suggest`, `delegation-new`, `delegations-in`, `delegation-steps`; группы — 🤖 тест
`tabs_and_own_only`; живой справочник — владелец)

1. «Поручить», в поле исполнителя — две буквы фамилии: подсказки с должностью под именем и загрузкой справа («2 в
   работе», «нет поручений»). Выбрать — под именем «должность · загрузка».
2. В карточке поручения под именем исполнителя (у меня) и автора (у исполнителя) — должность из справочника.
3. «Поручения», Ctrl+N — «Я поручил», форма «Новое поручение» с полем названия. Без названия «Поручить» — тост;
   Esc — ничего не создано. С названием и исполнителем — поручение в «Ждут принятия».
4. Отклонить поручение мне — оно в «Мне поручили» в группе «Отклонённые» (в конце).
5. Строка состояния: «Мне поручили» — «2 новых поручения» / «Новых поручений нет»; «Я поручил» — «В «Ждём»: N».
6. «Вернуть с комментарием», «Предложить срок», «Отклонить» — у кнопок подсказки («Статус станет «В работе»», «Пока
   автор не решит, срок прежний», «Задача уйдёт из ваших списков»).
