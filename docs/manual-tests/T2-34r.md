# T2-34r. Уведомления

Статус: ⏳ (вид — 🤖 снимок `toasts`, хранение — 🤖 тест)

1. Ошибка (например, выключить сеть и отправить отчёт о фишинге): тост с «Подробнее в журнале» — открывается история.
2. История: внизу «Открыть журнал» — папка `logs` с файлами журнала.
3. Перезапуск: вчерашние уведомления — в истории («Вчера»), без тостов.
