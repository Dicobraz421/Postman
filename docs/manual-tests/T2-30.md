# T2-30. Исполнитель: «Ответить автору», «Запланировать», «В проект»

Статус: ⏳ (вид — 🤖 снимки `delegation-in-mail`, `delegations-in`; живой сервер — владелец)

1. «Задачи» → «Поручения» → «Мне поручили», выбрать поручение. Командная строка: «Новая задача», «Ответить автору»,
   «Запланировать», «В проект».
2. Ctrl+R (и в русской раскладке — Ctrl+К) — новое письмо во вкладке автору поручения, тема «Re: <название>».
3. «Запланировать» — тост «В календаре: …», блок в календаре; кнопка неактивна, пока блок стоит.
4. «В проект» — строка «Проект» в карточке поручения с вариантами; выбрать проект — он у моей копии (у автора свой).
5. «Я поручил», своё поручение: «Поручить», «Напомнить», «Забрать», «Удалить»; Ctrl+R — письмо исполнителю.
