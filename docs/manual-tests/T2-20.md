# T2-20. Внешнее приглашение и подсказки «Вашего дня»

Статус: ⏳ (вид — 🤖 снимки `invite-external`, `invite-answered`; выбор подсказки и `PRODID` — 🤖 тесты; живой
сервер — владелец)

1. Приглашение с другого домена (Google Calendar, Outlook.com): принять. Карточка — строкой: тема · день · время,
   «Внешнее приглашение · Google», «ответ ушёл письмом организатору», «✓ Вы приняли», «Изменить ответ ▾».
2. «Изменить ответ» — полная карточка с кнопками.
3. Приглашение коллеги (свой домен), принято — полная карточка с «Вашим днём», как раньше.
4. Новое приглашение: навести на блоки «Вашего дня» — подсказка «Тема · время»; у встречи — «· это приглашение»,
   у пересекающегося — «· пересекается с приглашением …» с общим временем.
