# MAC-DES. Главное окно на Mac — по макету MainMac

Статус: ⏳

MacBook (Apple Silicon), macOS 13 или новее. Сборка — артефакт CI «macOS» PR MAC-DES (как скачать и снять карантин —
`docs/manual-tests/MAC-01.md`, шаги 1–2). Рядом — макеты `MainMac`, `MainMacDark`, `MainMacFull` (страница
«✓ Главное окно»).

1. Заголовок. Запустить Postman в окне. Ожидается: слева «светофоры», сразу за ними вкладки; значка приложения,
   кнопок разделов, шестерёнки и своих «─ □ ✕» в заголовке нет. Вкладки «Почта» нет.
2. Разделы над деревом. Под заголовком слева, над деревом папок — четыре кнопки разделов во всю ширину дерева,
   выбранная — на светлой плашке с контуром. Справа от них — «Новое письмо» над списком. Щелчок по «Календарю» —
   календарь, ⌘1 — снова почта. Перетащить разделитель папок шире/уже — строка разделов меняет ширину вместе с деревом.
3. Вкладки. Открыть письмо во вкладке (двойной щелчок), ⌘, — «Настройки», новая встреча. Ожидается: у каждой вкладки
   значок по типу (конверт синий, календарь розовый, шестерёнка), активная — полужирная с чертой акцентом снизу, без
   плашки. ⌘W закрывает активную.
4. Вкладка без строки команд. Активна вкладка «Настройки» или письма. Ожидается: разделы — в заголовке за
   «светофорами»; щелчок по «Почте» возвращает к списку писем, разделы снова над деревом.
5. Полный экран. Зелёная кнопка (или Вид → «Полноэкранный режим»). Ожидается: «светофоров» нет, на их месте —
   разделы, черта, вкладки; строки над деревом нет, «Новое письмо» — у левого края. Выйти из полного экрана —
   раскладка из шагов 1–2 сразу.
6. Тёмная тема. «Настройки» → «Внешний вид» → «Тёмная» (или тема системы — тёмная). Повторить шаги 1–5: цвета —
   как `MainMacDark`, контуры и черта видны.
7. Узкое окно. Сузить окно: кнопки строки команд уходят в «…», меню «…» открывается под самой кнопкой.
