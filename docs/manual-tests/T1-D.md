# T1-D. Токены выделения, тёмное окно, тема «Серая»

Статус: ⏳

1. Светлая: выделенное письмо — голубой тон (#D1E4F4) и синяя полоса слева; наведение на другую строку — бледный тон;
   наведение на выделенную ничего не меняет. Щёлкнуть в поиск или переключиться в другое окно — выделение серое
   (#EBEBEB), полоса серая. То же у контактов и папок.
2. Акценты (Настройки → Внешний вид): у бирюзового, зелёного, фиолетового, графита — свой тон выделения.
3. Тёмная: фон окна темнее (#191919), карточки списка и чтения на нём видны; выделение — синий тон #2B3E50.
4. Настройки → Внешний вид → Тема → «Серая»: окно #DADADA, карточки и панель папок #EDEDED, белого нет; тёмная тема
   Windows её не переключает; после перезапуска тема та же.
