# PAR-06. Трей на Linux, вход без пароля по домену

Статус: ⏳ (стенд с Linux — когда появится)

1. KDE Plasma 6 (и GNOME с расширением AppIndicator): запустить Postman — значок в трее. Подсказка — «Postman» или
   число непрочитанных; при непрочитанных значок с отметкой. Меню: «Открыть», «Выход».
2. «Закрытие окна» → «В трей»: «✕» — окно пропало с экрана и панели задач (X11; Wayland — свёрнуто), щелчок по значку
   — вернулось. GNOME без расширения: значка нет, «✕» закрывает Postman.
3. Автозапуск включить: в `~/.config/autostart/postman.desktop` строка `Exec=… --minimized`; после входа — только
   значок в трее.
4. Новое письмо при свёрнутом окне — уведомление; щелчок по нему открывает письмо.
5. Вход без пароля (Windows в домене, macOS/Linux с `kinit user@CORP.EXAMPLE`): учётка `…@corp.example` на
   Exchange — выбор «без пароля» есть; учётка другого домена — выбора нет.
