# S8-35: «Безопасность» — шифрование диска с базой (BitLocker)

1. Машина без BitLocker на системном диске: «Настройки → Безопасность» — первой строкой «Диск C: с данными Postman
   не зашифрован BitLocker», пояснение и «Параметры BitLocker»; кнопка открывает «Шифрование диска BitLocker»
   панели управления. Баннеров и тостов нет.
2. С включённым BitLocker: «Диск C: с данными Postman зашифрован BitLocker» с галочкой, без кнопки.
3. Приостановить защиту (`manage-bde -protectors -disable C:` от администратора) и открыть раздел заново — строка
   «не зашифрован»; `-enable` — снова «зашифрован».
4. Строка совпадает с «Управление BitLocker» Windows; окно не замирает при открытии раздела (чтение — в фоне).
