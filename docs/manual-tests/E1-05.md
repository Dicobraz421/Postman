# E1-05: внешние встречи — ручная проверка

1. Учётная запись на The Post: новая встреча с внешним участником, у которого настроена ссылка занятости (FBURL), — в помощнике планирования видна его занятость с источником; у участника без ссылки — «нет данных».
2. Настройки → Календарь → «Опубликовать по ссылке»: уровень «занят / свободен», ссылка копируется и открывается в браузере как ICS; «Отозвать» — ссылка перестаёт работать.
3. «Подписаться на календарь по ссылке» (например, опубликованный календарь Google): календарь появляется только для чтения, обновляется по интервалу.
4. Учётная запись на Stalwart: пункты публикации скрыты; занятость внешнего участника — по FBURL из карточки контакта.
