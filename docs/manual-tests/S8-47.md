# S8-47. Установщик MSI

Статус: ⏳

Тихую установку, обновление, отказ ставить старую поверх новой и удаление проверяет CI (`scripts/windows/msi-check.ps1`).
Здесь — то, что видит человек. MSI — `postman-<версия>-windows-x64.msi` со страницы выпуска (первый — с 0.1.0-beta.3)
или артефакт Actions.

1. Закройте Postman, если он запущен из архива. Двойной щелчок по MSI: окно хода установки, затем запрос UAC
   «Разрешить этому приложению вносить изменения». После «Да» установка заканчивается без вопросов.
2. «Пуск» → «Postman»: Postman запускается, данные и вход прежние (те же, что у копии из `install.ps1`).
   Откройте письмо с вложением PDF: просмотр работает (песочница из `Program Files`).
3. «Параметры» → «Приложения» → «Установленные приложения»: строка «Postman», издатель «Pets», версия вида `0.1.30x`,
   значок Postman.
4. Удалите Postman там же: «Удалить». Ярлык из «Пуска» пропал, папки `C:\Program Files\Postman` нет,
   `%LOCALAPPDATA%\Postman` на месте.
5. Без прав администратора (обычная учётная запись или отказ в UAC): установка не идёт, ничего не меняется. Для такого
   случая — архив и `install.ps1`.
