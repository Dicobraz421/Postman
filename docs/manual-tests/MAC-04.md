# MAC-04. Системные возможности macOS

Статус: ⏳

MacBook Air M1, macOS 13 или новее. Сборка — артефакт CI «macOS» PR MAC-04 (как скачать и снять карантин —
`docs/manual-tests/MAC-01.md`, шаги 1–2). Запуск — из Finder или Dock. Нужен живой ящик (шаги 1–3, 6) и Word для Mac
(шаг 1; без Word — Safari).

1. Вставка из Word. В Word — таблица 3×3 с жирным текстом и заливкой ячеек, выделить, ⌘C. В Postman — новое письмо
   (⌘N), щелчок в текст, ⌘V. Ожидается: таблица сеткой, жирный и заливка сохранились. То же со страницей Safari
   (таблица или текст со ссылкой): ссылка осталась ссылкой.
2. Открывать при входе. «Настройки» → «Общие» → «Открывать при входе в систему» — включить. «Системные настройки» →
   «Основные» → «Объекты входа»: в «Открывать при входе» есть Postman. Выйти из системы и войти. Ожидается: Postman
   открылся сам, почта синхронизируется. Выключить переключатель — Postman пропал из «Объектов входа».
3. Тема по системе. «Настройки» → «Внешний вид» → тема «Как в macOS». «Системные настройки» → «Оформление» →
   «Тёмное». Ожидается: Postman сразу тёмный, без перезапуска. «Цветовой акцент» → фиолетовый — кнопка «Новое
   письмо» и выделение в списке фиолетовые. Вернуть «Светлое» и прежний акцент.
4. FileVault. «Настройки» → «Безопасность»: первая строка — «Диск с данными Postman зашифрован FileVault» (или «не
   зашифрован» с кнопкой «Настройки FileVault» — кнопка открывает «Конфиденциальность и безопасность» → FileVault).
   Состояние совпадает с `fdesetup status` в Терминале.
5. Клавиши и тексты. «Настройки» → «Клавиатура»: тексты — с ⌘ и «macOS», без «Ctrl» и «Windows». Назначить любой
   команде ⌃R (физический Control): в таблице — «⌃R», не «⌘R», и ⌃R её выполняет. Сбросить. Удержать ⌘ в списке писем
   — появляются подсказки клавиш. ⌘-щелчок по двум письмам — выбраны оба. ⌘W на главной вкладке — Postman скрыт,
   Dock возвращает окно; на вкладке письма ⌘W закрывает вкладку.
6. Щелчок по уведомлению. Скрыть Postman (⌘H), отправить себе письмо с другого ящика. Щелчок по баннеру. Ожидается:
   Postman впереди, открыто это письмо.
7. Замер простоя (один раз). Закрыть Postman (⌘Q), в Терминале
   `/Applications/Postman.app/Contents/MacOS/postman --bench`, минуту ничего не трогать. Ожидается: строка с
   `idle_cpu_pct=…` и `idle_phys_footprint_mb=…` — прислать её целиком.
8. Политика (по желанию, нужен пароль администратора). Терминал:
   `sudo defaults write "/Library/Managed Preferences/io.github.dicobraz421.postman" Theme -string fluent-dark`,
   затем `sudo killall cfprefsd` и запустить Postman. Ожидается: тема тёмная, выбор темы закрыт («Тему задаёт
   организация»). Убрать: `sudo rm "/Library/Managed Preferences/io.github.dicobraz421.postman.plist"`,
   `sudo killall cfprefsd`.

Что записать в отчёт: номер шага и что видно (снимок экрана: ⇧⌘4, пробел, щелчок по окну); для шага 7 — строку
замера.
