# Ручная проверка: хранилище формата 7 (мелкие части по хэшу, сжатие)

Windows, своя почта (база формата 6 от прежней версии). ADR 0006, дополнение 2026-11-14.

1. Перед обновлением: «Настройки → Учётные записи → Настроить» — запомнить размер офлайн-кэша. Закрыть Postman.
2. Запустить новую версию: вместо списка — «Обновление хранилища: N %», окно отвечает; по окончании — список писем
   как прежде, письма открываются, вложения сохраняются (в том числе крупные, больше 1 МБ).
3. Открыть письмо «На этом компьютере» (локальный архив) — текст и вложения на месте.
4. «Настройки → Общие → Журнал и диагностика → Хранилище писем»: сначала «Считаю…», затем размер на диске, число
   писем и уникальных частей, «Сэкономлено … (… %): повторы — …, сжатие — …». «Пересчитать» — то же заново.
   Интерфейс при подсчёте не замирает.
5. Размер офлайн-кэша (п. 1) — меньше прежнего.
6. Закрыть Postman посреди «Обновления хранилища» (п. 2 на другой копии базы) и запустить снова — перенос
   продолжается, письма целы.
7. Журнал: строка `store: migrated to the current format`, без `content references after migration`.
