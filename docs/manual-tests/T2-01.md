# T2-01. Ссылки во встречах и в письмах простым текстом

Статус: ⏳ (сцены `event-online`, `event` — 🤖; живой Exchange — владелец)

1. Exchange: встреча Teams (или Телемост/Zoom) в календаре → подробности справа: строка с камерой, ссылкой и
   «Подключиться». «Подключиться» и щелчок по ссылке открывают браузер на встрече.
2. Там же описание встречи: ссылки подчёркнуты цветом акцента и открываются щелчком; «Присоединиться…<https://…>» —
   ссылка нажимается.
3. Встреча с местом-ссылкой (место — только адрес): строки места нет, есть строка «Подключиться».
4. Письмо простым текстом (без HTML) со ссылкой `https://…` и `www.…`: ссылки нажимаются. Нужен новый
   `postman-worker.exe` той же версии.
