# T2-47. Личные группы контактов

Статус: ⏳ (вид — 🤖 снимки `contacts-groups`, `contacts-new-group`, `contacts-to-group`, `compose-group`,
`compose-group-expanded`; живой сервер — владелец)

1. «Контакты» → слева «Группы»: свои группы с числом участников, ниже «Новая группа».
2. «Новая группа»: справа форма — название и участники через «;» (адрес, «Имя <адрес>» или имя из справочника).
   «Сохранить» — группа в списке слева; после перезапуска — на месте (сервер: JMAP, CardDAV, Exchange).
3. Сотрудник справочника выбран → «В группу» в командной строке → группа из меню: тост «… — в группе …», число
   участников выросло. Тот же ещё раз — «уже в группе».
4. Карточка группы: участники, «×» — убрать, щелчок по участнику — его карточка. «Изменить» — та же форма.
5. «Написать группе»: в «Кому» — чип «Имя N»; «+» — участники чипами. Отправить письмо с чипом группы: у
   получателя в «Кому» — адреса участников, адреса группы нет.
6. Exchange: группа — личный список рассылки в «Контактах» Outlook (тот же состав); убрать участника в Postman — в
   Outlook его нет, участники из справочника, добавленные в Outlook, остаются.
7. «Удалить» у группы — строка «Удалить группу …? Да / Нет»; контакты участников остаются.
