# S7-04. Почта по IMAP и SMTP

Статус: 🤖 частично (2026-11-06): шаги 1–10 — стенд; владельцу — «Сохранить» через диалог Windows (шаг 3); шаг 2 расходится с S7-05 шагом 1 (на том же стенде рейл полный); общий ящик виден как «Shared Folders» (находка F11)

Стенд Stalwart (IMAPS 993 и SMTPS 465 открыты из офисной сети, `docs/STALWART.md`; сертификат стенда
самоподписанный — запуск с `POSTMAN_INSECURE_TLS=1`), учётная запись `user1`. Обе темы.

1. Первый запуск (или «Настройки → Аккаунты → Добавить аккаунт»): адрес сервера `imaps://<адрес стенда>` (SMTP — тот
   же узел, 465), логин `user1@itt.test`, пароль. Адрес без схемы у сервера без JMAP (только IMAP) — Postman сам
   берёт IMAP (S7-04в); у стенда JMAP есть — адрес без схемы остаётся учётной записью JMAP. Ожидание: вход, дерево папок — «Inbox», «Drafts», «Sent Items»,
   «Junk Mail», «Deleted Items» (порядок — как у Outlook), письма «Входящих» в списке.
2. На рейле — только «Почта» и «Настройки»; в «Настройках» нет «Календаря», «Правил», «Автоответа» (основная учётная
   запись — IMAP). Вторая учётная запись IMAP рядом со Stalwart (JMAP) — своей группой в дереве, рейл — как у основной.
3. Письмо открывается: текст и HTML (без внешних картинок), вложения — список, «Сохранить» и просмотр работают.
4. Письмо себе с вложением: уходит, копия — в «Sent Items», новое во «Входящих» появляется само за несколько секунд
   (IDLE), без «Обновить».
5. Прочитано / не прочитано, флаг, категория — видны в другом клиенте (Thunderbird по IMAP) и обратно: отметка в
   Thunderbird появляется в Postman (опрос — до 2 мин, «Входящие» — сразу).
6. Перенос в папку и «Удалить» (в «Deleted Items»), затем удаление насовсем — так же на сервере.
7. Черновик: правка письма сохраняется в «Drafts», новая версия заменяет прежнюю (одна копия).
8. Поиск «Все папки» находит письма на сервере, которых ещё нет в списке (старше первых 500).
9. «Отменить» в тосте после отправки (10 с) — письмо не ушло, черновик открыт снова; без отмены — ушло. Закрыть
   Postman в окне «Отменить» — письмо уходит при закрытии. «Отправить позже» нет.
10. Ответ на письмо — в одной беседе с ним (лента беседы, S5-05); фильтры «Все папки» (например «Непрочитанные»,
    «От: …») находят письма на сервере, которых нет в первых 500.
