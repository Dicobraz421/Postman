# S8-42. Занятость внешних участников по ссылке

Статус: 🤖 частично (2026-11-06): шаги 1, 2 — сцены, шаги 3–8 — стенд сети (`docs/stand/net.py`); в шагах 3 и 4 — бесконечные серии, `Z`, исключения и переносы на файлах стенда (`net-s842-link`, `net-series-busy`), настоящие файлы Outlook и Google не сверялись; шаг 7 — через JSContact

Нужна настоящая ссылка: календарь Outlook или Google, опубликованный как `.ics`, либо файл VFREEBUSY на https-сервере.
Данные — только тестовые.

1. Новая встреча, обязательный участник с чужим доменом: в его строке — «Внешний адрес — приглашение уйдёт письмом» и
   «Указать ссылку».
2. «Указать ссылку», ввести `http://…`, Enter: «Нужна ссылка https:// с именем сервера», строка не закрылась.
3. Ввести настоящую ссылку, Enter: «Загружаю занятость по ссылке…», затем занятость в строке участника, подпись «· по
   ссылке»; в «Все участники» счётчик данных вырос на одного, общие окна учитывают эту занятость.
4. Сверить интервалы с календарём-источником: повторы, часовой пояс, встречи «под вопросом» — светлым блоком,
   прозрачные и отменённые не показаны.
5. Внизу вкладки «Ссылка занятости <адрес>» — открывает строку, «Убрать» — снова «Указать ссылку».
6. Неверный адрес или выключенная сеть: «Занятость по ссылке недоступна» не позже чем через 5 с, окно не замирает.
7. Контакт с `FBURL` (vCard на CardDAV или JSContact `calendars` на JMAP): занятость появляется сама, вводить ссылку не
   нужно. Правка контакта в Postman ссылку не стирает.
8. Перезапуск: указанная ссылка сохранилась. Перейти на другую неделю — занятость запрашивается для неё.
