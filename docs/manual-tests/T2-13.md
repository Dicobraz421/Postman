# T2-13. Повторяющиеся встречи

Статус: ⏳ (тесты переводов — 🤖; живые серверы — владелец)

1. Новая встреча → «Повтор ▾» → «Каждую неделю»: на сервере (Outlook / веб) — серия по этому дню недели.
   То же для Exchange, JMAP, CalDAV.
2. «По будням», «Каждый месяц», «Каждый год» — серия с тем же правилом.
3. Встреча в 00:30 с «Каждую неделю» (CalDAV): серия — по нужному дню, не на день раньше.
4. Повторяющееся приглашение от внешнего (только письмом, JMAP / CalDAV): после открытия письма — серия в календаре.
