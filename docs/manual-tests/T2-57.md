# T2-57. Безопасность: песочница и состояние защиты

Статус: ⏳ (вид — 🤖 снимок `settings-security`)

1. Postman, перенесённый в папку без прав для «Всех пакетов приложений»: открыть письмо — песочница «частичная».
   Выполнить `icacls` из подсказки, «Проверить снова» — «Полная» без перезапуска.
2. «Состояние защиты» совпадает с разделом: «Пароли: не хранить» — «Не хранятся»; адрес ИБ пуст — «адрес не задан».
3. «По умолчанию» — картинки «Не загружаются никогда», TLS 1.2+; каталог сертификатов не тронут.
