# T2-44. Руководитель, кабинет, телефоны, фамилия и имя

Статус: ⏳ (вид — 🤖 снимки `contacts`, `contact-edit`; JSContact, vCard, Exchange — 🤖 тесты; живой сервер — владелец)

1. Exchange: карточка сотрудника — «Руководитель» (щелчок — его карточка), «Рабочий телефон», «Мобильный», «Отдел»,
   «Кабинет» — как в адресной книге Outlook. Stalwart: руководителя и кабинета нет — «—».
2. «Новый контакт»: поля «Фамилия», «Имя», «Организация», «Должность», «Электронная почта», «Рабочий телефон»,
   «Мобильный», «Адресная книга: Мои контакты». Сохранить — в списке «Фамилия Имя», телефоны — в своих полях.
3. Изменить контакт с мобильным, заведённый в другом клиенте (Outlook, телефон): мобильный — в поле «Мобильный», после
   сохранения там же (у другого клиента — тоже мобильный).
