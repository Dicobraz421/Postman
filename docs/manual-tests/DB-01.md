# DB-01. Данные клиента в базе профиля: обновление со старой версии

Статус: ⏳ (владелец; нужна сборка до DB-01 и после)

Подготовка — на прежней версии Postman (до DB-01), основной вход в живой ящик:
1. «Настройки → Категории»: переименовать категорию, поменять ей цвет.
2. «Настройки → Подписи»: подпись с картинкой (логотип PNG) — умолчанием для новых писем; шаблон письма.
3. «Календарь → Подписки → Добавить по ссылке»: публичный `.ics` (например, `https://cal.example.test/public/basic.ics`
   стенда), события видны.
4. Вызвать пару уведомлений (выключить сеть — «Нет связи»; отправить письмо и «Отменить»). Закрыть Postman.
5. В `%LOCALAPPDATA%\Postman` есть `account-…redb.labels.json`, `account-…redb.settings.json`,
   `account-…redb.settings.images\`, `subscriptions\`, `notices.jsonl`.

Обновление:
6. Поставить новую версию, запустить: метки с новым именем и цветом в списке писем; «Новое письмо» — подпись с
   картинкой, картинка видна; шаблон на месте; подписка в календаре с событиями без сети; история уведомлений
   (🔔) — записи из п. 4.
7. Рядом с базой — те же файлы с `.bak` на конце, без `.bak` — нет; `settings.json`, `account.json` — на месте.
8. Закрыть и запустить снова: всё из п. 6 на месте, файлов `.bak` больше нет.
9. Поменять подпись (убрать картинку), удалить подписку, перезапустить: изменения сохранились, новых файлов рядом с
   базой не появилось.
