# T1-01. Значок окна и панели задач — «Ленты»

Статус: ⏳

Release-архив из CI этого PR, переустановка (`install.ps1`). Значки Windows кэширует: если после установки видна
старая картинка — перезайти в Windows или `ie4uinit.exe -show`.

1. Запустите Postman. Ожидание: на панели задач и в Alt+Tab — значок «Ленты» (три полосы: синяя, стальная, розовая),
   не конверт; на панели задач значок чёткий (малый кадр своего размера, не уменьшенный крупный).
2. Ярлык в «Пуске» и `postman.exe` в Проводнике. Ожидание: тот же значок.
3. Напоминание задачи при свёрнутом окне (задача с напоминанием через минуту, окно свернуть). Ожидание: тост
   «Postman» со значком «Ленты».
