## А. Экспорт демо-ящика из интерфейса

1. Postman с демо-ящиком: `cargo run --release -p postman-gpui -- --demo 50000` (или `postman.exe --demo` из архива;
   рядом с `postman.exe` — `postman-worker.exe`: письма в свойства Outlook разбирает он).
   Ожидание: окно, демо-ящик.
2. ПКМ по «Входящие» (с подпапками) → «Экспорт…».
   Ожидание: в списке форматов — EML, mbox, Maildir, **PST** («Файл данных Outlook · «Импорт и экспорт»»); MSG нет.
3. PST, «С подпапками» включено → «Выбрать папку и начать…» → пустой каталог, например `C:\tmp\pst\demo`.
   Ожидание: в строке состояния «Экспорт: N из M», в конце тост «Экспортировано N писем · PST · каталог» с «Открыть
   папку». В каталоге — один файл `Входящие.pst`, без `*.tmp`. Писем без содержимого в базе (их демо не хранит) —
   строкой «K писем не загрузились…» в тосте: это охват, не ошибка PST.
4. Повторите шаг 3 в тот же каталог.
   Ожидание: рядом появился `Входящие (2).pst`, первый файл не тронут.
5. «Экспорт учётки…» (палитра) → PST.
   Ожидание: файл с именем учётки (демо — `Postman.pst`), в нём все папки учётки деревом.
6. Начните экспорт учётки в PST и сразу «Остановить» (щелчок по строке состояния).
   Ожидание: тост «Экспорт остановлен…», недописанного `.pst` и `*.tmp` в каталоге нет.

## Б. Outlook (classic)

7. Скопируйте `Входящие.pst` из шага 3. «Файл → Открыть и экспортировать → Открыть файл данных Outlook» → копия.
   Ожидание: без «Средства восстановления папок» и без ошибок; в дереве — файл «Входящие», в нём «Входящие» с
   подпапками (как в Postman) и «Удалённые».
8. Раскройте папки. Ожидание: число писем в папках — как в Postman; темы, отправители, даты, прочитанные и
   непрочитанные, скрепка у писем с вложениями.
9. Откройте письмо с вложением, вложение — двойным щелчком. Ожидание: текст письма на месте, вложение открывается
   (картинка, PDF, документ — своим приложением). Письмо с пересланным письмом (вложение `.eml`/«элемент Outlook»):
   двойной щелчок — открывается письмо с темой, текстом и своими вложениями.
10. Большой файл: `C:\tmp\pst\8 открыть в Outlook (10000).pst` — 10 000 писем в «Входящие», «Входящие → Проекты»,
    «Архив» (3334 / 3333 / 3333; у каждого сотого — вложение 64 КиБ).
    Ожидание: открывается без восстановления; в папках — столько писем; письма и вложения открываются; поиск по
    «Письмо 5000» находит одно письмо.
11. Закройте Outlook («Закрыть «…»» на файле в дереве или выход).

## В. scanpst

12. `C:\Program Files\Microsoft Office\root\Office16\SCANPST.EXE` → копия из шага 3, которую Outlook не открывал
    (сделайте её сразу после шага 3) → «Начать».
    Ожидание: только «несущественные несоответствия», в журнале («Подробности») нет строк `!!` и `??`. Так scanpst

    обнаружено» для PST недостижимо и не нужно.
13. То же для `C:\tmp\pst\7 для scanpst (10000).pst`.
    Ожидание: как в шаге 12.

## Как собраны файлы шагов 10 и 13

Тестом (адреса — только `example.test`): `set POSTMAN_EXPORT_SAMPLES=C:\tmp\pst` и
`cargo test -p postman-export --test pst` → `C:\tmp\pst\S8-33б 10000.pst` (и `S8-33б вложенное.pst` — письмо с
пересланным письмом в два уровня); копии — `7 для scanpst (10000).pst`, `8 открыть в Outlook (10000).pst`.
