# S7-07б. Правка и отмена своей встречи; телефон коллеги у Exchange

Статус: 🤖 частично (2026-11-06): шаг 7 — сцены, шаги 1–3 — стенд (JMAP, CalDAV); не покрыто — 4, 5 на стенде; Exchange — часть шагов 1–5 и шаг 6

Три учётные записи по очереди (или рядом в одном окне): Stalwart по JMAP (`user1` → `user3`), «стандарты» по CalDAV
(`user1` → `user2`, `docs/manual-tests/S7-05.md`) и Exchange (тестовые `user1` → `user2`, правила S7 «Проверка на
боевом Exchange»: всё — с `[postman-test]` в теме и удаляется после проверки). Обе темы.

1. Своя встреча с участником: в подробностях под темой — «Изменить» и «Отменить встречу». У встречи коллеги и у
   приглашения от другого организатора кнопок нет.
2. «Изменить» одиночной встречи: открывается вкладка «Изменение встречи · тема» с темой, местом, временем,
   участниками и описанием события; поля «От» нет (или оно не меняется). Перенесите на час, смените тему,
   «Отправить». Ожидание: тост «Изменения отправлены»; вкладка закрылась; в неделе — новое время и тема; у участника
   (его клиент или OWA) — обновлённое приглашение и новое время.
3. «Отменить встречу» одиночной: строка «Отменить встречу? Участники получат отмену.» — «Не отменять» убирает строку;
   «Отменить встречу» — тост «Встреча отменена…», встречи в неделе нет; у участника — письмо об отмене, встречи нет
   (или она помечена отменённой).
4. Повторяющаяся встреча (заведите в OWA или другом клиенте, каждый день, 3 раза, с участником): «Изменить» —
   строка «Только эту / Всю серию / Назад». «Только эту» → вкладка, время второго экземпляра +1 ч → в неделе
   перенесён только он. «Всю серию» → перенос на +30 мин → все экземпляры сдвинулись. У Stalwart по CalDAV после
   «Только эту» в неделе может остаться и прежний экземпляр — это сервер (`docs/STALWART-GAPS.md` №49).
5. «Отменить встречу» у повтора: «Только эту» — экземпляра нет, остальные на месте; «Всю серию» — серии нет; у
   участника — отмены.
6. Exchange, «Контакты → Справочник»: найдите коллегу с телефоном в адресной книге Outlook. Ожидание: при открытии
   карточки «Телефоны» заполняются (запрос `ResolveNames`), не «—».
7. Демо (`--demo`): «Изменить» открывает вкладку; «Отменить встречу» → «нужен сервер» тостом, строка не зависает.
