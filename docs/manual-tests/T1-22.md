# T1-22. «Отправленные» — письма выбираются и открываются, как в других папках

Причина на Exchange («response too large» у заголовков списка) исправлена в плагине EWS (7ac9da5, 47b8c55); здесь —
проверка интерфейса.

1. Учётка Exchange → «Отправленные»: список писем есть (не «response too large»), щелчок по письму выделяет его и
   открывает в области чтения; стрелки ↑/↓ ходят по письмам.
2. Там же: Ctrl+щелчок и Shift+щелчок выделяют несколько писем; «Переместить» и «Удалить» работают, флажок ставится.
3. То же в «Отправленных» почты Stalwart (JMAP) — без отличий от «Входящих».
4. Снимки `sent`, `sent-letter` с `--live` на учётке Exchange — письмо открыто.
