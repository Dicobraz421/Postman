# T3-08. Конец серии: «до даты» и «N раз»

Статус: ⏳ (тесты переводов и разворота — 🤖; снимки и живые серверы — владелец)

1. Новая встреча → «Повтор ▾» → «Каждую неделю»: ниже в меню — «Без конца / До даты… / N раз», отмечено «Без конца».
2. «N раз»: рядом с кнопкой — поле «10 раз»; ввести 3, отправить — на сервере (Outlook / веб) три встречи.
   То же для Exchange, JMAP, CalDAV.
3. «До даты…»: поле «до дд.мм.гггг» (через три месяца); ввести дату через две недели — последняя встреча не позже
   этой даты, в сам этот день — есть.
4. Встреча в 00:30 с «До даты…» (CalDAV, пояс восточнее UTC): последний день серии — выбранный, не на день раньше.
5. В поле — «abc», 0 или дата раньше начала → «Отправить»: строка «Конец повтора не распознан», встреча не ушла;
   исправить — строка пропала.
6. «Не повторяется» — поле конца исчезло; снова «Каждый день» — «Без конца».
7. Закрыть вкладку с заполненной серией «до даты» и открыть черновик — повтор и дата на месте.
8. Серия с концом (своя и от другого клиента): в подробностях — «Каждую неделю: вторник, до 30.12» или «…, 5 раз»,
   не «особое правило».
