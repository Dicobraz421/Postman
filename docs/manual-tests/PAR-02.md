# PAR-02. S/MIME и LDAP — одно поведение на Windows, macOS и Linux

Статус: ⏳ (MacBook владельца)

Журнал — `POSTMAN_LOG=debug`. Тестовые сертификаты — из `postman_smime::testkit` или своего тестового УЦ.

## macOS — пункты «[проверить]» (PAR-02, `crates/core/src/smime/macos.rs`)

1. **Имя политики S/MIME в настройках доверия.** «Связка ключей» → тестовый корневой сертификат → «Доверие» →
   «Защищённая почта (S/MIME)»: «Никогда не доверять», остальное — «Всегда доверять». Открыть письмо, подписанное
   сертификатом этого УЦ. Ожидается: «Сертификат в списке недоверенных» (корень исключён для S/MIME). Затем вернуть
   «Использовать системные настройки» для S/MIME и поставить «Никогда» только для «SSL»: письмо — «подписано», как
   до изменения. Если в шаге 1 итог «подписано» — имя политики в настройках не «SMIME»: команда
   `security dump-trust-settings -d` (или без `-d`) покажет `Policy Name`, его — в `smime_setting`.
2. **Код `SecTrust` для неверной подписи.** Письмо, у которого сертификат подписанта подписан не ключом УЦ
   (подменён издатель). Ожидается: «Подпись сертификата неверна» (не «Ошибка проверки цепочки»). В журнале `debug` —
   `smime: chain rejected by the OS` с `code`; если код не -67688 и не -67808 — записать его в
   `ERR_SEC_INVALID_SIGNATURE`.
3. **Отзыв не дольше 8 с.** Отключить сеть (или закрыть OCSP/CRL УЦ брандмауэром), открыть подписанное письмо.
   Ожидается: итог не позже чем через ~8 с, «отзыв не проверен».
4. **Связка ключей и PIN.** Письмо, зашифрованное на сертификат смарт-карты (или ключ с паролем), и одновременно
   подпись другого письма. Ожидается: окно PIN появляется у того действия, где нажато «Ввести»; второе ждёт, не
   падает с отказом.

## PAR-02b

5. **«Ещё не действует».** Письмо, подписанное сертификатом с `notBefore` в будущем. Ожидается на всех ОС: «Срок
   действия сертификата подписи ещё не начался» (не «истёк»).
6. **Промежуточные из писем (macOS, Linux).** Письмо A с цепочкой подписант → промежуточный → корень (промежуточный
   вложен), затем письмо B того же УЦ без промежуточного. Ожидается: A и B — «подписано» (как на Windows с
   промежуточным в хранилище `CA`). Файл `smime-intermediates.bin` в каталоге данных, права — только владелец.
