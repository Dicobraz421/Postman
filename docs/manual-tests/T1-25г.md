# T1-25г. Справочник страницами, Exchange — поиском

Статус: ⏳

1. JMAP (Stalwart): «Справочник компании» — первая страница сразу, прокрутка к концу подгружает следующую; счётчик — всего людей.
2. Exchange: справочник пуст, строка «Справочник доступен поиском»; поиск по имени показывает людей (первая страница найденного).
3. Exchange: «Мои контакты» — создать контакт, он виден в Outlook; правка и удаление — так же.
