# CAL-MENU. Меню события по правой кнопке, новая встреча двойным щелчком (#660, #661)

Статус: ⏳ (ручная проверка на Windows — владелец)

1. Неделя, правая кнопка по своей встрече с участниками: событие выбрано (подробности справа), у курсора меню
   «Открыть · Написать участникам · Отменить встречу», справа — клавиши (Enter, Ctrl+Shift+R). «Отменить встречу» —
   строка подтверждения в подробностях, окна нет.
2. Правая кнопка по приглашению без ответа: «Открыть», «Принять», «Под вопросом», «Отклонить» (и «Написать
   участникам», если их больше одного). Принятое — без «Принять». Ответ уходит, как кнопкой в подробностях.
3. Меню с клавиатуры: ↑/↓, Home/End, Enter — выполнить; Esc и щелчок мимо — закрыть, фокус вернулся.
4. Месяц: правая кнопка по строке события — то же меню.
5. День/неделя: двойной щелчок по пустому месту в 14:40 при шаге 30 мин — вкладка встречи на этот день, 14:30,
   длительность из «Настроек → Календарь». Шаг 15 мин — 14:30 или 14:45 по месту.
6. Двойной щелчок по событию — встреча не создаётся.
7. Месяц: двойной щелчок по пустой клетке другого дня — встреча в этот день в 10:00; сегодня — время «Новой встречи».
   Двойной щелчок по числу дня — только переход к дню.
8. Английский интерфейс: подписи меню по-английски.
