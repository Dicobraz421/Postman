# T2-28. Первый запуск

Статус: ⏳ (вид — 🤖 снимки `firstrun*`, ход — 🤖 `task-24-firstrun`; живой сервер — владелец)

1. Без сохранённого входа: «Адрес электронной почты» → адрес → «Продолжить».
2. Шаг «Сервер»: «Ищу настройки…», затем «Найдены настройки: <вид> · <узел> · <чем> · N с» (Exchange, JMAP или
   IMAP). Не нашёл — поле «Адрес сервера». «Настроить вручную» на шаге 1 — сразу поле.
3. Пароль → «Проверить и подключить» → шаг «Проверка»: подключение и авторизация ✓, «Папки…» с именем папки;
   «Открыть почту» — почта; без нажатия — откроется сама после первой загрузки.
4. «Клавиши: Одиночные» — J/K в списке работают. «Пропустить» — пустое окно, аккаунт — в «Настройки → Аккаунты».
