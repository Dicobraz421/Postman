# T2-19. «Удалить из календаря» у отменённой встречи

Статус: ⏳ (Exchange — 🤖 тест-заглушка `cancelled_invite_removed_quietly`, вид — 🤖 снимок `invite-cancelled`;
JMAP, CalDAV и живой Exchange — владелец)

1. Коллега приглашает на встречу, вы принимаете; коллега отменяет. Письмо об отмене: «Встреча отменена организатором
   · …» и кнопка «Удалить из календаря».
2. Нажать: «Встреча удалена из календаря» (тост и строка карточки), встречи в календаре нет. Организатору письма не
   пришло.
3. Нажать у отмены, когда встречи уже нет: «В календаре этой встречи нет».
4. Серия: организатор отменил один экземпляр — удаляется только он, остальные на месте. Отменил всю серию — уходит вся.
5. Повторить для JMAP (Stalwart/The Post), IMAP+CalDAV и Exchange.
