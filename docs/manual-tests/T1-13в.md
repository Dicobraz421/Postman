# T1-13в. Документ Word в просмотре вложений

Статус: 🤖 частично (2026-11-06): `.docx`, Esc, `.docm` с проверкой, настоящий щелчок по `.xlsm` — сцены; шаг 1 — стенд

1. Письмо с вложением .docx: щелчок по карточке — текст документа в панели просмотра (заголовки, списки, таблицы), прокрутка.
2. ← / → — к соседним вложениям; Esc — закрыть. Большой документ — строка «Показано начало документа».
3. .docm (макросы) — красный щиток и карточка проверки, как раньше.
