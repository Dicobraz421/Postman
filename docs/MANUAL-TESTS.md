# Ручные проверки (Windows)

Сюда собирается то, что проверяет только владелец руками: окно, ввод, поведение ОС. Разделы 1–43 — в этом
файле. **Новые разделы (с 2026-10-22)** — отдельным файлом `docs/manual-tests/<задача>.md` (например
`S5-30.md`): заголовок `# <задача>. <название>`, строка `Статус: ⏳`, шаги. Этот файл PR не трогает — так параллельные
PR не конфликтуют по номерам. Проходим в диалоге: агент даёт команду и шаги, владелец отвечает
отметкой; итог — в «Результат» и, если что-то не так, отдельным PR.

**Порядок.** PR мержится после зелёного CI; ручная проверка — после мержа, по одной сборке со всеми
непроверенными разделами.

**Сборка.** `C:\Users\a.antropov\Documents\Claude\2026 FileNav\Postman\target\release\postman.exe`
(`cargo build --release -p postman-gpui`). Демо-ящик — `%LOCALAPPDATA%\Postman\demo.redb`.

## Статус разделов

✅ — принято; 🔁 — найдены ошибки, исправлены, ждёт перепроверки; ⏳ — смержено, ждёт проверки; 🤖 — проверено
автоматически без нажатий в окне (`app-gpui/tests/manual.rs`, `cargo build -p postman-worker && cargo nextest run -p
postman-gpui --test manual --run-ignored only`; язык — тесты `every_literal_key_is_translated`,
`language_follows_windows_by_default`), снимки просмотрены агентом.
С 2026-11-06 сюда же входят сцены с вводом внутри процесса (`cal_drills`, `mail_drills`, `input_drills`, `task_drills`: клавиши и мышь
идут в окно мимо ОС) и живой стенд Stalwart (`docs/stand/peer.py`). Статус ✅ ставит только владелец, агент — никогда.
Шаг, закрытый частично, считается открытым: в строке сказано, что не покрыто. Клавиши с буквой в сценах проверены на одной
раскладке, другая раскладка не проверялась.

## 2. Снимки экранов (S2-05)

`postman.exe --screens <каталог>` — пять PNG без участия человека.

1. Запустить с каталогом, например `%TEMP%\postman-screens`. Ожидание: окно появляется и само закрывается,
   в каталоге `list.png`, `letter.png`, `search.png`, `calendar.png`, `assistant.png`; код выхода 0.
2. Открыть снимки. Ожидание: каждый — настоящее окно (не чёрный, не пустой) и тот экран, что в имени.
3. `--screens … --lang en`. Ожидание: те же экраны по-английски.

## 3. Язык интерфейса (S2-06)

1. Запустить без `--lang`. Ожидание: язык — как у Windows (русский).
2. `--lang en`. Ожидание: все надписи по-английски: строка команд, папки, область чтения, строка состояния,
   календарь и помощник планирования (дни недели, легенда).
3. `--lang ru`. Ожидание: всё по-русски, сырых ключей вида `nav-mail` нигде нет.

## 4. Один экземпляр (S2-06)

1. Запустить Postman, свернуть окно.
2. Запустить второй раз (ярлыком или из проводника). Ожидание: второе окно не появляется; первое
   разворачивается и выходит на передний план, справа внизу тост «Postman уже запущен — показано это окно».
3. Закрыть Postman, запустить снова. Ожидание: обычный старт.
4. `--bench` при открытом Postman. Ожидание: замер идёт в своём окне (замеры не подчиняются правилу).

## 5. Журнал Windows (S2-06)

1. `postman.exe --demo abc --screens Z:\нет\такого` (недоступный каталог). Ожидание: выход с кодом 1.
2. «Просмотр событий» → «Журналы Windows» → «Приложение», источник `Postman`, код 1000. Ожидание: ошибка
   с текстом о сбое запуска (Windows допишет, что описание события не найдено, — источник регистрирует установщик).
   Из PowerShell (фильтр `ProviderName` для незарегистрированного источника не работает):
   `Get-WinEvent -LogName Application -FilterXPath "*[System[Provider[@Name='Postman']]]" -MaxEvents 3 | % { $_.Properties.Value }`
3. Паника: из `pets` — `cargo run -p pets-shell --example probe -- panic`. Ожидание: в журнале запись
   источника `PetsProbe` с текстом паники и местом в коде.

6. Наведение на закладки внизу списка — над ними панель с числами во всю ширину; список и письмо не сдвигаются;
   увели мышь — панель закрылась.
7. Две закладки («Угрозы» и «Срок») — письма любой из них; плюс «Непрочитанные» слева — только подходящие под то и другое.
8. «×» у закладок — скрыты, тост; «…» → Вид → Быстрые фильтры — вернулись. Настройки → Быстрые фильтры: скрыть
   «Мне» и поднять «Истекают» — закладки в списке так же; включённая скрытая закладка снимается с фильтров.
9. Панель чтения «Снизу» (Настройки → Чтение) — закладки у нижнего края списка; «Скрыта» с открытым письмом — закладок нет.
10. Живой ящик: «Мне», «Внешние», «Упоминания» считаются по своему адресу; «Все папки» + фильтр находит письма старше
    загруженных страниц. Тёмная тема: панель, чип, закладки и заголовки групп читаются.

## 26. Календарь, встреча вкладкой, приглашения, контакты (S5-11)

1. Ctrl+2: неделя, «Сегодня» / Alt+Home, Alt+↑/↓, щелчок по дню в месяце слева — его неделя; линия текущего времени.
2. Встреча с категорией — цвет её категории (как полоса у письма); приглашение без ответа — пунктир, «под вопросом» —
   штрихованная полоса, отклонённое не видно.
3. Щелчок по встрече — подробности справа: время, место, «Пересекается с …», участники с ответами, «Внешний»;
   «Написать участникам» — письмо с адресатами.
4. Стенд (user1 ↔ user3): у приглашения в подробностях «Принять» — блок сплошной, у организатора «принял»;
   «Изменить ответ» → «Под вопросом» → штрих; «Отклонить» — блок пропал.
5. «Открыть мою занятость» слева → адрес user3 → «Открыть» → тост; у user3 во вкладке встречи занятость user1 видна.
6. «Создать встречу» / Ctrl+Shift+Q — вкладка «Новая встреча» без строки команд; тема меняет название вкладки.
   Адрес + Enter или «;» — чип с точкой занятости; «×» убирает; подсказки ↑↓ Enter; Esc закрывает вкладку.
7. Подбор времени: «Только общее свободное время» — зелёные окна, щелчок ставит начало; длительность, день ‹ ›,
   «Учитывать необязательных»; без него — занятость каждого; у коллеги без открытой занятости — «нет данных».
8. Стенд: Ctrl+Enter — тост «Приглашения отправлены», вкладка закрылась, встреча в неделе; у user3 — письмо-приглашение.
9. Письмо-приглашение: карточка (листок дня, время, место, «N из M приняли»), справа «Ваш день» и «Пересекается: …»;
   A / T / N отвечают; после ответа — «Вы приняли · Изменить ответ».
10. Стенд: user1 переносит встречу — у user3 новое письмо «Организатор изменил: время», прежнее время зачёркнуто,
    старое письмо — «устарело»; user1 удаляет встречу — строка «Встреча отменена организатором».
11. Ctrl+3: «Справочник компании» и «Мои контакты», буквы и указатель, поиск Ctrl+E; карточка — «Написать», «Встреча»
    (вкладка с участником), «Копировать адрес» (в буфере), «Сегодня» — занятость; у сотрудника «Добавить в мои контакты».
12. Личный контакт: Ctrl+Shift+C — форма, F2 — правка на месте, Delete → «Да» — удалён; на стенде — после перезапуска так же.
    Тёмная тема: календарь, вкладка встречи, карточка и контакты читаются.

## 27. Вложения: лента, просмотр, макросы (S5-07)

Демо: письмо с картинкой в тексте (каждое второе, «Коллеги, добрый день!…») — пять вложений.

1. Под шапкой — «Вложения · 5 · …» и «Сохранить все…»; карточки высотой 40 px в ряд по четыре: плашка типа (PDF, ZIP…),
   имя, размер; картинка из текста письма в ленте не повторяется. Не влезло — последняя карточка «+2», щелчок раскрывает
   все, «Свернуть» — обратно. Наведение на карточку — полное имя и кнопки «Просмотр», «Открыть», «Сохранить как…».
2. «Бюджет.xlsm» — красная полоса слева и щиток; «Открыть» у неё нет.
3. Щелчок по «Отчёт за квартал.pdf» — просмотр на месте текста письма (не окно): страница по ширине панели, «1 / 3», ‹ › листают,
   название документа в панели. Колесо — страница прокручивается до низа (виден колонтитул «1 / 3»), без сдвига и пустых
   полос; окно шире или уже — страница снова по ширине и чёткая (S5-07б). Щелчок по той же карточке или «×» — закрыть, текст письма вернулся.
4. В просмотре → / ← — соседнее вложение (архив, книга, фото…); Esc — закрыть. В поле поиска стрелки двигают курсор,
   а не вложения.
5. «Снимки экрана.zip» — оглавление: имя, размер, дата; `tools/collect.bat` и `report.docm` — красным со щитком,
   внизу «2 опасных файла…». На диск ничего не распаковано (в `%TEMP%` и `Загрузки` новых файлов нет).
6. «Бюджет.xlsm» — карточка «Открытие заблокировано · Содержит макросы», «VBA-макросы: 3 модуля» и их имена,
   «Сохранить…» и строка о защищённом просмотре; сохранённый файл — свойства → «Этот файл получен с другого компьютера…».
7. «Фото стенда.jpg» — картинка с размером и форматом («300 × 200 px · JPEG»), по центру, сразу под ней подпись;
   «Открыть в приложении» открывает системный просмотрщик. Фото больше панели (стенд: JPEG 4000 × 3000) — по ширине
   панели, целиком, вниз — прокрутка; в строке — исходный размер (S5-07б).
8. «Сохранить все…» → выбрать папку → тост «Сохранено 5 файлов: …»; повтор в ту же папку — копии «… (2)…», прежние
   файлы не затёрты; у всех метка «из Интернета».
9. Стенд: письмо с вложением `.xlsx`, внутри которого макросы (переименованный `.xlsm`) — щиток появляется после
   открытия письма; `.doc` с макросами — так же. PDF 10–40 МБ — просмотр или строка ошибки, окно не зависает.
10. Повреждённый PDF или архив (обрезанный файл) — в просмотре «Просмотр не удался: …», остальное письмо и лента работают;
    строка состояния «Песочница: полная». Тёмная тема: лента, просмотр и карточка блокировки читаются.
11. Демо: письмо «Коллеги, график загрузки стенда…» (одно на сотню, в начале ящика — «… 104») — картинка 2400 × 1500
    в тексте: целиком по ширине области чтения, рамка и четыре цветных угла видны, текст под ней — сразу, без пустоты;
    у письма с логотипом — логотип 300 × 200 и текст сразу под ним (S5-07б).

## 28. Жизненный цикл: сроки, напоминания, ждём ответа (S5-04)

1. Письмо открыто: в шапке под «Кому…» — «Срок», «Напомнить», «Ждать ответа», «Исчезнет». «Срок» (или Ctrl+Shift+G) —
   панель на месте, не окно: «Сегодня», «Завтра», «В пятницу», «На следующей неделе» с датой справа, «Выбрать дату и
   время…». «В пятницу» — в строке и в шапке янтарный текст с часами «До пт», без подложки; Esc и щелчок мимо закрывают.
2. «Выбрать дату и время…» → `завтра`/`32.10` — строка ошибки; прошлая дата — «Этот срок уже прошёл»; дата с временем
   сегодня через час — «До ЧЧ:ММ». У письма с просроченным сроком — плотная янтарная заливка «Просрочено 1 д», письмо —
   наверху списка в группе «Срочное» (Настройки → «Просроченный срок» выключить — группы нет). «Убрать срок» снимает.
3. «Напомнить» → «Сегодня позже»: тост «Напомню …», письмо ушло из «Входящих» в «Архив» (у стенда «Архива» нет —
   появилась папка «Архив»); метка «Напомнит ЧЧ:ММ». В срок (оставить Postman открытым) — письмо снова во «Входящих»,
   непрочитанное, наверху в «Срочном», внизу карточка «Напоминание · тема · Открыть»; «Открыть» — письмо открыто,
   прочитано, через минуту «Срочное» пропало. Простой с напоминанием в будущем — 0 % CPU в диспетчере задач.
4. Новое письмо с «Ждать ответа · 3 дня» → отправлено: в «Отправленных» метка «Ждём ответа · 3 д»; закладка «Ждём»
   («Все папки») его находит. «Ждать ответа…» у письма — 1/2/3/5/7 дней, «Не ждать ответа» снимает.
5. Стенд: user1 пишет user2 с «Ждать ответа», user2 отвечает (тот же разговор) — у user1 метка ожидания исчезла, тост
   «Пришёл ответ». Ответ от другого адресата или из другой беседы — метка остаётся.
6. Стенд: «Ждать ответа…» → «Выбрать дату…» сегодняшняя дата (срок прошёл) — письмо из «Отправленных» появилось во
   «Входящих», метка «Нет ответа · N д», тост; убрали его оттуда в «Архив» — обратно не возвращается.
7. «Исчезнет…» → «Через 1 д» — метка «Исчезнет через 1 д»; дата в прошлом через «Выбрать дату…» отклоняется; срок
   наступил (дата вчера проставлена вторым клиентом или перевести часы) — письмо в «Удалённых» (Настройки →
   «Исчезнувшие письма: В «Архив»» — в «Архиве»), тост «Исчезло писем: 1». «Никогда» — метки нет.
8. Стенд: письмо «Код подтверждения: 482913» во «Входящие» — через несколько секунд метка «Исчезнет через 24 ч»
   (Настройки → «Коды подтверждения» — часы); выключить правило — новые коды без метки; «Исчезнет… → Никогда» у кода —
   метка больше не появляется.
9. Стенд: Настройки → «Рассылки в архив» включить, 1 день — прочитанные письма с `List-Unsubscribe` / `List-Id` старше
   дня ушли в «Архив», последняя от каждого отправителя осталась, тост «Рассылки в «Архиве»: N»; обычные письма на месте.
10. Тёмная тема: «До пт» читается, «Просрочено» — тёмная янтарная подложка со светлым текстом, нейтральные метки серые;
    панель выбора и карточка напоминания — на слое окна. Закрыть Postman до срока напоминания и открыть после — письмо
    возвращается сразу при запуске (работает, пока Postman запущен).

## 29. Выделение, контекстное меню, фишинг, офлайн, тосты (S5-08)

1. Наведение на строку письма — на месте аватара флажок; щелчок по флажку выделяет письмо, флажки появляются у всех
   строк, над списком вместо заголовка — панель «Выбрано: 1 из N», кнопки «Прочитано», «Флаг», «Категория ▾», «Срок ▾»,
   «В папку ▾», «Архив», «Удалить», «×». Компактная плотность (Настройки → Общие) — флажок на месте 18 px.
2. Ctrl+щелчок по другому письму (открыто одно) — выделены оба; Shift+щелчок ниже — диапазон от последнего, прежние
   Ctrl-письма на месте; Shift+↓/↑ — диапазон растёт и сжимается; Ctrl+A — все письма папки («Выбрано: N из N»);
   Esc — выделение снято (в поле поиска Ctrl+A выделяет текст).
3. Выделено два и больше — в области чтения сводка: «N писем выбрано», «От: … и ещё N · размер · непрочитанных»,
   первые письма с «×» (убрать из выделения), кнопки с клавишами, «Esc — снять выделение · Снять».
4. «Прочитано» на выделении — все прочитаны, тост «Прочитано · N писем · Отменить»; «Отменить» — непрочитанными снова
   только те, что были. Ctrl+Q / Ctrl+U / Insert / клавиши 1–9 при выделении — так же пачкой.
5. «Архив» (или Backspace), «В папку ▾» → папка, «Удалить» (Delete): письма ушли из списка, выделение снято с ушедших,
   тост с «Отменить» возвращает их. В «Удалённых»: выделить → «Удалить» — строка «Удалить навсегда N писем?» → «Да».
6. «Срок ▾» на выделении — панель сроков «Срок · N писем»; вариант — метка у всех.
7. Правая кнопка по строке (в выделении — меню над выделением с «Выбрано N писем», вне — над этим письмом, строка в
   рамке; у строки беседы это её последнее письмо, всем письмам — выделением): «Ответить / Ответить всем / Переслать» (для нескольких — серые), «Прочитано», «Флаг», «Категория ▸» с цветами,
   «Срок…/Напомнить…/Ждать ответа…/Исчезнет…», «Переместить ▸» с папками, «Архив», «Удалить», «Сообщить о фишинге» с
   красной маской. Клавиатура: Shift+F10 или клавиша «Меню» — меню у выбранной строки; ↑/↓, → — подменю, ← — назад,
   Enter — выполнить, Esc и щелчок мимо — закрыть; j/k и цифры в открытом меню список не трогают.
8. Ctrl+Shift+V — меню с открытым «Переместить ▸»; щелчок по папке — письмо там, тост «Перемещено в «…»».
9. Стенд: «Сообщить о фишинге» у письма — оно в «Нежелательных» (Junk Mail), закладка «Угрозы» его находит (счётчик +1),
   тост «Сообщено о фишинге · 1 письмо в «Нежелательных» · Отменить»; «Отменить» — обратно во «Входящих», «Угрозы» −1.
10. Стенд: Настройки → Общие → «Сообщения о фишинге» — адрес user2 (не адрес — подсказка «Это не адрес почты»); снова
    «Сообщить о фишинге» — у user2 письмо «Фишинг: 1 письмо» с вложением `.eml`, у user1 тост «Сообщение о фишинге
    отправлено на …». Поле пустое — пересылки нет.
11. Стенд, офлайн: отключить сеть (или VPN к стенду) — в строке состояния серая точка «Нет связи · повтор через N с»
    (обратный отсчёт, растёт 5 → 10 → 20 → 40 → 60 с), над своими папками — логин и метка «нет связи», над списком —
    полоса «Нет подключения к … Повторить сейчас» с «×»; тоста «Нет связи…» нет. Без связи отметить письмо прочитанным
    и перенести другое в «Архив» — в строке состояния «2 изменения ждут отправки»; «Повторить сейчас» — попытка сразу.
    Включить сеть — всё снято, в 🔔 записи «работаем офлайн» и «восстановлена», на сервере (веб-клиент Stalwart)
    отметка и перенос появились. Простой без связи — CPU ~0 % (таймер раз в секунду).
12. Тосты: сделать подряд 5 действий с тостом (например «Прочитано»/«Флаг» на разных письмах) — видно три, новые
    сверху, под ними «+2 ещё» (открывает историю); у тоста «N с» до скрытия и полоса внизу; предупреждение — серая
    полоса слева, ошибка — красная; × и щелчок по тосту — закрыть. 🔔 в строке состояния — панель «Уведомления» справа:
    «Все / Ошибки / Действия», группы по дням, «Отменить» в истории работает, после — «выполнено»; Esc закрывает.
    Тёмная тема — всё то же, маска и ошибки — приглушённый красный.

## 30. Палитра команд и поиск (S5-10)

1. Ctrl+K — оверлей под заголовком окна поверх командной строки (не окно, не затемняет): группы «Команды», «Папки»,
   «Быстрые фильтры»; у команд справа клавиши. ↑/↓ — по строкам (с последней — на первую), Enter — выполнить, Esc и
   щелчок мимо — закрыть, Ctrl+K ещё раз — тоже закрыть; фокус возвращается туда, где был.
2. Выполнить из палитры «Ответить всем», открыть папку «Архив», включить быстрый фильтр «Срок»; снова Ctrl+K с пустым
   запросом — эти строки первыми в своих группах.
3. Набрать `арх` — «Архив» папкой (и в общих ящиках — с именем ящика); `fh[` (то же в английской раскладке) — то же
   самое; `нвпс` — «Создать письмо» (буквы по порядку), совпавшие буквы — жирные. Справа — «N результатов».
4. Набрать слово из темы письма (`отчёт`) — группа «Письма»: отправитель, тема с янтарной подсветкой, дата; Enter —
   письмо открыто справа. Во вкладке письма (Ctrl+N) Ctrl+K: есть «Отправить письмо», «Жирный»; выполнить «Жирный» —
   сработал в тексте письма.
5. Ctrl+E, ввести `квартал` (без Enter): через полсекунды — результаты; поле шире, справа в нём «Везде | Текущая
   папка». Над списком «Поиск: квартал · N результатов · все папки» и «×»; письма группами по папкам («Входящие»,
   «Архив», «Отправленные»), группа сворачивается.
6. Совпадения в строках (отправитель, тема, начало текста) — янтарной подложкой, словоформы тоже («квартала»).
   Открыть письмо — подсветка в теме и тексте, над текстом «Совпадение 1 из N · «квартал»» (с S5-14).
7. «Уточнить»: чипы «от: …», «есть: вложения», «непрочитанные», «за 30 дней» (или «за 7 дней»), «категория: …» —
   нажать — чип тёмный, в строке поиска появилось условие (`has:attachment` и т. п.), результатов меньше; ещё раз —
   условие снято. Чипов больше, чем места, — строка прокручивается колесом.
8. Синтаксис руками: `from:петров after:30d`, `subject:счёт is:unread`, `кому:мне есть:вложения`, `before:2026-10-01` —
   результаты соответствуют; `Re: договор` — `Re:` просто слово. «Текущая папка» — без групп по папкам, только открытая
   папка.
9. Esc в поле поиска — снова папка, подсветки нет. Папка слева во время поиска — открыта папка, без подсветки.
10. Стенд, «Везде»: слово, которое есть только в письмах за пределами загруженных страниц, — находится (сервер),
    «ищем на сервере…» в строке над списком пропадает; без сети (выдернуть кабель) — поиск по своему индексу работает,
    интерфейс не замирает при наборе. Тёмная тема: подсветка — тёмная янтарная, текст читается; палитра — на слое окна.

## 31. Вид беседы: стопка, как Outlook, на папку (S5-05б)

Демо-ящик: беседа «Пилот SIEM: сроки» — 4 письма (2 во «Входящих», 2 в «Отправленных»).

1. Правая кнопка по «Входящим» — меню «Вид беседы ▸»; наведение или → — «Лента / Стопка / Как Outlook / По умолчанию»
   (галочка у текущего, у «По умолчанию» справа — общий вид из настроек); ↑/↓, Enter — выбрать, ← — назад, Esc и щелчок
   мимо — закрыть; j/k при открытом меню список не трогают.
2. «Стопка» → открыть «Re: Пилот SIEM: сроки»: под темой «4 письма · 2 участника · Развернуть все», письма от старых к
   новым; прочитанные — строкой (аватар, отправитель, начало текста, дата), последнее и открытое — раскрыты (шапка
   «Кому: …», время, «Ответить» и «Переслать»), у письма с историей — «··· показать цитату» (повторно — скрыть).
3. Щелчок по строке — письмо раскрыто и открыто (шапка и вложения — у него); щелчок по шапке раскрытого — свёрнуто;
   Enter — свернуть или раскрыть открытое; «Развернуть все» / «Свернуть все»; Ctrl+→ / Ctrl+← — по письмам, каждое
   раскрывается. «Ответить» у письма стопки — ответ именно на него.
4. «Как Outlook» во «Входящих»: в шапке списка и строке состояния — число писем; беседы — одной строкой со стрелкой
   «›» и числом писем в серой таблетке; одиночные письма — как раньше. Щелчок по стрелке — под строкой письма беседы
   (строки ниже, с отступом и линией, точка — непрочитанное), без черты под головой; ещё щелчок — свёрнуто.
5. Клавиатура в «как Outlook»: j/k — по видимым строкам; → на беседе — развернуть, ещё → — к первому письму под ней;
   ← на письме под головой — к голове, ещё ← — свернуть; Enter — свернуть или развернуть. Открыт просмотр вложения —
   ← / → листают вложения, как раньше.
6. В области чтения при «как Outlook» — одно письмо и строка «Беседа: N писем · ← пред. · след. → · k из N»; кнопки и
   Ctrl+→ / Ctrl+← — по всем письмам беседы (и из «Отправленных»), у краёв кнопка серая.
7. Выделение (S5-08) при «как Outlook»: флажок или Ctrl+щелчок по строке беседы — выбраны все её письма (сводка «N
   писем»), повторно — сняты; Shift-диапазон и Ctrl+A — с письмами свёрнутых бесед; «Прочитано», «Архив», «Удалить» —
   над всеми; правая кнопка по строке беседы — меню «Выбрано N писем», «Ответить» — на верхнее письмо.
8. Настройки → Чтение: общий вид («Лента» / «Стопка» / «В списке, как Outlook») и «Вид для папки» — то же, что в меню
   папки, меняется сразу в открытой папке; «По умолчанию» в меню снимает свой вид папки. Перезапуск — выбор на месте.
   Тёмная тема — таблетка, линии беседы и строки стопки читаются.

## 32. Доводка S5: переход по совпадениям, значки палитры (S5-14)

1. Ctrl+E, `квартал`, открыть письмо Outlook из результатов. Над текстом — «Совпадение 1 из N · ↑ ↓ · «квартал»»;
   первое совпадение (в теме) — плотной янтарной подложкой, остальные — бледной.
2. F3 — «2 из N», выделено следующее совпадение; ещё F3 до последнего, затем F3 — снова «1 из N» (по кругу);
   Shift+F3 — назад. Кнопки ↑ / ↓ в строке — то же. Совпадение ниже края области чтения — прокручивается в вид
   (примерно на треть высоты), выше края — тоже; видимое — без прокрутки.
3. F3 в поле поиска (курсор там) — тоже переход. Другое письмо — снова «1 из N». Esc — поиск закрыт, строки и
   подсветки нет, F3 ничего не делает. Одно совпадение — «1 из 1» без стрелок.
4. Ctrl+K: у каждой команды свой значок (ответ — стрелка, удалить — корзина, срок — часы, жирный — «B», настройки —
   шестерёнка…), не одинаковые шевроны; значков-квадратиков («тофу») нет. Тёмная тема — значки читаются.
5. Настройки → Клавиатура: «Следующее совпадение в письме» — F3, «Предыдущее» — Shift+F3; переназначение работает.

## 33. S/MIME: проверка подписи (RSA, ГОСТ) (S5-12 Ф1)

Подпись проверяет воркер-песочница (`postman-smime`), цепочку и отзыв — Windows; ГОСТ — своя реализация Postman
(не сертифицирована) или СКЗИ, если оно установлено. Демо-ящик: `postman.exe --demo 2000`.

1. Демо: письмо «Договор поставки: подписанная версия» (Петров Иван) — в шапке справа серый значок «✓ Подписано ˅»;
   `smime.p7s` в ленте вложений нет. Щелчок по значку — под шапкой карточка «Цифровая подпись»: «Подпись верна…», кто
   подписал (имя · адрес), издатель с меткой «корпоративный», срок, отпечаток SHA-256 группами, «RSA 2048 · SHA-256»,
   время подписи, «Отзыв: не проверялся (демо-ящик)», «Сертификат сохранён…». Ещё щелчок — карточка закрыта. Палитра
   Ctrl+K → «Подробности подписи» — то же.
2. «Акт сверки за III квартал» (Соколова Мария): «Подписано», в карточке — «ГОСТ Р 34.10-2012 (256 бит, TC26-256-B) ·
   Стрибог-256», «Проверено: Postman, без СКЗИ (реализация не сертифицирована)», «Отзыв: не проверен (ГОСТ без СКЗИ)»,
   метки «корпоративный» нет.
3. «Счёт на оплату №2041» (Бухгалтерия): значок красный «Подпись недействительна», карточка — красная полоса слева и
   «Содержимое письма изменено после подписи…»; красный — только тут и в п. 6.
4. «Коммерческое предложение» (ООО «Вектор»): серый «Издатель не доверен», карточка — «Подпись верна, но сертификат
   выпущен не доверенным центром», «Отзыв: не проверялся», «Сертификат сохранён…» нет.
5. Тёмная тема (`--theme dark`) — значки и карточка читаются, красный приглушён, как у щитка вложений.
6. Стенд, Outlook (RSA): из Outlook (сертификат S/MIME корпоративного или тестового CA в «Личных» и корень — в
   «Доверенных корневых») отправить подписанное письмо на ящик Postman. В Postman: «Подписано», в карточке — имя и адрес
   из сертификата, издатель, «RSA 2048 · SHA-256», «Отзыв: не отозван · проверено …» (CA с HTTP CDP доступен) или
   «не проверен — нет связи с центром сертификации» (CDP недоступен). Повторное открытие — мгновенно (из кэша).
7. То же письмо, корень CA удалён из «Доверенных корневых» (или CA не установлен): перезапуск Postman — «Издатель не
   доверен». Сертификат подписанта помещён в «Недоверенные сертификаты» — красный «Сертификат подписи
   недействителен». Вернуть хранилища как было.
8. Письмо от адреса, которого нет в сертификате (Outlook: общий ящик или «От» вручную) — красный «Адрес подписи не
   совпадает с «От»», в карточке — оба адреса.
9. ГОСТ [проверить]: письмо, подписанное в КриптоПро CSP (или ViPNet) сертификатом ГОСТ Р 34.10-2012, если удастся
   получить — «Подписано», «ГОСТ Р 34.10-2012 (… бит, …)», «Проверено: Postman, без СКЗИ». Затем установить КриптоПро
   CSP (пробная версия на 90 дней), перезапустить Postman: «Проверено: СКЗИ (<имя провайдера>): цепочка и отзыв;
   подпись — Postman», отзыв — как у RSA (по CDP УЦ). Удалить КриптоПро — снова «без СКЗИ».
10. Письмо с подписью внутри (`smime.p7m`, Outlook: «Отправить подписанное сообщение открытым текстом» выключено) —
    тело показано, `smime.p7m` в ленте нет. Зашифрованное письмо — `smime.p7m` остаётся вложением, значка нет
    (расшифровка — Ф2). Поток окна не замирает ни на одном шаге (CA недоступен — проверка в фоне до 10 с).

## 35. Хоткеи схемы «Outlook» и вкладки почты (Ctrl+T) (S5-16)

Демо-ящик (`--demo 50000`); шаги 1–5 — в русской и английской раскладке. Свои клавиши до проверки — сброшены
(Настройки → Клавиатура → «Сбросить все»), кроме шага 6.

1. «Почта»: ↓/↑ — по письмам; J и K ничего не делают. Insert — панель «Срок» у письма; флаг — только кнопкой «Флаг»
   (панель выделения, контекстное меню). Ctrl+Shift+G и Ctrl+Shift+F — ничего; фильтры — воронкой.
2. Письмо с приглашением: A, T, N ничего не делают; «Принять» / «Под вопросом» / «Отклонить» — кнопками.
3. «Календарь» (Ctrl+2): PgDn / PgUp — следующая и предыдущая неделя, Home — сегодня; Alt+↑/↓, Alt+Home — ничего.
4. Новое письмо (Ctrl+N) и вкладка встречи (Ctrl+Shift+Q): Ctrl+Enter отправляет, Alt+S — нет.
5. Ctrl+T на «Входящих»: справа от «Почты» — вкладка «Входящие» (значок письма), тот же список. В ней: воронка →
   «Все папки» и «Непрочитанные», выбрать письмо — название вкладки «Все папки». Ctrl+Tab в «Почту» — там «Входящие» без
   фильтров и прежнее письмо; Ctrl+Tab обратно — «Все папки» с фильтром и выбранным письмом. Ещё Ctrl+T — третья
   вкладка справа. Ctrl+W во вкладке почты — закрыта, активна соседняя слева со своим состоянием; «Почту» Ctrl+W не
   закрывает. Во вкладке почты щелчок «Календарь» в заголовке — главная вкладка с календарём.
6. Перенос своих клавиш: закрыть Postman; в `%LOCALAPPDATA%\Postman\settings.json` убрать `keys_rev` и поставить
   `"keys": { "mail.next": ["j"], "mail.remind": ["insert"], "compose.send": ["ctrl-enter", "alt-s", "ctrl-s"] }`.
   Запустить: Настройки → Клавиатура — у «Следующее письмо» клавиши нет, «Напомнить» — Insert, «Срок…» — без
   клавиши, «Отправить письмо» — Ctrl+Enter, Ctrl+S; конфликтов нет.

## 37. Схема «Одиночные клавиши» (S5-17)

## 38. Встреча: свободные окна и клавиши (S5-23)

Демо-ящик, обе темы.

1. Ctrl+Shift+Q (новая встреча), участники из демо. «Только общее свободное время»: общие окна — тонкая мягкая рамка
   цвета свободного времени без заливки, подпись времени — снизу столбца; наведение — рамка плотнее и свечение.
   Выбранное время — рамка того же цвета со свечением. Строки «нет данных» и внешних — бледная заливка без штриховки,
   у внешних — голубая, не бирюзовая; «вне офиса» в «занятости каждого» — серый.
2. Щёлкнуть по пустому месту сетки, затем → и ←: свечение переходит по общим окнам, у края дня — остаётся на месте;
   Enter — встреча в окно под свечением (поля «Начало – конец» меняются). Подсказка при наведении на сетку — «← → — по
   свободным окнам, Enter — выбрать». В поле «Тема» ←/→ двигают курсор текста, Enter окна не трогает.
3. Сменить длительность на 2 ч: окна короче пропадают, ←/→ идут по оставшимся.
4. Ctrl+Shift+B — фокус в поле «Обязательные», подсказки адресов из справочника и контактов.
5. «Настройки → Календарь» → «Синий»: окна, свечение и рамка выбранного — синие.
6. Выбранное время: тянуть рамку мышью — встреча сдвигается по шагу сетки (30 мин; «Шаг сетки» 15 мин — по 15),
   за край дня не уходит; тянуть левую и правую ручки — меняются начало и конец, короче шага не становится. Поля
   «Начало – конец» и длительность — следом. Shift+→ / Shift+← (вне полей) — конец на шаг.
7. PgDn / PgUp — следующий и предыдущий день, Home — сегодня (вне полей; в поле — курсор текста).
8. Ctrl+D или значок корзины справа на панели — вкладка встречи закрывается без отправки.
9. «Занятость каждого»: «занят» — синяя заливка (тёмная — приглушённый синий), «под вопросом» — бледно-голубая с синей
   рамкой; в строке «нет данных» ссылки «Запросить доступ» нет.

## 39. KeyTips и подсказки кнопок (S5-18)

Демо-ящик (`--demo 50000`), письмо открыто.

1. Удерживать Ctrl ~полсекунды: над «Новое письмо», «Ответить» и другими кнопками командной строки, полем поиска,
   разделами в заголовке, «×» активной вкладки, «Срок» в шапке письма — плашки с клавишами (Ctrl+N, Ctrl+R, Ctrl+E, Ctrl+1…, Insert).

3. Настройки → Клавиатура → «Одиночные клавиши»: удерживать Ctrl — на кнопках R, A, F, C, /; на карточке

4. Настройки → Клавиатура → выключить «KeyTips»: удержание Ctrl плашек не показывает, подсказки остались.

## 40. Живое отображение Markdown в письме (S5-27)

Демо-ящик, Ctrl+N.

1. Набрать: `## Итоги`, Enter, `**важно**`, `*курсив*`, `<u>подчёркнуто</u>`, `~~старое~~`, `` `код` ``,
   `[отчёт](https://corp.example)`, `> цитата`, `- пункт` и вложенный `  - пункт`, `1. первый`. По мере ввода: заголовок
   и «важно» — жирные, «курсив» — курсивом, «подчёркнуто» — с линией, «старое» — зачёркнуто, «код» — на подложке,
   «отчёт» — акцентом с подчёркиванием, цитата — серым, маркеры списков — акцентом; знаки `##`, `**`, `*`, `<u>`,
   `~~`, `` ` ``, `[`, `](…)`, `>` — приглушённо. Курсор, выделение, Ctrl+Z работают как в обычном поле.
2. Незакрытое `**слово` — обычный текст; `\*не курсив\*` — звёздочки как текст, косая черта приглушена.
3. Кнопки «Ж», «К», «Ч», списки, ссылка, цитата — разметка вставляется и сразу оформлена. Кнопки «Предпросмотр» и
   Ctrl+Shift+P больше нет.
4. Отправить себе: письмо пришло оформленным (HTML) — как набрано.
5. Ответ в области чтения (Ctrl+R) — то же оформление. Тёмная тема — цвета разметки читаются.

## 42. Цвета по таблице токенов DESIGN (S5-31)
