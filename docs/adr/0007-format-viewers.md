# ADR 0007. Просмотрщики форматов: встроенные — в воркере, новые — модулями WASM в песочнице

Статус: **предложение** (S8, `docs/specs/S8.md`). Требование владельца 2026-10-28 —
`docs/decisions/2026-10-28-v1-requirements.md` п. 3: xlsx и pptx, другие популярные форматы, новые — без
перекомпиляции. Меняет воркер (`crates/worker`, CODEOWNERS) и пакет установки (новый `postman-viewer.exe`).

## Как сейчас

- Просмотр вложений — в воркере-песочнице (`crates/worker/src/preview.rs`, S5-07, T1-13а): `PreviewKind` →
  `Preview`. Есть: картинка (PNG, JPEG, GIF, WebP — `image`), страница PDF (`hayro`), оглавление ZIP, текст
  (UTF-8, иначе CP1251; `.txt`, `.csv`, `.eml`, `.json`, `.xml`…), проверка Office на макросы (OLE `cfb`, OOXML
  `vbaProject.bin`), `.docx` → блоки IR (`quick-xml`, T1-13а).
- Выбор просмотра — `postman_core::attach::viewer` по имени и MIME; `.docm`, `.xlsm`… и старые `.doc`/`.xls`/
  `.ppt` — только проверка на макросы.
- Песочница Windows: AppContainer без capabilities, Job Object (1 ГиБ памяти, один процесс), mitigation policies,
  среди них **`PROHIBIT_DYNAMIC_CODE`** (ACG: нельзя создать исполняемую память); сторож — 8 с на запрос
  (`TIME_LIMIT`), вход — до 48 МиБ (`MAX_INPUT`).
- Размер воркера — 10,13 МиБ при бюджете ≤ 11 МиБ (S7-09, `docs/decisions/2026-10-26-size-budget-s7.md`); после
  `.docx` — 10,35 МиБ (замер ниже).

## Встроенный набор S8 (в воркере, как `.docx`)

Разбор — свой, поверх того, что в воркере уже есть (`zip`, `quick-xml`, `cfb`, `mail-parser`, `image`): новых
крейтов почти нет, защиты те же (лимит распаковки, глубина XML, без DTD и сущностей, пределы блоков и символов).

| Формат | Что показываем | Чем |
|---|---|---|
| `.xlsx`, `.xltx` | листы вкладками: таблица значений (общие строки, числа, даты по `numFmt`, итог формулы из кэша, не вычисление), до 1 000 строк × 100 столбцов на лист | `zip` + `quick-xml` (своё; `calamine` — MIT, но тянет свой `zip` и `encoding_rs`, а нужно ~400 строк) |
| `.pptx`, `.ppsx`, `.potx` | слайды по порядку `presentation.xml`: заголовок, текст фигур, таблицы, заметки докладчика; картинки — пометкой | `zip` + `quick-xml` |
| `.odt`, `.ods`, `.odp` | как docx, xlsx, pptx (`content.xml`) | `zip` + `quick-xml` |
| `.rtf` | абзацы, жирный, курсив, таблицы текстом; кодировки `\ansicpg` (1251 и др.), `\u` | своё (~300 строк) |
| `.csv`, `.tsv` | таблица (разделитель — по первым строкам; UTF-8 / CP1251) | своё, сейчас — текст |
| `.md` | разметка → IR | `pulldown-cmark` (MIT, уже в сборке у `compose`) |
| `.eml`, вложенное `message/rfc822` | письмо в письме: шапка, тело тем же путём HTML → IR, список вложений | `mail-parser` (есть) |
| `.msg` (Outlook) | то же: тема, от, кому, дата, тело (`PR_BODY`, `PR_HTML`; RTF сжатое — LZFu → RTF → текст), вложения | `cfb` (есть) |
| `.bmp`, `.ico`, `.tiff` (сканы, факсы) | картинка, у TIFF — страницы | признаки `image` (`bmp`, `ico`, `tiff`) |
| PDF | уже есть | — |

Не в 1.0: старые двоичные `.doc`, `.xls`, `.ppt` (только проверка на макросы, как сейчас), `.7z` и `.rar`
(оглавление — после 1.0, у `rar` нет чистой лицензии), SVG (рендер — отдельный движок; показ текстом не нужен),
HEIC (кодек под патентами).

`Preview::Document` обобщается: `sections: Vec<Section { title, blocks }>` — у `.docx` одна, у книги — по листу,
у презентации — по слайду; интерфейс показывает вкладки листов и листание слайдов, как страницы PDF.

## Новые форматы без перекомпиляции — варианты

| Вариант | Как | Безопасность | Цена | Итог |
|---|---|---|---|---|
| **A. Модуль WASM в песочнице, интерпретатор `wasmi`** | `<имя>.wasm` + описание; вход — байты вложения, выход — те же `Section`/IR; импортов у модуля нет | две стенки: память WASM (модуль не видит ничего, кроме своего входа) + AppContainer; топливо (`fuel`) и предел памяти — в самом интерпретаторе; ACG не мешает: исполняемой памяти интерпретатор не создаёт | **+0,91 МиБ** к exe (замер ниже); медленнее родного кода в 10–30 раз [оценка] — для просмотра первых N страниц достаточно | **рекомендация** |
| A′. WASM, `wasmtime` + Cranelift (JIT) | то же, компиляция в машинный код | JIT требует исполняемой памяти — **несовместим с `PROHIBIT_DYNAMIC_CODE`**: пришлось бы ослабить песочницу; готовые `.cwasm` — машинный код, загрузка `unsafe` | **+10,43 МиБ** (замер ниже) — больше всего воркера | отклонено |
| B. Декларативное описание | TOML: контейнер (ZIP), путь части, правила «элемент XML → абзац/ячейка/заголовок» | разбор — наш код в воркере; описание кода не исполняет | ~50 КиБ | отклонено как основной путь: годится только для «XML в ZIP»; уже xlsx (общие строки по индексу, форматы чисел, даты) и pptx (порядок слайдов через связи) требуют индирекций — описание вырастает в язык программирования без отладчика; двоичные форматы (RTF, LZFu, OLE) не описать. Остаётся частью модуля A: какие расширения, MIME и сигнатуры он берёт |
| C. Внешние конвертеры | LibreOffice `--headless --convert-to`, Office через COM, `pdftotext` и т. п. | чужой процесс с правами пользователя и сетью вне песочницы; LibreOffice исполняет макросы и регулярно получает CVE разбора; в AppContainer не запускается (профиль, шрифты, реестр) | ноль в exe, но сотни МБ установки на машине, запуск 1–3 с, нет гарантии офлайн и наличия | отклонено: нарушает «чужие данные — только в песочнице» (CLAUDE.md), а песочницу не ослабляем без ADR |

### Решение: A

- **Отдельный процесс `postman-viewer.exe`** — хост модулей WASM на `wasmi`, в той же песочнице, что воркер (код
  `crates/worker/src/sandbox`, AppContainer, Job Object, mitigation policies с ACG). Отдельно, а не в
  `postman-worker.exe`: воркеру остаётся 0,65 МиБ до бюджета (10,35 из 11), они нужны встроенным форматам; хост
  нужен только пользователям модулей и запускается по требованию; сбой модуля не роняет просмотр писем. Бюджет `postman-viewer.exe` — ≤ 2 МиБ
  (база 0,23 + `wasmi` 0,91 + IR и serde ~0,3 [оценка]).
- **Пределы модуля:** вход — до 48 МиБ (как `MAX_INPUT`); память WASM — до 256 МиБ (`StoreLimits`); топливо —
  предел на запрос (порядка 10⁹ инструкций [подобрать по корпусу]); сторож времени процесса — 10 с, как
  `PREVIEW_TIMEOUT`; Job Object — 512 МиБ на процесс; выход — до 8 МиБ и тех же пределов блоков/символов, что у
  `.docx`. Превышение — «не удалось показать», файл можно сохранить.
- **Без сети и ФС:** импортов у модуля нет вовсе (ни WASI, ни своих функций; журнал модуля — строкой в его
  ответе); модуль с любым импортом не загружается. AppContainer без capabilities — вторая стенка.
- **ABI v1** (своё, ядро модели WASM без компонентов — `wasmi` их не поддерживает): экспорты
  `pm_abi() -> u32`, `pm_alloc(len) -> ptr`, `pm_view(ptr, len) -> u64` (указатель и длина ответа), ответ —
  postcard `ViewerOutput { sections | image | error }`. Хост **проверяет ответ как чужие данные**: ссылки — через
  проверку ссылок IR (`postman_ir`), длины и вложенность — пределами, пиксели — размер кадра ≤ 2048 px.
- **Описание модуля** `<имя>.json` рядом: имя, версия, ABI, расширения, MIME, сигнатуры первых байтов, свои
  пределы (не больше общих). Встроенный просмотрщик главнее модуля с тем же расширением.
- **Где лежат:** `%ProgramFiles%\Postman\viewers` (ставит администратор) и `%LOCALAPPDATA%\Postman\viewers`
  (пользователь); в просмотре — подпись «Просмотр: модуль «FB2» 1.0», у пользовательского — «сторонний»;
  «Настройки → Просмотр вложений» — список с включением (вопрос №4 — подпись модулей).
- **SDK:** крейт `viewers/sdk` (guest, `wasm32-unknown-unknown`, без std-ввода-вывода) с типами `Section`/IR и
  макросом экспорта; образец — модуль **FB2** (`viewers/fb2`: XML-книга, частая в России), собирается в CI, в
  пакет не входит. Модули на других языках — по тому же ABI.

Скретч-крейты `target/a-s8spec` (не в рабочей области): пустая программа читает файл; та же программа загружает
модуль WASM и вызывает функцию с топливом.

## Цена

- Встроенные форматы — в воркере: по оценке +0,2–0,4 МиБ (свой разбор, `pulldown-cmark`, признаки `image`);
  с 10,35 МиБ — до 10,6–10,8 при пределе 11 МиБ; если превысит — решение владельца (вопрос №5), не перенос
  форматов в WASM.
- Новый exe в пакете (`postman-viewer.exe` ≤ 2 МиБ) и его сборка в `scripts/windows/package.ps1`.
- Своё ABI — его держим стабильным (номер версии в `pm_abi`); смена — новая версия, старые модули работают.

## Откат

Хост модулей — отдельный exe: без него встроенный просмотр работает как прежде, модули просто не находятся.
