# ADR 0008. Значки — Fluent UI System Icons (SVG) вместо шрифта Segoe Fluent Icons

Статус: **принято** (владелец, 2026-11-06; макет «✓ Главное окно», `MainIcoFluent`). ⚠ отступление от базиса:
базис Pets (`pets-architecture`, эталон — Урфин) рисует значки шрифтом ОС Segoe Fluent Icons (`chrome.rs`, `ICON_FONT`).

## Почему
- Владелец: значки интерфейса «примитивные, дешевят дизайн»; выбран набор Outlook и Teams — Fluent UI System Icons,
  Regular 20 (`docs/DESIGN.md` → «Значки»).
- Segoe Fluent Icons — набор системных настроек Windows: одна толщина, мало почтовых значков (папка со стрелкой,
  ответ всем, черновик, карантин), цвет — только целиком.

## Решение
- SVG из `@fluentui/svg-icons` (MIT, лицензия — в `THIRD-PARTY`), только нужные (≈ 30 файлов, ~20 КиБ), вшиты в exe
  (`include_bytes!`, `AssetSource` gpui), рисуются `svg()` с цветом из токенов `icon.*`.
- Шрифт остаётся для кнопок окна (свернуть, развернуть, закрыть) — системные.
- Обновление набора — вручную, по списку файлов в `app-gpui/res/icons/README.md`.

## Последствия
- Размер exe: +≈ 20 КиБ (бюджет ≤ 53 МиБ).
- Тест: каждый значок из таблицы команд есть в наборе; снимки `list`, `settings-general` — без «квадратиков».
- Урфину — по запросу владельца; в `pets` выносим, если наберётся второе приложение.
