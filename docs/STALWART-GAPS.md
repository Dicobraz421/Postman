# Чего не умеет Stalwart (для отчётов и настройки)

> Справка о поведении Stalwart. С 2026-11-05 основной сервер — The Post, Stalwart не правим, форк ruStalwart закрыт
> (`docs/decisions/2026-11-05-server-thepost.md`). Колонка «патч» — история.

Список пробелов и ошибок, найденных на стенде (Stalwart v0.16.27, Community), — чтобы сообщать о них в Stalwart
или чинить настройкой. Подробности и как проверено — `docs/STALWART.md` (номер находки — «п.»). Новое — сюда же,
сразу по находке. Все строки разобраны по коду и документации сервера 2026-10-21.

Род:
- **ошибка сервера** — поведение противоречит спецификации или себе; о ней — отчёт;
- **нет функции** — нужного нет; о ней — пожелание;
- **наша настройка** — решается конфигурацией стенда или рабочего сервера, коду не нужно;
- **наша ошибка** — клиент или тест пользовался сервером неправильно; исправлено у нас;
- **ограничение спецификации** — сервер делает по RFC или черновику; менять — в рабочей группе IETF JMAP, не у Stalwart;
- **[проверить]** — не подтверждено до конца.

**Куда сообщать.** Только на портал https://support.stalw.art: ошибки — категория Issues (нужен журнал уровня trace),
пожелания — Feature Ideas. Issues и Discussions в GitHub от посторонних закрываются автоматически, подтверждённую
ошибку мейнтейнер переносит туда сам. PR от нас нет: CONTRIBUTING Stalwart запрещает код, написанный ИИ, и принимает
PR только от одобренных авторов. Столбец «Отчёт» — черновик отчёта (у владельца, не опубликован; ссылки появятся
после публикации); `/t/N` — уже существующая тема портала, туда — комментарий.
