# Выпуск — только после полной сверки документации (гейт)

Владелец, 2026-11-12: после T3-13 (трей) инструкция, `README.txt` в архиве и страница выпуска ещё говорили
«закройте Postman перед обновлением», хотя крестик теперь прячет окно в трей. Документы должны догонять код к
каждому выпуску, а не по случаю.

- **Гейт выпуска:** тег `v<версия>` публикуется, только если в его коммите есть `docs/releases/<версия>.md` — сверка
  всей документации: каждый документ отмечен `[x]` и с итогом («обновлено: что, PR» или «без изменений»).
- **Какие документы:** все `*.md` в корне и в `docs/` (без подкаталогов), `scripts/*/README.txt`,
  `.github/release-notes.md`. Новый документ гейт требует сам — список не ведётся руками.
- **Проверка:** job `docs-gate` (`.github/release_docs_check.py`) на теге, до `publish`; красный — выпуска нет.
- **Порядок:** `docs/DEV.md` «Выпуск»; шаблон — `docs/releases/TEMPLATE.md`. Устаревшее исправляется в PR выпуска или
  раньше своими PR по полосам; генерируемые документы пересобирает полоса docs-gen до тега.
