# Postman для macOS

Владелец, 2026-11-11: приступить к версии Postman для macOS. Урфин остаётся только для Windows.

- **Отменяет для Postman** решение «только Windows» (S0 №57 Урфина, 2026-10-20: Linux и macOS не собираются и не
  проверяются) и уточняет п. 4 «Расхождений с базисом» (`docs/specs/S0-decisions.md`, 2026-10-19): Windows —
  основа, macOS — вторая платформа с CI. Linux — по-прежнему по запросу.
- **Только Apple Silicon (arm64), macOS 13 и новее.** Intel не собирается и не проверяется.
- **Подписи Apple пока нет:** приложение подписано ad-hoc (`codesign -s -`), без нотаризации. Пользователю —
  инструкция: первый запуск отклоняется, «Системные настройки → Конфиденциальность и безопасность → Всё равно
  открыть» (или снять карантин `xattr -dr com.apple.quarantine Postman.app`). Аккаунт Apple Developer (подпись
  Developer ID и нотаризация) — к волне выпуска (MAC-06).
- **Ручная проверка** — на MacBook Air M1 владельца: файлы `docs/manual-tests/MAC-*.md`.
- Порядок работ — волны MAC-01…MAC-06 (`docs/tasks/MAC-01.md` и далее). Платформенный код — по-прежнему только
  в `sys`-модулях; песочница воркера на macOS — Seatbelt (`sandbox_init`), не слабее Windows и Linux.
