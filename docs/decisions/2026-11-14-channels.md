# Каналы бесед: почта первая, Telegram модулем, Matrix после

Владелец, 2026-11-14: Postman остаётся почтовым клиентом, но беседа становится общей сущностью для разных каналов —
почта, Telegram, позже Matrix. Каналы — модули по общему договору, как протоколы почты (ADR 0004).

- **Почта — первый и главный канал.** Ничего в почте не упрощается ради чатов; почтовые пути (JMAP, IMAP, EWS)
  подключаются к договору каналов адаптером, без переписывания.
- **Договор канала** — новый ADR (класс B, карточка CH-01): беседа, сообщение, участник, вложение и возможности
  канала (правка, удаление у всех, реакции, «прочитано», «печатает», сквозное шифрование). Правило «Нет у сервера —
  нет на экране» распространяется на каналы: интерфейс показывает только то, что канал умеет.
- **В договоре сразу — всё общее, что возможно** (владелец, 2026-11-14): хранение, поиск, кросс-ссылки между
  каналами (ссылка на сообщение, «Переслать в…», связанные беседы, один контакт во всех каналах), черновики и
  очередь отправки, уведомления и счётчики, экспорт. Канал реализует только протокол. Перечень — CH-01.
- **Общее для всех каналов** делается один раз в ядре: список бесед, поиск, «Медиа беседы», заглушить и закрепить,
  быстрый ответ, @упоминания, ответ на фрагменты. Хранение — единое хранилище (ADR 0006).
- **Первый внешний канал — Telegram** (CH-03): официальный клиентский API, сторонние клиенты разрешены. Ключ
  приложения (`api_id`/`api_hash`) регистрирует владелец; в репозиторий он не попадает.
- **Второй — Matrix** (CH-05), после Telegram: открытый протокол, сквозное шифрование в клиенте. Мосты Matrix к
  закрытым сетям — только на сервере и отдельным решением.
- **Не делаем**: WhatsApp и Signal через неофициальные библиотеки (обратная разработка) — нарушение условий сервисов,
  блокировка аккаунтов, поломки при каждом обновлении. Вернёмся, если появится законный путь.
- **Каналы выключаемы**: настройка и ключ политики организации на каждый канал; новые каналы до стабилизации — за
  флагом, выключены по умолчанию.
- **Чаты поверх почты** (Postman#566) — частный случай этого же договора, канал поверх почтового пути.
- **Очередь**: после текущих задач («Ответить всем» новым участникам, «Медиа беседы», хранилище, удобства мессенджеров).

## Почему
Почта уже движется к виду мессенджера (лента беседы, быстрый ответ, упоминания); тот же интерфейс нужен чатам, и его
выгоднее сделать один раз. Telegram первым — потому что это реально другой протокол (поток событий, правки) с
законным доступом: договор проверяется на настоящем отличии, без серой зоны.
