# Поиск по вложениям: подпись — только если в письме нет; вложения ради поиска не скачиваем

Владелец, 2026-11-11 (ответы на «Решения для владельца» T3-10, PR 559):

- Подпись «во вложении: имя — …отрывок…» в строке результата — только когда само письмо (тема, отправитель и
  получатели, тело) запросу не отвечает. Слова есть и в письме — обычное превью.
- Вложения в фоне ради поиска по их тексту не скачиваем: ищется текст вложений, уже лежащих на компьютере.
- Пределы текста вложений в индексе — пока 64 КБ на вложение и 256 КБ на письмо.

На будущее (хотелки, отдельными задачами):

- Фоновая загрузка вложений ради поиска по их тексту.
- Текст PDF в поиске — новая возможность воркера (полоса sandbox).
- Пределы текста вложений — настройкой.
