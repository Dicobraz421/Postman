# Linux — обычная платформа (не tier 2)

Владелец, 2026-11-13: Linux больше не tier 2. Пересмотр, обещанный решением `2026-11-12-linux.md` после LIN-03:
LIN-01…LIN-06 сделаны и вышли в 0.1.0-beta.6.

- **Linux — третья платформа на общих правилах**: Windows — основа, macOS — вторая, Linux — третья; слово «tier 2»
  снимается.
- **CI**: Linux-проверки (clippy, модули просмотра wasm32, nextest с полной песочницей, снимки под Xvfb) входят
  в обязательную проверку `gate`. Способ — job `linux` переносится из `linux.yml` в `ci.yml` и попадает в `needs`
  у `gate`: без связки между workflow, и проверяется в очереди слияния (у `linux.yml` нет `merge_group`). В
  `linux.yml` остаётся `bundle` — артефакт сборки для разработки на PR.
- **Ручная приёмка** — когда будет стенд (GNOME на Wayland и KDE); до того карточки Linux закрываются по CI.
- Прочее решения `2026-11-12-linux.md` (выпуск AppImage + deb + rpm, песочница, бюджеты) — в силе.

## Почему
Платформа выпускается и обновляется сама; поломка Linux, не замеченная `gate`, уходит в main и в выпуск.
