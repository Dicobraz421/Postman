# Внешние картинки: «Загрузить картинки» и доверенные домены

Владелец, 2026-11-11 (отзыв бета-тестера, issue #552, п. 5: «добавлять внешние домены в доверенные, чтобы письмо
нормально прогружалось»). Принят рекомендованный вариант. Решение заменяет отмену картинок «От доверенных» из T2-G
(«Отменено: картинки „От доверенных/Всегда“») — только эту часть; остальные отмены того списка в силе.

- **В письме.** Строка «Внешние картинки не загружаются (N)» над текстом получает две кнопки:
  «Загрузить картинки» — только это письмо и только сейчас; «Всегда для домена <домен отправителя>» — домен в
  доверенные. Письма доверенных доменов загружают картинки сами.
- **В настройках.** «Настройки → Безопасность», рядом с «Картинки из интернета» (Не загружаются никогда / Спрашивать):
  список доверенных доменов — добавить и убрать.
- **Кнопки — только при «Спрашивать».** «Не загружаются никогда» (выбор пользователя или политика организации
  `ExternalImages = never`) — ни загрузки, ни кнопок, доверенные не действуют: политика сильнее выбора. По умолчанию —
  «Спрашивать» (владелец, 2026-11-11): без нажатия картинки всё равно не грузятся. Прежний файл настроек с
  «никогда» один раз переводится на «Спрашивать» — до T3-04 «Спрашивать» ничего не меняло.
- **Риск принят.** Загрузка сообщает отправителю, что письмо открыто, — только по явному выбору пользователя.
- **Опасное письмо** (`$phishing`, `pm.threat` — решение `2026-11-09-security-is-server.md`): ни кнопок, ни загрузки с
  доверенного домена.
- **Песочница не ослаблена.** Картинки качает процесс интерфейса (тот же HTTPS-клиент, что ссылки занятости S8-42:
  только `https`, имя сервера, а не IP и не `localhost`, без входа и кук; `http` — повышается до `https`), байты
  раскодирует воркер (как картинки `cid:`), у воркера сети по-прежнему нет. Пределы: 5 МиБ на картинку, 20 МиБ и
  40 картинок на письмо, 5 с на картинку; пиксели слежения 1×1 не грузятся никогда. Байты — в памяти до выхода
  (16 последних писем), на диск не пишутся.
- Домен — точное совпадение с доменом адреса отправителя (`corp.example` не включает `mail.corp.example`).
