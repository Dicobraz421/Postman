# 2026-11-04. Внешние встречи: занятость внешних участников, публикация и подписка на календари

Решение владельца (проверка клиента 2026-11-04). Серверная сторона — The Post, SRS ред. 7 п. 4.4
(`Dicobraz421/ThePost`, решение `docs/decisions/2026-11-04-calendar-external-api.md`).

Что уже работает и не меняется: приглашения внешним участникам (`sendSchedulingMessages`, iMIP рассылает сервер), входящие
приглашения из писем (разбор в воркере, ответ организатору), занятость коллег (`Principal/getAvailability`), отложенная отправка.

Новое:
- Занятость внешних участников в помощнике планирования. Если сервер объявил `urn:thepost:availability` — `Availability/get`
  для адресов, которых нет среди Principal; иначе (Stalwart и др.) — запасной путь: ссылка занятости `FBURL` из карточки контакта,
  загрузка VFREEBUSY, разбор — только в воркере. Нет данных — «нет данных», не «свободен».
- Публикация своего календаря по ссылке — если сервер объявил `urn:thepost:calendarpublish`: создать, показать, отозвать
  ссылку, уровень детализации («занят / свободен», «тема и время», «полностью»).
- Подписка на опубликованный календарь (ссылка ICS или webcal): отдельный календарь только для чтения, обновление по интервалу
  из настроек (обоснованный таймер: у источника нет уведомлений), разбор — только в воркере; работает с любым сервером.
- Расширения определяются по `capabilities` сессии JMAP; без них соответствующие действия скрыты.
