# «Поручить дальше» — через отказ с предложенным исполнителем

Владелец, 2026-11-10 (сверка макетов T2-G, вопрос по T2-30): «1 б, кнопку меняй если надо».

- Нового шага поручения (iTIP `PARTSTAT=DELEGATED`) нет. Исполнитель, пока поручение ждёт ответа, жмёт «Предложить
  другого»: выбирает коллегу, пишет причину — уходит обычный отказ с комментарием «Предлагаю передать: Имя <адрес>».
- У автора «Поручить другому» открывается с предложенным исполнителем — одно действие.
- Кнопка на макете («Поручить дальше») переименована в «Предложить другого»: передачи без автора нет.
