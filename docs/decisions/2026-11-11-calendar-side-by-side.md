# Календари коллег — наложением по умолчанию, переключатель «Рядом»

Владелец, 2026-11-11, по отзыву бета-тестера (issue #552, п. 2): «Календарь — календарь коллеги в отдельном блоке
(чтобы не накладывался на мой)».

- По умолчанию — как сейчас, наложением (макет S5-22): события коллег в одной сетке с моими, цветом календаря владельца.
- Добавлен режим «Рядом», как в Outlook («Просмотр рядом» / «Наложение»): у каждого показанного календаря (мой и каждый
  отмеченный флажком коллега) — свой блок дней с шапкой (имя и цвет владельца), блоки рядом через зазор, шкала времени
  общая слева, пересечения считаются в каждом блоке отдельно. Виды «День», «Раб. неделя», «Неделя»; «Месяц» — всегда
  наложением.
- Режим один на все календари: кнопка-переключатель «Рядом» в командной строке календаря, команда в палитре,
  «‹» в шапке блока коллеги возвращает наложение. Выбор хранится в «Настройки → Календарь» (`calendar.side_by_side`).
- Показан только мой календарь — оба режима выглядят одинаково.
- Макет `Calendar` режима «Рядом» не рисует — его дорисует сессия дизайна; до неё раскладка — по этому решению.
