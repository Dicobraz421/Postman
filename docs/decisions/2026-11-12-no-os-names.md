# Без названий ОС в текстах интерфейса

Владелец, 2026-11-12. В текстах интерфейса на всех ОС нет названий ОС и систем («Windows», «macOS», «Диспетчер
учётных данных Windows», «BitLocker» и т. п.), кроме случаев явной необходимости: «система», «системное хранилище
паролей», «шифрование диска».

- Системная тема называется «Как в системе» / «System» (`pets-ui-theme-system`, pets); язык и часовой пояс по
  системе — так же.
- Варианты строк под ОС (`<ключ>-mac`, `sys::os_key` в `app-gpui`) допустимы только там, где действия разные: клавиши
  (⌘ вместо Ctrl, Option вместо Alt), меню.
- Исключение — страница выпуска и документация для выбора файла под ОС.
- Проверка — тест `sys::os_texts::texts_have_no_os_names` (`app-gpui/src/sys/mod.rs`).
