# Пересылка и интеграции — только на сервере; порядок правил без Alt

Владелец, 2026-11-11 (сверка макетов T2-G, вопросы T2-50).

## Пересылка и интеграции

«Любые пересылки или связанные с этим интеграции делает сервер. Клиент занимается своей частью задачи. ДЛП или
что-то еще другое работает только на уровне сервера, но работает в 100% случаев.»

- Пересылку по правилу (`redirect :copy`) и любые интеграции, которые отправляют почту наружу, выполняет только сервер.
  Postman их не повторяет и не выполняет сам, даже когда запущен.
- Правило с действием «Переслать» всегда уходит на сервер. Выбор «в приложении» у такого правила не действует
  (`rules.rs`: `local` сбрасывается при `Action::Redirect`).
- Проверки DLP и подобные — на сервере, для всех писем. В клиенте своей DLP для пересылки нет.
- Подпись макета `SettingsRules` «Правила без пересылки и карантина уйдут на сервер» (пересылка в приложении)
  отменена этим решением.

## Порядок правил

«1 а да» — Alt+↑/Alt+↓ из подсказки макета `SettingsRules` не добавляем: правило клавиш «Alt не используется»
(макет `SettingsKeys`) без исключений. Порядок меняется стрелками у строки правила.
