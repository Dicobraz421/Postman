# Postman для Linux — tier 2, выпуск AppImage + deb + rpm

Владелец, 2026-11-12: приступить к сборке Postman под Linux — на тех же условиях, что Урфин (решение Урфина
`docs/decisions/2026-11-12-linux.md` того же дня).

- **Снимает «Linux — по запросу»** (`docs/specs/S0-decisions.md`, 2026-10-19; `2026-11-11-macos.md`): запрос сделан.
  Windows — основа, macOS — вторая платформа, Linux — третья.
- **Статус — tier 2** до конца этапа «Запускается» (LIN-01…LIN-03): Linux собирается и тестируется в CI отдельным
  `linux.yml`, ручной приёмки нет, в `gate` не входит. Потом статус пересматривается.
- **Окно и отрисовка** — штатный gpui для Linux (Wayland и X11, wgpu/Vulkan); под отдельные оконные менеджеры ничего
  не пишем. Системная интеграция — стандарты freedesktop (Secret Service, portal, `xdg-open`, `.desktop`) в
  `sys`-модулях.
- **Вид** — Fluent, как на Windows; из системы — только тёмная/светлая тема и акцент.
- **Выпуск** — AppImage, deb и rpm (x86_64); Flatpak не делаем. Строка «Linux — `linux-x64.tar.gz`» в `docs/DEV.md`
  («Выпуск», S8-39) заменяется этим решением — правит LIN-06.
- **Бюджеты** скорости и размера на Linux — предупреждение, не блокируют.
- **Ручная проверка** — отложена: стенда с Linux нет; появится — GNOME (Wayland) и KDE.
- **Песочница воркера** — seccomp + Landlock, не слабее Windows и macOS; ослаблять нельзя (LIN-04).

## Почему

Замер 2026-11-12 (облачная сессия, Ubuntu 24.04 x64, `main` @ 13a3b88), без правок кода:

- `cargo check --workspace --all-targets --locked --features postman-worker/viewer` — без ошибок и предупреждений.
- Debug-сборка `postman`, `postman-worker`, `postman-viewer`; окно под Xvfb (X11, Vulkan llvmpipe) показывает
  демо-ящик, минута работы без ошибок в журнале.
- Системные пакеты сборки: `libkrb5-dev`, `libxkbcommon-dev`, `libxkbcommon-x11-dev` (плюс Wayland, xcb, fontconfig,
  Vulkan).
- Не работает: значки шрифта Segoe Fluent Icons («квадратики»); хранилище паролей, снимок окна (`--screens`),
  `mailto`, автозапуск, журнал в файл, открытие в файловом менеджере — заглушки `not(any(windows, macos))`.
- Не проверено: nextest, clippy, песочница, Wayland; `--bench` под Xvfb не завершился за 150 с; release-сборка
  `postman` (thin LTO) не уложилась в 30 минут на 4 ядрах.
