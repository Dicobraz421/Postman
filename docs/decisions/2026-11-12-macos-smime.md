# S/MIME на macOS — решения по вопросам PR MAC-05

Владелец, 2026-11-12 (Dicobraz421/Postman#587). Все — рекомендованные варианты.

1. **Список своих сертификатов в настройках** — отдельной задачей для обеих ОС: `docs/tasks/S5-12.7.md` (экран
   «Безопасность → свои сертификаты», `docs/SMIME.md` §7). Ядро уже отдаёт список — `personal_certificates()`.
2. **Без окон при открытии письма** — оставить `SecKeychainSetUserInteractionAllowed(false)` на время операции (под
   замком, флаг процесса); смарт-карты проверить на M1 (`docs/manual-tests/MAC-05.md`, шаг 4). Отвергнуто:
   `LAContext.interactionNotAllowed` — не покрывает файловую Связку «вход».
3. **«Корпоративные» корни** — домен доверия администратора; на M1 проверить корень из профиля MDM. Метки нет —
   корень задаётся отпечатком в `POSTMAN_CORPORATE_CA` (доверие от этого не меняется). Отвергнуто: считать
   корпоративными все корни Связки «Система», кроме Apple.
4. **Промежуточные сертификаты** — только из письма (хранилища CA, как у Windows, на macOS нет; Outlook кладёт
   цепочку в письмо). Отвергнуто: CA-сертификаты из Связок ключей.
5. **Зависимости в межполосном PR `x/*`** — можно, если задача прямо требует крейт (`security-framework` в MAC-05);
   отдельный PR полосы deps не нужен.
