# Состав списков рассылки справочника: `members` у The Post, число — при выборе

Владелец, 2026-11-11 (T3-09, вопросы из PR #558):

- **JMAP.** Состав группы справочника The Post отдаёт свойством `members` у `Principal` («делаем members»): список
  идентификаторов участников или множество `id → true`. RFC 9670 его не описывает — это расширение The Post; сервер
  без свойства (Stalwart) — «не поддерживается», список показывается без состава.
- **Число участников** («soc@… 8») — после выбора списка: `ExpandList` по выбранному, заранее видимые строки не
  раскрываем. До выбора строка списка — без числа.
- **Другие пути** — по стандарту протокола: где списков справочника в протоколе нет (CardDAV, IMAP), ответ —
  `ListError::Unsupported`; своих расширений не придумываем.
- **Ошибка** — перечислением `ListError` (`Unsupported` | `Failed`), не строкой: интерфейс отличает «не
  поддерживается» от сбоя без разбора текста.
