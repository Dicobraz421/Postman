# Справочник компании у Exchange — поиск с подсказкой, без чтения всего GAL

- Дата: 2026-10-28.
- Вопрос: «Справочник компании» у Exchange — списком по страницам (`docs/decisions/2026-10-28-manual-test-1.md`) или
  поиском. Боевой Exchange 2013 CU23 без строки поиска GAL не отдаёт (`FindPeople` — `ErrorInvalidOperation`,
  `docs/EXCHANGE.md`, находка 18).

## Решение

- Без строки — пустой справочник с полем «Найти в справочнике» (подсказка, как искать).
- Найденное — списком, следующие результаты — подгрузкой по прокрутке.
- Весь справочник не читаем никогда: ни страницами без строки, ни `ResolveNames` по буквам.

## Как в коде

- Плагин EWS: `DirectoryPage` — пустая страница с `search_only`, `DirectoryLoaded` — пустой (T1-25в); поиск —
  `FindPeople` по строке.
- Интерфейс — T1-25г. Подгрузка найденного по прокрутке требует страниц у поиска (`FindPeople` с `offset`) — правка
  договора ядра, отдельной карточкой.
