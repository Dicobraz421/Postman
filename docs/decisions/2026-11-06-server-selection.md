# Ctrl+A в большой папке — выборка на сервере, а не загруженные письма

Решение владельца 2026-11-06: «делай сразу правильно, сервер». Не предупреждение «выбрано N из M», а настоящее действие
над всей выборкой: выборку определяет сервер, перенос идёт задачей, интерфейс письма не грузит.

Как сделано — `docs/adr/0006-single-store.md`, п. 4а.
