# «Прочитано» на macOS — ⇧⌘U

Владелец, 2026-11-12. На Windows «Отметить как прочитанное» — Ctrl+Q. На macOS ⌘Q зарезервировано системой под выход из
программы, поэтому там «Прочитано» — ⇧⌘U, как в «Почте» Apple (`MAC_MOVED` в `app-gpui/src/keymap.rs`, MAC-02, #575).

- Отвергнуто: оставить на маке «Прочитано» без клавиши по умолчанию — пользователю пришлось бы назначать её самому.
- Расхождение с Windows принимается: на каждой ОС — привычная там клавиша.
