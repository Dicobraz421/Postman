# «Ответить всем»: вложения беседы новым участникам

Владелец, 2026-11-13: чаще всего в «Ответить всем» добавляют человека, и он остаётся без вложений. Новый участник
получает вложения беседы, те, кто их уже получал, — нет. «Переслать» остаётся стандартным: все вложения и блок
«От / Дата / Кому / Копия / Тема».

## Кто есть кто
- **Уже получал** — был в «От», «Кому» или «Копии» любого письма беседы, где было это вложение.
- **Новый участник** — адресат черновика («Кому», «Копия», «Скрытая»), которого нет ни в одном письме беседы.
  Правило действует и для «Ответить», если человека добавили руками. Новых нет — поведение как раньше.
- Данные — из кэша: письма беседы (`thread_id`), их получатели и тела. Черновики беседы не в счёт: их адресаты
  ничего не получали.
- Вложения сравниваются по содержимому: крупные части письма (от 64 КиБ) — по SHA-256, который уже посчитало
  хранилище (ADR 0006, `Cache::letter_parts`); остальные — по SHA-256 байтов из кэша, если они есть; иначе — тот же
  blob или тот же размер и имя. Одинаковый файл в нескольких письмах уходит один раз.
- «Вложения беседы» — файлы писем: без картинок в тексте (подписи, логотипы), приглашений `.ics`, подписи и
  конверта S/MIME и пустых файлов; без того, что черновик уже несёт.

## Отправка: две копии одного письма
- У обеих копий одинаковые «Кому», «Копия», тема, In-Reply-To и References; Message-ID у каждой свой.
- Копия без вложений беседы доставляется только прежним участникам, копия с вложениями — только новым:
  JMAP — `EmailSubmission` с `envelope.rcptTo`; IMAP/SMTP — RCPT TO конверта.
- EWS доставляет всем из заголовков: основное письмо идёт всем как обычно, новым — второе письмо «Вложения из
  беседы»: та же тема, место в беседе, короткий текст, вложения.
- Прежних участников среди адресатов нет — одно письмо с вложениями всем.
- В «Отправленных» одна запись — копия прежних участников. JMAP: копия новым создаётся с `onSuccessDestroyEmail`;
  IMAP: в «Отправленные» дописывается только основная; EWS: второе письмо — `SendOnly`.
- Копия новым уходит первой. Не скачались байты вложений — отправка останавливается с ошибкой, не уходит ни одна
  копия. «Отменить» и отмена отложенной отправки (JMAP) отменяют и копию новым: связь отправок хранится в кэше.

## В черновике
- Строка над текстом: «Новым участникам (Имя) уйдут вложения беседы: N файлов» и «Не отправлять» — только для этого
  письма; отключили — «… вложения беседы не уйдут» и «Отправить». Команда `compose.share_attachments` — то же.
- Строка появляется и исчезает вместе с новым адресатом в полях; без цитаты («При ответе на сообщение») правило
  то же.

## Пересылка вложений (проверка 2026-11-13)
- Вложение уходит целиком: те же байты, имя, тип; картинка в тексте — inline с Content-ID и именем.
- Не скачалось или пришло пустым — письмо не уходит, ошибка «Вложение „…“ не скачалось».
