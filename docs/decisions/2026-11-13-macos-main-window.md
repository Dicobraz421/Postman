# macOS: главное окно по макету MainMac

Владелец, 2026-11-13: утверждён дизайн главного окна для macOS. Макеты — холст «Postman — дизайн», страница
«✓ Главное окно»: `MainMac` (светлая), `MainMacDark` (тёмная), `MainMacFull` (полный экран). Windows и Linux остаются
на `MainNav_title`, их не трогаем. Отклонённые варианты (`MainMacS1`–`S3`, `MainSw_*`) не делаются.

- **Заголовок**: слева системные «светофоры», за ними вкладки; своих кнопок окна, значка приложения и шестерёнки нет
  («Настройки…» ⌘, — в меню «Postman»).
- **Вкладки — только объекты** (письмо, встреча, вкладка почты ⌘T, настройки): значок 16 px по типу, цветом раздела;
  активная — полужирная, черта 2 px акцентом снизу, без плашки. Главной вкладки в полосе нет — её показывают разделы.
- **Разделы** (Почта, Календарь, Контакты, Задачи) — строкой из четырёх кнопок 32 px над деревом папок, во всю его
  ширину; «Новое письмо» и командная строка — над списком.
- **Полный экран**: «светофоров» нет — разделы встают на их место в заголовке (за ними черта 1 px), строка над деревом
  уходит, командная строка — от левого края.
- Темы — светлая и тёмная, как у остального окна. Команды и клавиши — те же (таблица команд), отличается только
  раскладка (ADR 0011: отличие ОС — свойство ОС, «светофоры» и полный экран рисует система).

## Почему
На Mac заголовок занимают «светофоры» ОС: значок приложения и разделы в нём теснят вкладки и выглядят чуждо. Разделы
над деревом папок — привычное место навигации в приложениях macOS.

Реализация — `docs/tasks/MAC-DES.md`.
