# Самообновление Postman — общий крейт `pets-update`

(владелец, 2026-11-11, Postman#503, класс B) Исполняет решения Урфина
[«Обновление продуктов»](https://github.com/Dicobraz421/Urfin/blob/main/docs/decisions/2026-11-11-self-update.md) и
[«Выпуск»](https://github.com/Dicobraz421/Urfin/blob/main/docs/decisions/2026-11-11-release-workflow.md): проверка
раз в сутки и по кнопке на GitHub Releases, установка только по согласию, подпись minisign вшитым ключом, включено по
умолчанию, выключатель в настройках и групповой политике. Это единственная сеть интерфейса Postman по своей
инициативе (модуль `app-gpui/src/update.rs`); телеметрии нет. winget (#500) остаётся каналом для администраторов.

Особенности Postman:

- **MSI «для всех»** (решение 2026-11-07) стоит в Program Files: обновление запускает `msiexec /i … /passive`, и
  Windows спрашивает разрешение (UAC). Отказ в UAC — прежняя версия запускается снова с тостом «Не удалось обновить».
- **Portable** (архив и `install.ps1`, без прав администратора) обновляется из `.zip`: файлы рядом с exe заменяются.
  Вид установки — метка `postman.portable` рядом с exe (кладут архив и `install.ps1`, MSI — нет); копии из архивов до
  метки узнаются по `install.ps1` рядом с exe. Профиль у обоих видов — `%LOCALAPPDATA%\Postman`, замена его не трогает.
- **Политика:** стандартная Pets `HKLM\Software\Policies\Aahz\Postman`, `AllowUpdate` (DWORD), и своя Postman
  `Software\Policies\Pets\Postman`, `AllowUpdate` строкой, как прочие политики Postman. `0` в любой — запрет, сетевых
  запросов нет, выключатель заперт, кнопки «Проверить обновления» нет.
- **Канал по умолчанию — по сборке:** у беты «Предварительный», иначе тестировщик не увидит следующих бет; выбор в
  настройках сильнее.
- **Выпуск:** job `publish` подписывает каждый `.msi` и `.zip` (`.minisig`); без секрета `UPDATE_SIGNING_KEY` выпуск
  красный. Ключ общий с Урфином (id `FBEB16F843D809C6`, 2026-11-12), открытая часть — в `UPDATE_PUBLIC_KEYS`.
