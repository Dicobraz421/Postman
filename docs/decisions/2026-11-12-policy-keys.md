# Политики организации — один набор ключей и типов для всех ОС

(владелец, 2026-10-26, согласие в чате на исправление нестыковок PAR-AUDIT, класс B; POL-01)

- Все политики Postman — в одном месте: Windows `Software\Policies\Pets\Postman` (HKLM, затем HKCU), macOS — профиль
  конфигурации пакета Postman (только принудительные значения). Таблица ключей и типов — `docs/tasks/POL-01.md`.
- Тип значения не меняет смысла: `REG_SZ` и `REG_DWORD` на Windows, строка, логическое, целое и дробное на macOS
  читаются одинаково. Неверный тип или значение — WARN в журнал, значение не применяется.
- `AllowUpdate` переезжает из `Software\Policies\Aahz\Postman` (решение 2026-11-11 «self-update») в общий ключ;
  прежний ключ — запасной, пока в общем значения нет, и пишет WARN «перенести».
