Postman — почта, календарь и контакты (сервер Stalwart, JMAP) для Windows 10/11 x64

Файлы:
  postman.exe         — приложение
  postman-worker.exe  — изолированный разбор писем (песочница); всегда рядом с postman.exe
  postman-viewer.exe  — просмотр вложений модулями (песочница), если есть в архиве; рядом с postman.exe
  install.ps1         — установка для текущего пользователя, без прав администратора
  README.txt          — этот файл

УСТАНОВКА

1. Распакуйте архив в любую папку.
2. Откройте в этой папке PowerShell (в Проводнике: Файл → «Открыть Windows PowerShell»
   или правой кнопкой по пустому месту → «Открыть в Терминале») и выполните:

     powershell -ExecutionPolicy Bypass -File .\install.ps1

Postman ставится в %LOCALAPPDATA%\Programs\Postman, ярлык «Postman» — в меню «Пуск».
Сценарий даёт папке установки право чтения для приложений-песочниц (ALL APPLICATION PACKAGES):
без него песочница воркера и просмотра вне Program Files не запускается. Повторный запуск — обновление
(закройте Postman перед ним).

Параметры install.ps1:
  -Destination <папка>   другая папка установки
  -NoShortcut            без ярлыка в «Пуск»
  -Uninstall             удаление: файлы и ярлык (данные и сохранённый вход остаются)
  -RegisterEventSource   по желанию, от администратора: зарегистрировать источник «Postman»
                         журнала Windows «Приложение» (вместе с -Uninstall — снять регистрацию).
                         Без него ошибки в журнал тоже пишутся, но «Просмотр событий» показывает
                         перед текстом «Не найдено описание для события…».

УДАЛЕНИЕ

  powershell -ExecutionPolicy Bypass -File "%LOCALAPPDATA%\Programs\Postman\install.ps1" -Uninstall

Данные остаются, их можно удалить вручную:
  %LOCALAPPDATA%\Postman — кэш писем, поисковый индекс, демо-ящик;
  «Диспетчер учётных данных» → «Учётные данные Windows» → записи «Postman:…» — сохранённый вход.

ЗАПУСК

Меню «Пуск» → Postman. При первом запуске — строка входа: адрес сервера, имя и пароль; пароль
хранится в диспетчере учётных данных Windows. Забыть вход: postman.exe --sign-out.
Демо без сервера: postman.exe --demo
Параметры: postman.exe --help

Окна консоли у Postman нет. Вывод --help, --bench и снимков (--screens) идёт в консоль, из которой
запущен postman.exe, или в файл (> файл). Командная строка cmd не ждёт окна приложения —
запускайте так: start /wait postman.exe --help. PowerShell: postman.exe --help | Out-Default.

Замер для разработчиков: start /wait postman.exe --demo --bench > bench.txt
(окно само листает список и меняет размер около минуты — не трогайте его).

ЖУРНАЛ

Ошибки и сбои — в журнал Windows «Приложение», источник Postman («Просмотр событий»).
Подробный журнал: задайте переменную POSTMAN_LOG=debug и запустите с перенаправлением:
  start /wait postman.exe 2> postman.log

ПОДПИСЬ

Подписанная сборка — с цифровой подписью на вкладке «Цифровые подписи» в свойствах postman.exe.
Неподписанную при запуске из распакованного архива SmartScreen предупредит:
«Подробнее» → «Выполнить в любом случае». После install.ps1 предупреждения нет: сценарий снимает
с установленных файлов отметку «загружено из Интернета».
